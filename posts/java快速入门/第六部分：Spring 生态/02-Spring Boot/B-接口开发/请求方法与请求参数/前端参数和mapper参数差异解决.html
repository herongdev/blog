处理插入其余表的多余参数

前端参数和mapper参数差异解决

请求方法与请求参数

On this page

现在的情况是这样的，我新增的地点时，我有一些用户输入的信息，但还有一些字段比如addressId是我插入地址表后得到的，那这个reqVo和Mapper的参数如何定义呢，要用两个类吗

ChatGPT 你可以使用多种方法来解决这个问题，下面是几种可能的解决方案：

方法 1：使用两个不同的VO类 你可以为用户输入和数据库插入操作定义两个不同的VO（Value Object）类。

java Copy code public class PlaceInputVO { // 用户输入的字段 // ... }

public class PlaceDatabaseVO extends PlaceInputVO { private Long addressId; // 从地址表中获取的ID // 其他从数据库或其他来源获取的字段 // ... } 方法 2：使用一个VO类，但动态设置属性 你也可以定义一个VO类，在运行时动态地设置其addressId字段。

java Copy code public class PlaceVO { // 用户输入的字段 private Long addressId; // 可以在运行时设置 // ... } 在这种情况下，你可以首先使用用户输入来创建一个PlaceVO对象，然后在插入地址表并获取addressId后，设置这个对象的addressId。

方法 3：使用Map或者@Param注解在Mapper中传递多个参数 如果你不想在Java代码中创建额外的类，你也可以在MyBatis Mapper中使用@Param注解或者Map对象来传递多个参数。

例如，在Mapper接口中：

java Copy code Long add(@Param("placeInput") PlaceInputVO placeInputVO, @Param("addressId") Long addressId); 然后在mapper.xml文件中，你可以使用#{placeInput.someField}和#{addressId}来访问这些参数。

选择哪一种方案取决于你的具体需求和项目结构。每种方案都有其优缺点，你需要根据你的应用程序的复杂性和灵活性需求来决定。
