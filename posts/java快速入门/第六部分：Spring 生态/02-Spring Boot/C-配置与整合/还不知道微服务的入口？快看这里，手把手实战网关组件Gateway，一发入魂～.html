springboot企业级实战 专栏收录该内容 5 篇文章4 订阅 已订阅 1、Gateway简介 Gateway项目提供了一个构建在 Spring 生态系统之上的 API 网关，包括: Spring 5、 Spring Boot 2和 Project Reactor。Spring Cloud Gateway 旨在提供一种简单而有效的方法来路由到 api，并为它们提供交叉关注点，如安全性、监视/度量和弹性。

官网链接直通车gateway

Spring Cloud Gateway 的特点:

基于 Spring Framework 5、 Project Reactor 和 Spring Boot 2.0构建 能够匹配任何请求属性上的路由。 基于路由的条件构造器Predicates 和过滤器filter 断路器集成。 集成 Spring Cloud DiscoveryClient 易于编写的路由的条件构造器Predicates 和过滤器filter 请求速率限制 路由的路径重写 那么我为什么需要使用gateway网关呢？

主要原因是在开发恋爱话术服务和之前的毕设项目服务对应的小程序时，为了方便使用同一个https安全域名，所以把两个功能的代码写在一个项目里面，导致每次修改一个功能时会影响另一个服务的使用，没有达到微服务各司其职的理念，所以打算通过使用gateway网关来对项目进行一个重构，最终实现一个域名根据路由分别转发到不同的后端服务上。
