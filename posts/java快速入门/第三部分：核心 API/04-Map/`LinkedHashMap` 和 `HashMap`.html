`LinkedHashMap` 和 `HashMap`

On this page

LinkedHashMap 和 HashMap 是 Java 中两种常用的映射类型，都实现了 Map 接口，但它们在内部结构和行为上有一些重要的区别。下面是一个表格，详细比较这两者的特点：

特性HashMapLinkedHashMap
排序不保证任何顺序按插入顺序或访问顺序维护键值对
性能插入和查找的速度略快插入和查找速度略慢，因为需要维护元素的顺序
内存占用较低较高，因为需要额外的内存来维护元素的顺序链表
迭代顺序不固定，与键的哈希码有关固定，按照元素的插入顺序或最后访问顺序（取决于构造时的选择）
构造函数选项无特定选项可以选择访问顺序（access-order）或插入顺序（insertion-order）
使用场景当元素的顺序不重要时使用当需要维持元素的插入顺序或访问顺序时使用
数据结构基于哈希表的实现基于哈希表的实现，但增加了一个双向链表以维护顺序
对null键和值的支持允许键和值为null（最多一个null键）同样允许键和值为null

总结： ​

  • 使用 HashMap：当你不需要关心 Map 中元素的顺序，只需要快速存取时。
  • 使用 LinkedHashMap：当你需要保持元素插入的顺序，或者在 LRU 缓存（最近最少使用缓存）实现中保持访问顺序时。

LinkedHashMap 提供的顺序性使其在需要顺序的场景下非常有用，如在缓存策略、记录插入顺序的特定应用中，或者当输出的顺序需要与输入完全一致时。
