一、Reject但没有明确return值
async function foo() {
    console.log(1);
    Promise.reject(3);
}
foo().then(console.log, console.log)

异步函数内部reject()一个值，并没有return一个值的效果，所以上面的函数实际上还是返回了一个resolve(undefined)的Promise，所以没有被promise拒绝回调捕获；

二、函数内部了抛错
异步函数内部throw 错误有return一个值的效果，会返回一个拒绝的期约；

    console.log(1);
    throw 2
}
foo().catch(console.log)
输出：1  2

第四点，async 函数可以保留运行堆栈。
`const` `a` `=` `()` `=>` `{`

 `=>`
