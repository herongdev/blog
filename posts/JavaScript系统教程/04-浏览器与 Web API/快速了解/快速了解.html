快速了解 ​

本节目标：理解“快速了解”的核心思路，并能把它用于实际开发或面试表达。 Blob（Binary Large Object）是 Web 编程中用于表示原始数据的对象，通常用于处理图片、视频、音频等文件类型的数据。 **一、**Blob 是什么？ Blob 是一个二进制数据的集合。它可以表示任意的原始数据，不限于特定格式。Blob 的主要特点是：

  • 不可变：一旦创建，Blob 的内容无法修改，只能通过操作新数据来创建新的 Blob。
  • 数据块：可以是文本、图片、视频、音频等任意数据的二进制表示。
  • 内存高效：Blob 可以存储大量数据，适合用于文件下载、上传和数据传输。

**二、**Blob 的主要属性和方法1. 创建 Blob 使用 Blob 构造函数创建一个 Blob 对象： const blob = new Blob([data], { type: "mime-type" });

  • data：一个数组，包含需要存储的数据，可以是字符串、ArrayBuffer、TypedArray 或其他 Blob。
  • type：MIME 类型，用于指示数据类型，例如 image/png、text/plain、application/pdf 等。
    • 是否需要指定 MIME 类型？
      • 推荐指定：指定 MIME 类型（例如 "application/vnd.ms-word"）能够帮助浏览器和操作系统更好地理解文件内容，并且在文件下载和打开时采用正确的程序。
      • 不指定也能正常运行：即使不指定 MIME 类型，文件仍然可以下载，但有时会缺乏文件类型信息（例如，可能不能自动选择正确的应用程序打开文件）。
    • 因此，指定 MIME 类型是一个最佳实践，它可以提升文件的兼容性和可用性。

示例： const textBlob = new Blob(["Hello, world!"], { type: "text/plain" });

2. 主要属性

  • size：Blob 的大小（字节），例如 blob.size。
  • type：MIME 类型，例如 blob.type。

示例： console.log(textBlob.size); // 输出 Blob 的字节大小 console.log(textBlob.type); // 输出 "text/plain"

3. 主要方法

  • Blob.slice([start[, end[, contentType]]])：从 Blob 中提取一个新 Blob。可以指定起始和结束的字节位置以及新 Blob 的类型。

const slice = textBlob.slice(0, 5); // 提取前5个字节

  • URL.createObjectURL(blob)：生成一个指向 Blob 的临时 URL，用于直接引用 Blob 数据。const url = URL.createObjectURL(textBlob);

URL.createObjectURL(blob) 确实创建了一个指向 Blob 的引用。返回的 url 是一个基于 blob: 协议的 URL，通常格式为 blob:<origin>/<unique-identifier>。 这个 URL 只在当前页面的会话中有效，可以在 HTML 元素（例如 <a> 标签的 href）中使用，并允许浏览器在需要时访问和使用该 Blob 数据。

  • URL.revokeObjectURL(url)：释放临时 URL 占用的资源。URL.revokeObjectURL(url);
  • Blob.text()：返回 Blob 内容的 Promise，用于读取文本数据。textBlob.text().then((text) =>console.log(text)); // 输出 "Hello, world!"
  • Blob.arrayBuffer()：返回一个包含 Blob 内容的 ArrayBuffer 的 Promise，用于读取二进制数据。textBlob.arrayBuffer().then((buffer) =>console.log(buffer));

**三、**Blob 的实际应用场合

  1. 文件下载：Blob 常用于下载功能，特别是在需要从网络获取文件、处理数据然后下载时。

const blob = new Blob(["Hello, world!"], { type: "text/plain" }); const url = URL.createObjectURL(blob); const a = document.createElement("a"); a.href = url; a.download = "example.txt"; a.click(); URL.revokeObjectURL(url); // 释放资源

  1. 文件上传：Blob 可用于存储并上传用户选择的文件，通过 FormData 对象与后端交互。

const formData = new FormData(); formData.append("file", blob, "example.txt"); fetch("/upload", { method: "POST", body: formData });

  1. 图片处理：Blob 可用于处理图片文件，比如将 <canvas> 中的图像转换为 Blob 并保存。

canvas.toBlob((blob) => { const url = URL.createObjectURL(blob); const img = document.createElement("img"); img.src = url; document.body.appendChild(img); URL.revokeObjectURL(url); });

  1. 显示媒体数据：Blob 常用于生成临时 URL，方便在网页上直接预览文件内容，例如预览音频、视频、图片等数据。

**四、**Blob 在开发中的其他重要知识

  1. MIME 类型：指定正确的 MIME 类型非常重要，尤其在下载和显示数据时。常见类型包括：
    • 文本：text/plain，text/html
    • 图片：image/png，image/jpeg
    • 文档：application/pdf，application/vnd.ms-excel
  2. 内存管理：Blob 数据占用较多内存，使用 URL.revokeObjectURL() 及时释放临时 URL，可以避免内存泄漏。
  3. 文件处理能力有限：Blob 主要用于客户端，通常只适合小文件处理，如果文件非常大（如视频文件），建议在后端进行处理。
  4. 安全限制：Blob URL 在生成后是与 origin 绑定的，跨域访问被限制，适合在客户端内部传递和处理数据。
  5. 异步读取：Blob.text() 和 Blob.arrayBuffer() 提供异步读取功能，更适合现代开发需求。

示例总结 以下是一个综合示例，演示了 Blob 的生成、下载和资源释放： const exportData = async (data) => { // 创建 Blob const blob = new Blob([data], { type: "application/json" }); // 创建临时 URL const url = URL.createObjectURL(blob); // 创建下载链接 const a = document.createElement("a"); a.href = url; a.download = "data.json"; document.body.appendChild(a); a.click(); // 释放 URL URL.revokeObjectURL(url); }; // 使用示例 const jsonData = JSON.stringify({ name: "Alice", age: 30 }); exportData(jsonData); Blob 是处理文件数据、实现下载和数据传递的实用工具。通过 Blob 的灵活操作，可以大幅提升 Web 应用的用户体验，例如支持用户在客户端直接预览、下载文件等。
