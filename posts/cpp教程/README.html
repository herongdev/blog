C++ 与 CMake 学习指南 ​

从 C++ 语法速览到 CMake 实战，再到 NAPI 模块构建，一站式掌握 C++ 原生开发。

    • 两种修复方案（用真名/包含头文件）
    • 常见错误与最佳实践

第三部分：图形学基础 ​

学习 OpenGL ES 图形渲染基础。

  • EGL 是什么？OpenGL 与系统之间的翻译官 ⭐

    • EGL 的翻译官角色
    • EGLDisplay、EGLSurface、EGLContext
    • 完整工作流程
    • 跨平台兼容性

  • OpenGL ES 3 与 EGL 的区别：工地比喻 + 实战清单 ⭐

    • OpenGL ES 3 = 建筑工人
    • EGL = 工地办公室
    • 工作流程对比
    • 版本区别（ES 3 vs ES 2）

  • 为什么一个面需要 6 个顶点：三角形基础与纸片立方体优化 ⭐

    • GPU 为什么只认三角形
    • 矩形 = 2 个三角形 = 6 个顶点
    • 纸片立方体优化（避免 Z-fighting）
    • 三角形绘制的优势

  • 顶点着色器与片段着色器：上色师傅比喻详解 ⭐

    • 顶点着色器 = 定位师傅（管位置）
    • 片段着色器 = 上色师傅（管颜色）
    • 完整工作流程
    • 数据量对比与分工效率

  • Shader 源是什么：食谱比喻与实战清单 ⭐

    • Shader 源 = 给 GPU 的“食谱”
    • 顶点/片段 Shader 职责与流程
    • GLSL 示例与项目组织
    • 为什么 Shader 提升灵活性和效率

  • 3D 开发基础：从零到一的十课（坐标/网格/相机/光照/流水线） ⭐

    • 坐标系与网格
    • 变换矩阵与相机
    • 材质/纹理与光照
    • GPU 流水线与动画帧率

text
1. C++ 快速入门 ← 语法基础
   ├─ .h 和 .cpp 文件
   ├─ 常用标准库（vector, string, algorithm）
   ├─ 类和 RAII
   └─ extern "C" 详解

2. CMake 基础 ← 构建系统
   ├─ Hello CMake
   ├─ 生成动态库
   └─ 文件组织

3. CMake 实战 ← NAPI 应用
   ├─ 第三方库管理
   ├─ 依赖链接
   └─ NAPI 模块构建

4. 语法深入 ← 理解规则
   └─ CMake 语法特点

进阶开发者路线 ​

text
1. NAPI 开发
2. HarmonyOS 原生模块
3. 性能优化
4. 多平台构建

图形学路线 ​

text
1. EGL 基础 ← 图形环境
   └─ EGL 是什么、如何初始化

2. OpenGL ES 3 ← 绘制技术
   └─ OpenGL ES 3 vs EGL 区别

3. 图形学基础 ← 渲染原理
   ├─ 为什么用三角形（6顶点/面）
   ├─ 顶点着色器（定位）
   └─ 片段着色器（上色）

🔧 开发环境 ​

推荐配置 ​

  • C++ 编译器：GCC/Clang
  • CMake：3.16 以上
  • 编辑器：VSCode / CLion / DevEco Studio
  • 操作系统：Windows / Linux / macOS / HarmonyOS

快速搭建 ​

  1. 安装 C++ 编译器（随操作系统自带或下载）
  2. 安装 CMake
  3. 创建第一个项目
  4. 按照教程实践
