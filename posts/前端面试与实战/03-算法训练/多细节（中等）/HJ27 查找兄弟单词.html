HJ27 查找兄弟单词 ​

本节目标：理解“HJ27 查找兄弟单词”的核心思路，并能把它用于实际开发或面试表达。 中等 通过率：18.46% 时间限制：1秒 空间限制：32M 知识点==查找== 描述 定义一个单词的“兄弟单词”为：交换该单词字母顺序（注：可以交换任意次），而不添加、删除、修改原有的字母就能生成的单词。 兄弟单词要求和原来的单词不同。例如： ab 和 ba 是兄弟单词。 ab 和 ab 则不是兄弟单词。 现在给定你 n 个单词，另外再给你一个单词 x ，让你寻找 x 的兄弟单词里，按字典序排列后的第 k 个单词是什么？ 注意：字典中可能有重复单词。 数据范围： 1≤n≤1000 ，输入的字符串长度满足 1≤len(str)≤10 ， 1≤k<n输入描述： 输入只有一行。 先输入字典中单词的个数n，再输入n个单词作为字典单词。 然后输入一个单词x 最后后输入一个整数k 输出描述： 第一行输出查找到x的兄弟单词的个数m 第二行输出查找到的按照字典顺序排序后的第k个兄弟单词，没有符合第k个的话则不用输出。 示例1 输入： 3 abc bca cab abc 1 输出： 2bca 示例2 输入： 6 cab ad abcd cba abc bca abc 1

输出： 3bca

说明： abc的兄弟单词有cab cba bca，所以输出3经字典序排列后，变为bca cab cba，所以第1个字典序兄弟单词为bca

思路：

  1. 如何判断是否是兄弟单词

  2. 如果取值索引越界如何处理

  3. 取第K个时，要减1才得到正确的索引 要找到给定单词的兄弟单词，并确定按字典序排列后的第 k 个兄弟单词，我们可以按以下步骤操作：

  4. 收集兄弟单词：遍历字典中的每个单词，比较它们和给定单词 x 是否是兄弟单词。判断两个单词是否为兄弟单词的标准是，它们的字母排序后相同，且原单词不相同。

  5. 排序并选择：将所有找到的兄弟单词按字典序排序，然后根据给定的 k 值选择对应的兄弟单词。

下面是Python代码实现： def find_brother_words(n, words, x, k):

收集兄弟单词 ​

brothers = [] for word in words: if word != x and sorted(word) == sorted(x): brothers.append(word)

按字典序排序兄弟单词 ​

brothers.sort()

输出兄弟单词的数量 ​

print(len(brothers))

如果存在第k个兄弟单词，输出它 ​

if k <= len(brothers): print(brothers[k - 1])

输入处理 ​

n, *words, x, k = input().split() n = int(n) k = int(k)

查找兄弟单词并输出结果 ​

find_brother_words(n, words, x, k)

这段代码首先定义了一个函数 find_brother_words，它接受字典单词的数量、字典单词列表、给定单词 x 以及整数 k 作为参数。函数内部，通过遍历和比较找出所有兄弟单词，然后将这些兄弟单词排序并根据 k 值选择输出。

注意：代码中的输入处理部分 (n, *words, x, k = input().split()) 使用了 Python 的解包特性来方便地接收和处理输入。这种方式假设输入格式严格按照题目描述，即首先是字典单词数量 n，接着是 n 个字典单词，然后是给定的单词 x，最后是整数 k。
