描述 IPV4地址可以用一个32位无符号整数来表示，一般用点分方式来显示，点将IP地址分成4个部分，每个部分为8位，表示成一个无符号整数（因此正号不需要出现），如10.137.17.1，是我们非常熟悉的IP地址，一个IP地址串中没有空格出现（因为要表示成一个32数字）。 现在需要你用程序来判断IP是否合法。 数据范围：数据组数：1≤�≤18 1≤t≤18 进阶：时间复杂度：�(�) O(n) ，空间复杂度：�(�) O(n)

输入描述： 输入一个ip地址，保证不包含空格 输出描述： 返回判断的结果YES or NO 示例1 输入： 255.255.255.1000 ==复制== 输出： NO

def is_valid_ipv4(ip): parts = ip.split(".") if len(parts) != 4: return "NO" for part in parts: if not part.isdigit() or not 0 <= int(part) <= 255: return "NO" if part != "0" and part.startswith("0"): return "NO" return "YES"

while True: try: ip = input() print(is_valid_ipv4(ip)) except EOFError: break
