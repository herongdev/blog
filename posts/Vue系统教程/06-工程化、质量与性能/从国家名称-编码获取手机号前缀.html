本节目标：理解“从国家名称-编码获取手机号前缀”的核心思路，并能把它用于实际开发或面试表达。 ==以下是关于 ​==从国家名称/编码获取手机号前缀（国际电话区号）​ ==的解决方案，结合 npm 包和 API 推荐：==

​****1. 使用 libphonenumber-js（推荐）​功能==：解析国家代码对应的国际电话区号（如== ==Afghanistan → +93====），支持反向查找。== 安装==：==

==bash== ==复制== ==npm== ==install== ==libphonenumber-js== ​****代码示例

​****2. 使用 google-libphonenumber（官方库的封装）​功能==：谷歌官方电话库的 Node.js 适配，功能更全面但体积较大。== 安装==：==

==bash== ==复制== ==npm== ==install== ==google-libphonenumber== ​****代码示例

==javascript== ==复制== ==const== ==libphonenumber== ===== ==require====(===='google-libphonenumber'====);========const== ==phoneUtil== ===== ==libphonenumber.PhoneNumberUtil.====getInstance====();====== // 获取国家区号======const== ==countryCode== ===== =='US'====;== // 美国======const== ==prefix== ===== ==phoneUtil.====getCountryCodeForRegion====(countryCode);== // 返回 1======console====.====log====(====+====${prefix}========);==

​****3. 使用 country-telephone-data（轻量级数据）​功能==：直接提供国家编码、电话前缀、格式等数据的 JSON 文件。== 安装==：==

==bash== ==复制== ==npm== ==install== ==country-telephone-data== ​****代码示例

==javascript== ==复制== ==import== =={ allCountries }== ==from== =='country-telephone-data'====;====== ==const== ==countryName== ===== =="Afghanistan"====;========const== ==countryData== ===== ==allCountries.====find====(c== ===>== ==c.name== ======= ==countryName);========if== ==(countryData) {====== ==console====.====log====(====+====${countryData.dialCode}========);== // +93======}==
