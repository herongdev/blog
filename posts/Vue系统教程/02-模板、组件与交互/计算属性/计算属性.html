计算属性 ​

本节目标：理解“计算属性”的核心思路，并能把它用于实际开发或面试表达。

说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。 显然在模板内使用表达式非常便利，但放入太多的逻辑会让模板过重且难以维护。

所以，对于任何复杂逻辑，应当使用计算属性。
==计算属性往往依赖于其它非计算属性。==
==计算属性的依赖属性变化的同时，计算属性也会更新。==
如下例：
==<div id====="example"====>======  ==<p>====Original message: "{{ message }}"====</p>======  ==<p>====Computed reversed message: "{{ reversedMessage }}"====</p>========</div>==
==var== ==vm === ==new== ==Vue({======  ==el:== =='#example'====,======  ==data: {======    ==message:== =='Hello'======  ==},======  ==computed: {======    ==//== ==计算属性的== ==getter======    ==reversedMessage:== ==function== ==() {======      ==// `this`== ==指向== ==vm== ==实例======      ==return this====.message.split(====''====).reverse().join(====''====)======    ==}======  ==}========})==
==结果：==
Original message: "Hello"
Computed reversed message: "olleH"
这里我们声明了一个计算属性 ==reversedMessage==。我们提供的函数将用作 property ==vm.reversedMessage== 的 **getter** 函数。
**特性：**
==依赖变化才求值，否则利用之前的缓存数据，类似于====react====中的====useMemo====；==

==相比之下，每当触发重新渲染时，调用方法将====总会====再次执行函数。==

==这也同样意味着下面的计算属性将不再更新，因为== ==Date.now()== ==不是响应式依赖：==
==computed: {======  ==now:== ==function== ==() {======    ==return== ==Date====.now()======  ==}========}==
**计算属性的** **setter**
==即设置计算属性的值的时候，设置计算属性所依赖属性的属性值。==
==计算属性默认只有== ==getter====，不过在需要时你也可以提供一个== ==setter====：==
==// ...========computed: {======  ==fullName: {======    ==// getter======    ==get:== ==function== ==() {======      ==return this====.firstName +== ==' '== ==+== ==this====.lastName======    ==},======    ==// setter======    ==set:== ==function== ==(newValue) {======      ==var== ==names = newValue.split(====' '====)======      ==this====.firstName = names[====0====]======      ==this====.lastName = names[names.length -== ==1====]======    ==}======  ==}========}========// ...==
==现在再运行== ==vm.fullName = 'John Doe'== ==时，====setter== ==会被调用，====vm.firstName== ==和== ==vm.lastName====也会相应地被更新。==

Vue之computed(计算属性)详解get()、set() 通过getter\setter实现对属性数据的显示和监视，计算属性存在缓存，多次读取只执行一次getter计算。

<script src="https://cdn.jsdelivr.net/npm/vue/dist/vue.js"></script>
<script>
  const demo = new Vue({
    el: '#demo',
    data: {
      firstName: 'A',
      lastName: 'B',
      fullName2: 'A B'
    },
    computed: {
      //

什么时候执行：初始化显示

/

相关的data属性发生变化

      fullName1() {//

计算属性中的get方法，方法的返回值就是属性值

        return this.firstName + ' ' + this.lastName
      },
      fullName3: {
        get() {//

回调函数 当需要读取当前属性值是执行，根据相关数据计算并返回当前属性的值

          return this.firstName + ' ' + this.lastName
        },
        set(val) {//

监视当前属性值的变化，当属性值发生变化时执行，更新相关的属性数据

          //val

就是fullName3的最新属性值

          console.log(val)
          const names = val.split(' ');
          console.log(names)
          this.firstName = names[0];
          this.lastName = names[1];
        }
      }
    }
  })
</script>

改变姓和名时，对应的姓名1和姓名2会发生改变。

改变姓名1时，姓和名、姓名2都不会改变。

改变姓名2时，对应的姓和名，以及姓名1也会改变。
