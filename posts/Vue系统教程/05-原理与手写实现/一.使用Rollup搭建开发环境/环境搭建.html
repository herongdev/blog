npm install

**四、安装完毕后，编写****rollup****配置文件**
**rollup.config.js****文件编写**
import babel from 'rollup-plugin-babel';
import serve from 'rollup-plugin-serve';
export default {
  input: './src/index.js',
  output: {
  file: 'dist/umd/vue.js',
    format: 'umd', // 打包后的模块化类型
    name: 'Vue', // 打包后的全局变量的名字
    sourcemap: true
  },
  plugins: [ // 要使用的插件
    babel({
      exclude: 'node_modules/**' // 使用babel进行转化，但排除node_modules
    }),
    process.env.ENV === 'development' ? serve({
      open: true,
      openPage: '/public/index.html',
      port: 3000,
      contentBase: ''
    }) : null
  ]
}
配置中
output配置，可以使用数组来配置不同格式的打包文件。
plugins：用来对rollup的各插件进行配置；上面配置了plugin-babel和plugin-serve；
sourcemap如下

总结：
通过rollup工具，我们将src中的源码打包到了dist目录中；

src中使用了高级语法，我们通过babel工具，将它转化为低级语法，并转换成了我们指定的格式，如umd,esm,iife,cjs等；

然后我们就可以在index.html中引入打包后的js文件，使用vue构建程序；

补充 安装rollup-plugin-node-resolve; 可以在找不到相应文件时，会按node方式去解析文件，即默认使用index.js文件； 安装：yarn add rollup-plugin-node-resolve 配置如下图：

这样rollup打包时，在找不到文件时，会尝试使用node的方式去解析，比如会考虑index.js文件；
