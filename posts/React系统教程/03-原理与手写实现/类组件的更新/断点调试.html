在updateComponent方法中：

  • 我们取出updater中保存的组件实例，还有pendingStates数组；

updateComponent() {

在这里，我们调用了getState方法，这个方法做了一个State合并，并返回State值，这里要注意setState的参数是函数的情况，在遍历pendingStates的过程中，如果state值为一个函数，每次传入这个函数的State值将会是上一次合并过的新的State值；

在shouldUpdate中，我们先把最新的State值保存在实例上，然后我们调用forceUpdate方法；

//

内部方法

function shouldUpdate(classInstance, nextState) {
  classInstance.state = nextState;
  classInstance.forceUpdate();
}

在forceUpdate方法中：

  • 我们取出oldRenderVdom；
  • 然后我们调用findDOM，目的是为了找到旧的真实DOM;
  • 接下来，我们调用组件的render方法，取得最新的renderVdom；
  • 最后，我们进行vdom对比；
  • 然后，我们把最新的renderVdom保存到实例的oldRenderVdom上；
forceUpdate() {
  let oldRenderVdom = this.oldRenderVdom;
  let oldDOM = findDOM(oldRenderVdom);
  let newRenderVdom = this.render();
  compareTwoVdom(oldDOM.parentNode, oldRenderVdom, newRenderVdom);
  this.oldRenderVdom = newRenderVdom;
}
