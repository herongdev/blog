接下来，我们要处理更新时的生命周期

我们在按钮上绑定了一个事件，这个事件是react的合成事件，会：

  • 作为浏览器的事件兼容处理；
  • 会将事件全部代理到document或根dom节点；
  • 还会在事件开始的时候将isBitchUpdate设置为true，结束时设置为false;
function updateProps(dom, oldProps, newProps) {
  for (let key in newProps) {
    if (key === 'children') {//children
      continue;//

此处忽略子节点的处理

    } else if (key === 'style') {//style
      let styleObj = newProps[key];
      for (let attr in styleObj) {
        dom.style[attr] = styleObj[attr];
      }
    } else if (key.startsWith('on')) {
      //dom[key.toLocaleLowerCase()] = newProps[key];
      addEvent(dom, key.toLocaleLowerCase(), newProps[key]);
    } else {
      dom[key] = newProps[key];//className
    }
  }
}

在处理jsx的属性时，对于事件类型，我们会调用addEvent方法； 这个方法会给相应的dom上面加上store属性； 同时，在document上面，也加上了该类型事件来代理dom上的事件； 之后jsx上的事件都会在document上进行调用dispatchEvent方法；

export function addEvent(dom, eventType, eventHandler) {
    let store;
    if (dom._store) {//_store

是给原生DOM对象上添加的自定义属性

        store = dom._store;
    } else {
        dom._store = {};
        store = dom._store;
    }
    //store.onclick=handleClick
    store[eventType] = eventHandler;
    //document.onclick=dispatchEvent
    if (!document[eventType]) {
        document[eventType] = dispatchEvent;
    }
}

/**
 *

不管点什么按钮，触发什么事件，最终执行的都是

dispatchEvent
 *

在合成事件的处理函数里，状态的更新是批量的

 * @param {*} event

原生的事件对象 不同的浏览可能是不一样

 */

当被代理dom上的某类型事件发生时，会调用些方法；

  • 先找到事件类型和target;
  • 将批量更新设置为true;
  • 创建一个合成事件对象；
  • 然后模拟向上冒泡；
  • 从target开始，从中取出真实的事件处理函数；
  • 然后在合成事件对象上加上targe和currentTarget；
  • 再绑定this为被代理dom后，调用事件处理函数，并传入合成的事件对象；
  • 所以，所有的事件，实际上是在document.dispatchEvent中进行统一处理的；
  • 最后，我们循环currentTarget，把这个事件冒泡出去，让所有添加了同类事件处理函数的dom元素都触发这个事件；
  • 最后，我们把isBatchingUpdate设置为false；
  • 然后执行真正的更新；
