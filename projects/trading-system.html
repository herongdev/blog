CASE / 03-B

交易界面的核心不是信息密度，而是让持续变化的状态始终可判断、可操作。

场景
交易平台同时承载行情、账户、订单和图表等高频变化信息，对状态一致性、渲染效率和异常恢复都有较高要求。
核心问题
在 WebSocket 持续推送、多账户切换和大数据表格场景下，维持清晰的数据流和稳定的交互反馈。
SYSTEM / BUILD

项目构成

  1. 01

    基于 Vue 3、TypeScript、Vite 与 Pinia 组织模块和状态边界。

  2. 02

    围绕 WebSocket 实时更新设计页面数据链路，并处理多账户上下文。

  3. 03

    使用虚拟化表格承载高密度列表，减少无效渲染。

  4. 04

    接入 KLineChart Pro 与 TradingView Datafeed，连接行情数据与图表交互。

  5. 05

    参与上线后的独立维护，持续定位交易链路和图表数据问题。

FLOW

工作链路

  1. 1实时行情 / 账户事件
  2. 2状态归一化
  3. 3表格与图表渲染
  4. 4交易交互
  5. 5异常定位与维护
