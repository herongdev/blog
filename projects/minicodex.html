CASE / 01-B

把“AI 会写代码”拆成一条可解释、可授权、可验证的工程链路。

场景
编码 Agent 的难点不在一次性生成代码，而在怎样读取上下文、调用工具、修改文件、执行检查，并让人能够理解和约束它的行为。
核心问题
在自动化效率与工程安全之间建立明确边界：哪些动作能自动执行，哪些必须审批，怎样记录过程并验证结果。
SYSTEM / BUILD

项目构成

  1. 01

    从输入任务、保存任务和生成计划开始，让目标与执行步骤都有稳定载体。

  2. 02

    通过 Tool Registry 和权限审批约束文件、命令等能力的调用范围。

  3. 03

    在修改之后运行检查，并用 Trace、Replay、Eval 留下可回看和可评估的过程。

  4. 04

    再把后端 API、SSE 和桌面界面接入同一条任务链路，形成完整的人机协作体验。

FLOW

工作链路

  1. 1输入任务
  2. 2生成计划
  3. 3人工审批
  4. 4调用工具并修改
  5. 5运行检查
  6. 6记录与评估
