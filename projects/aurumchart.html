CASE / 03-A

把交易图表从单页组件，整理为面向不同终端和交互习惯的产品能力。

场景
交易产品需要在多种终端上呈现蜡烛图、指标和实时变化。不同平台在渲染、手势、生命周期和接入方式上都有差异。
核心问题
在多端交付中保持核心图表语义一致，同时针对各平台做交互适配，而不是简单套用同一套 Web 容器。
SYSTEM / BUILD

项目构成

  1. 01

    将蜡烛图、技术指标和实时更新作为核心能力边界。

  2. 02

    覆盖 Web / H5、Android、iOS、HarmonyOS 与 UniApp 等产品形态。

  3. 03

    针对平台交互做适配，使缩放、拖动和实时数据更新符合端侧使用方式。

FLOW

工作链路

  1. 1统一图表语义
  2. 2平台接入层
  3. 3端侧交互适配
  4. 4实时行情更新
