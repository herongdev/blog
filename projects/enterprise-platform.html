CASE / 02-A

面对复杂系统，先建立可持续迭代的前端结构，再处理空间数据、设备和业务流程的交汇。

场景
政企项目通常包含 Web 与移动端、多角色权限、地图和三维场景、视频设备以及跨部门流程，交付周期长、协作边界多。
核心问题
让空间可视化与真实业务流程共存，同时保持多端代码的可维护性，并在团队协作中清楚界定个人负责范围。
SYSTEM / BUILD

项目构成

  1. 01

    智慧水利：承担 Web / App 前端架构与框架搭建，交付核心业务模块。

  2. 02

    通过 GeoServer、SuperMap、OpenLayers、Cesium 与 Three.js 组织二维三维空间能力。

  3. 03

    接入摄像头、云台控制与全景等现场能力，使地图场景能够服务业务判断。

  4. 04

    工程管控：作为团队参与者完成 React Web 模块，以及 Vue 2 + uni-app 的移动端核心模块。
