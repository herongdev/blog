第一次使用

  1. 在“设置”中保留本机方式，到“本地识别”下载或导入 Whisper Base 模型。首次联网下载约 148 MB，请保持前台。也可先录音，随后再转写。
  2. 点底部“录制”，授权麦克风，保持声稿在前台。完成后点“结束并保存”，先保存原音，文字可稍后补齐。
  3. 在录音列表打开记录，点按文字回听对应语句或片段，修改文字并保存。识别稿需要你自行核对。
  4. 通过详情的更多菜单复制全文或导出 TXT、SRT、JSON。重要记录建议定期导出备份。

导入已有音频

从录音列表导入你选定的文件。声稿会复制至本机私有目录，再使用所选方式转写。多个稿件可以共享同一原音，重新转写会另存结果。

需要云端转写

在设置中选择云端，填写兼容服务地址、模型与自己的 API Key。上传前请核对接收域名并阅读服务方隐私政策。没有配置或未确认时，声稿不会上传录音。

遇到问题

来信请描述设备型号、系统版本、声稿版本、所选转写方式及操作步骤。可以附上去除私人信息的截图。请不要发送 API Key；敏感录音不必随反馈提供。

删除记录和密钥

在录音详情中删除不需要的记录。若其他稿件仍引用同一原音，这份原音会继续保留。应用外的导出件、系统备份和云端副本需要在对应位置另行删除。

在“云端服务”中清空密钥并保存，可移除当前服务的已保存密钥。无需继续使用的密钥也可在服务方控制台撤销。
