01 / 留下声音

录制，或者导入。

保存完整麦克风录音，也可以导入已有的 M4A、MP3、WAV 等音频。本地资源没准备好时，仍可先保存原音。

02 / 整理文字

转写，回听，再校对。

按自然段阅读机器稿，点按文字回听对应音频。完整录音可以另存新转写结果，保留原稿与人工修改。

03 / 带走记录

搜索、复制和导出。

按标题或正文搜索历史录音。复制全文，或导出 TXT、SRT 和 JSON，用于自己的笔记与后续工作。

开始之前，你可能想知道。

需要注册账户吗？

声稿没有登录账户。本地方式无需 API Key；可选云端服务需填写你自己的服务地址与密钥。

刚安装就能离线识别吗？

录音可以先保存。默认 Whisper Base 首次需要下载约 148 MB 的模型，也可导入模型。准备完成后，本地转写不需要联网。

能一直在后台录音吗？

当前版本需要保持前台。进入后台会停止并尝试保存原音，不提供持续后台录音。
