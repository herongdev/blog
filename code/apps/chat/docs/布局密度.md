# 布局密度

“用户设置 → 语言与外观 → 布局密度”提供紧凑、适中、宽松三档，默认适中。选择后立即生效并保存到当前浏览器；支持中英文、明暗主题、跨标签页同步和首屏恢复。

## 产品取舍

密度用于调整一屏能容纳多少信息。紧凑减少列表行内边距、消息间隔和正文段距；宽松增加留白；适中保留已有布局。字体大小、行高、图标、侧栏和阅读列宽度保持原有规则。控件保留最小高度，适合长选项的自动换行继续生效。

参考 Adobe Spectrum 将密度与字号区分的做法：其紧凑 Tabs 保持相同字号，只收紧间距。当前项目按聊天阅读场景选择三档参数，并非复制某个产品的完整规范。[Spectrum Tabs 的 Density 说明](https://spectrum.adobe.com/page/tabs/)

基础间距尺度与组件使用方式分开维护，避免一个空间数字同时作为图标尺寸和布局间距时被全局缩放。这也符合 Spectrum 将间距值和平台尺度分开处理的思路。[Spectrum Spacing](https://spectrum.adobe.com/page/spacing/)

偏好窗口本身保持固定间距，三档使用静态的小型间距示意图。选择时窗口和选项位置不跳动；短屏允许窗口内部滚动。它使用原生单选组，支持方向键选择、Tab 导航以及 Escape 关闭并恢复焦点。

## 令牌与范围

`src/styles/tokens.css` 保留原有基础 `--space-*`，增加独立的 `--density-*` 语义间距层。默认值定义在 `:root`，紧凑和宽松通过 `:root[data-density]` 覆盖；这些选择器不覆盖字体、颜色、图标或控件高度。

以下像素值以浏览器根字号 16px 计，实际令牌使用 rem：

| 语义角色             | 紧凑 | 适中 | 宽松 |
| -------------------- | ---: | ---: | ---: |
| 桌面消息间隔         |   24 |   36 |   48 |
| 手机消息间隔         |   16 |   24 |   32 |
| 正文段落间隔         |   12 |   16 |   20 |
| 列表项上下间距       |    4 |    6 |    8 |
| 桌面输入区主内边距   |   12 |   18 |   24 |
| 菜单选项上下内边距   |    6 |    8 |   12 |
| 表格单元格上下内边距 |    4 |    8 |   12 |
| 引用卡片正文内边距   |   10 |   14 |   18 |

范围包括欢迎卡片、侧栏对话列表、消息列表、活动过程、Markdown 标题/段落/列表/表格/代码、输入区、下拉菜单、引用卡片及模型设置面板。基础控件字号、图标、内联引用标签、浮层安全边距、阅读宽度和移动端安全区不参与密度缩放。

新增组件时按职责选用间距角色；例如消息间隔使用 `--density-gap-message`，弹层正文使用 `--density-inset-popover`。不为密度生成另一套 JSX，不把密度判断散落到业务组件，也不使用页面 zoom、transform 缩放或修改根字号。

`tests/architecture/styles.test.mjs` 限制密度令牌只能用于 gap、padding、margin，阻止后续误用于字体和尺寸属性；同时限制根节点的密度覆盖只能声明密度令牌。

## 状态与兼容

- `src/preferences/settings.ts` 定义 `DensityPreference` 和合法值；沿用 v1 存储格式添加字段。缺失或非法 density 回退适中，原有合法语言和主题继续保留。
- `src/preferences/browser.ts` 设置 `html[data-density]`，启动脚本和运行时共用同一份偏好解析逻辑。
- `PreferencesProvider` 复用已有保存、失败提示和 storage 事件同步；切换不更新会话 key，也不取消模型请求。
- CSS 变化由已有阅读跟随逻辑处理：正在跟随时保持底部，主动上滚后不会因为密度变化强制回到底部。
- `useAutosizeTextarea` 观察可用宽度变化，对同一份草稿重新测量高度；只对宽度变化响应，避免自身写入高度造成观察循环。

## 验证

`tests/e2e/density.spec.ts` 对实际 DOM 尺寸进行验证，覆盖三档间距递增、字号/行高/阅读宽度稳定、控件最小高度、偏好窗口位置稳定、刷新恢复、生成中切换、历史阅读保护、320px 英文窄屏、菜单边界及草稿重新换行。

既有 `preferences.spec.ts` 补充密度跨标签页同步、删除恢复、存储禁止时仍可操作和 React 主脚本加载前应用密度。纯函数测试覆盖旧偏好兼容和非法值回退。

测试使用隔离服务和模拟数据，完整结果见 [最新验收记录](试岗交付说明.md#四实际验收记录)。浏览器验证覆盖 Chrome 桌面和手机视口；尚未进行 Safari、Firefox 或移动真机验证。
