# 多语言与主题

从侧栏左下角“用户设置 → 语言与外观”打开偏好设置。侧栏收起或使用手机时，先通过左上角按钮展开侧栏。支持简体中文、English，以及浅色、深色、跟随系统三种外观。偏好立即应用，不需要刷新或点击确认保存；“完成”关闭窗口。

偏好设置同时提供紧凑、适中、宽松三档布局密度，与语言和配色分别保存。旧版偏好缺少 density 字段时，补为适中，保留原有语言和主题。密度的令牌、范围与验证见 [布局密度](布局密度.md)。

## 使用规则

- 首次访问按浏览器语言列表选择第一个支持的中英文语言，地区变体归并到 `zh-CN` 或 `en`；没有匹配语言时使用简体中文。
- 默认主题为跟随系统；监听系统配色变化。手动选择浅色或深色后，不受系统切换影响。
- 当前浏览器通过 `zhixu.preferences.v1` 保存偏好，版本、语言和主题均做校验；损坏或未知版本数据回退到默认值。同源标签页通过 storage 事件同步。
- 存储被禁止或写入失败时，当前页面仍能切换，并在偏好窗口提示可能无法在刷新后恢复。
- 切换语言仅影响界面文案、无障碍名称、页面标题和描述。用户消息、历史标题、模型正文、推理原文、代码、工具事件内容与来源资料保持原样；本地附件仍回放原始中文内容。
- 语言和主题变化不更换会话组件的 key，不重启请求；输入草稿、流式任务和消息内容继续保留。欢迎页不参与消息的自动跟随，避免英文排版高度变化把页面滚到底部。

## 职责分工

| 入口                                           | 职责                                             |
| ---------------------------------------------- | ------------------------------------------------ |
| `src/i18n/catalog.ts`                          | 中英文文案与语义 key；中文键集合约束英文完整性   |
| `src/i18n/translate.ts`                        | 类型安全的参数插值与翻译函数，不包含浏览器副作用 |
| `src/i18n/useI18n.tsx`                         | React 翻译上下文，展示组件订阅当前语言           |
| `src/i18n/notices.ts`                          | 现有应用错误字符串的兼容翻译；未知诊断保留原文   |
| `src/preferences/settings.ts`                  | 默认语言、偏好解析、主题决策等纯函数             |
| `src/preferences/browser.ts`                   | 存储读写、根节点属性同步                         |
| `src/preferences/PreferencesProvider.tsx`      | 偏好状态、系统与跨标签页监听、页面元信息更新     |
| `src/preferences/PreferencesDialog.tsx`        | 受控窗口，使用原生 radio 和 dialog 提供键盘操作  |
| `src/preferences/PreferencesDialog.module.css` | 窗口布局、状态、焦点与手机尺寸适配               |
| `src/styles/tokens.css`                        | 默认浅色令牌和深色语义令牌覆盖                   |
| `src/preferences/bootstrap.ts`                 | 复用解析逻辑，在应用启动前应用已保存偏好         |
| `scripts/vite/preferences-bootstrap.ts`        | 构建为小型同步脚本，注入 HTML head 起始位置      |

语言是纯展示依赖，聊天 reducer 与模型服务不读取浏览器语言。Markdown 自定义组件仍在模块级声明，通过上下文获得新文案，避免每次切换重建组件类型和丢失引用页码。

当前两种语言、少量静态界面文案使用类型化字典，不新增国际化包。插值替换不解析 HTML，也不会再次解释参数中的花括号。错误兼容适配集中在独立文件；后续如果扩展后端错误协议，应优先引入稳定错误码和参数，逐步替代中文字符串匹配。

## 维护方法

新增文案在 `catalog.ts` 中添加语义 key，例如 `preferences.title`；组件使用 `t("preferences.title")`。包含参数的文案使用 `{name}`，调用时传入同名参数。TypeScript 检查键与必需参数，单测检查两种语言的键和占位符一致。来源正文等外部数据不放入界面字典。

新增语言需同时更新 Locale 类型、字典集合、偏好校验与语言选择项。当前复数只处理界面需要的英文单数/复数；未来支持复杂复数、日期或数量格式时，应引入标准国际化格式能力并补充相应测试。

主题统一使用 `html[data-theme]`。组件通过 `--surface`、`--text-primary`、`--border` 等语义令牌取色；深色主题覆盖背景、文字、边框、状态、代码高亮及阴影，保留现有字号与布局令牌。新增视觉值遵循既有样式守卫，不在 TSX 写颜色或按主题拼内联样式。

`color-scheme` 同步到浏览器原生控件。偏好引导脚本位于 React 模块前，避免已保存的深色主题等到应用启动后才生效。部署若增加严格 CSP，应为该同步脚本配置 nonce 或构建产物 hash；当前项目未配置 CSP。

## 验证

`npm run check` 包括偏好解析、主题组合、字典完整性、插值、错误适配，以及公共模块不得依赖具体业务的边界检查。

`tests/e2e/preferences.spec.ts` 覆盖：

| 编号         | 场景                                                            |
| ------------ | --------------------------------------------------------------- |
| PREF-UI      | 双向切换语言与主题、草稿保留、英文模型设置、刷新恢复、深色菜单  |
| PREF-SYSTEM  | 系统实时切换、手动覆盖、多标签页同步、删除存储恢复默认          |
| PREF-STORAGE | 浏览器禁止存储时仍可操作，保存失败提示随语言变化                |
| PREF-BOOT    | 主应用脚本未加载时已应用偏好；损坏存储不会阻止启动              |
| PREF-STREAM  | 生成中切换不取消或重复请求，原始正文/推理/代码/引用保持可用     |
| PREF-MOBILE  | 320px 窄屏、radio 键盘操作、Escape 关闭并恢复焦点、英文错误提示 |
| PREF-LOCALE  | 首次访问按浏览器英文偏好初始化                                  |

完整回归同时验证流式、滚动、引用、复制与停止逻辑，结果见 [最新验收记录](试岗交付说明.md#四实际验收记录)。浏览器测试使用隔离服务与模拟数据，覆盖 Chrome 桌面和手机视口；尚未进行 Safari、Firefox 或移动真机验证。

浏览器机制参考：[matchMedia](https://developer.mozilla.org/en-US/docs/Web/API/Window/matchMedia)、[color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color-scheme)。
