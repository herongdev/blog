# 模型选择与能力

输入框右下角始终显示统一模型入口。菜单按本地样例、DeepSeek、阿里云百炼分组，直接选择具体模型；顶部不再重复展示数据来源选择器。

本地模式的菜单下方提供回放速度（1×、1.5×、2×、3×、4×）及演示场景，按钮显示当前回放速度。回放速度只影响固定 JSON 的播放间隔，不影响 API 生成速度。默认仍为原附件问答；异常和空结果用于人工验收。

模型列表来自服务端公开配置，不含密钥。未配置的服务仍可选择，发送时进入模型设置。空会话切换模型保留草稿及待发送附件；已有消息时沿用原有策略，开启新会话。生成期间禁止切换。

深度思考默认关闭，首次打开或刷新页面均从关闭状态开始；手动开启后，本次使用期间的新建会话和模型切换保留该选择。入口位于输入框「＋」工具菜单，与添加附件并列。开启后工具栏显示可关闭的状态标签，窄屏保留图标与无障碍名称；已关闭时可从「＋」重新开启。生成期间锁定工具菜单与状态标签。模型菜单不再承载思考开关。

## 能力边界

`shared/contracts/modelCapabilities.ts` 集中管理已核实的思考开关能力，界面与服务端适配共用。当前覆盖默认的 DeepSeek V4 Flash、Pro、实验视觉模型，以及百炼 Qwen Plus、Flash、Qwen3 VL Plus/Flash；自定义或未核实的版本默认不显示开关，也不向上游发送思考参数，让模型使用自身默认行为。

本次仅提供深度思考开关，不提供思考强度档位。没有接入独立加速参数，因此不展示“开启加速”。关闭思考与加速服务是不同功能。

核实日期：2026-09-04。新增模型时应核实具体模型与接口，补充能力表和适配测试。

## 验证

`tests/e2e/select.spec.ts` 覆盖统一选择入口、键盘导航、回放参数、窗口变化和生成锁定；`tests/e2e/composer.spec.ts` 验证模型与思考设置随模拟请求发送。`tests/integration/model-capabilities.test.ts` 验证未知模型不收到不支持的上游参数。测试不调用真实模型。
