# 试岗交付说明

本项目对应《前端试岗任务书》的 AI 对话页面。验收主线使用原附件数据，覆盖消息、流式输出、Markdown、引用、停止、异常、组件设计和活动过程；真实模型接入作为已有扩展。

## 交付范围速览

**任务书要求已实现**：用户／模型消息区分、自然滚动、流式输出、常见 Markdown、正文引用占位符转换与多来源切换、主动停止、加载／失败／空结果状态、组件拆分，以及思考和工具调用的活动过程。验收使用原始附件 JSON，详细对应关系见 [任务书验收对照](任务书验收对照.md)。

| 额外完成         | 交付内容与用途                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 前后端与多模型   | React + TypeScript 前端、NestJS 后端；本地 JSON、百炼、DeepSeek 统一事件适配；密钥仅由服务端使用，按模型能力提供思考开关，默认关闭     |
| 图片与文本附件   | 图片拖拽、粘贴、缩略图预览和视觉模型问答；TXT／Markdown／JSON 文本附件；不支持的入口提前禁用并解释，模型切换保留已有附件               |
| 聊天管理         | IndexedDB 历史与草稿恢复、搜索、归档、导出及项目分组；项目独立展开／收起，名称右侧“＋”新建聊天，当前聊天单独高亮，侧栏显示后台生成状态 |
| 个性化与可访问性 | 中英文、浅色／深色／跟随系统、紧凑／适中／宽松密度；键盘访问、焦点恢复、窄屏布局与减少动态效果适配                                     |
| 工程与回归       | 组件、逻辑与样式分离；共享类型协议、设计令牌、模块依赖约束；覆盖请求取消与迟到结果、引用交互状态、历史读取竞态等边界                   |
| 部署交付         | Docker 多阶段构建、Compose、健康检查、资源限制、日志轮转、镜像发布与回滚；线上 Nginx、HTTPS 与证书自动续期                             |

上述扩展不替代原题验收：本地 JSON 是固定回放；真实模型按用户输入回答，普通 API 聊天不伪造搜索、工具或来源。图片理解需要视觉模型。历史保存于当前浏览器，当前不含账户体系或跨设备同步。

源码 ZIP 包含运行代码、依赖锁文件、原题样例、测试、部署配置、第三方许可证和必要说明；不含 Git 历史、真实密钥、个人聊天数据、依赖目录、构建产物及课程资料。接收方解压后从 README 开始，本地 JSON 演示不需要密钥。在线体验：[chat.herong.info](https://chat.herong.info)。

## 一、先运行原题

Node.js 22.12+，在包含 package.json 的目录执行：

```bash
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`，数据来源保持“本地样例”。这条路径不需要 API Key，不请求外部模型。首次安装依赖需要网络。结束服务按 Ctrl+C。

生产构建使用 `npm run build`，停止开发服务后运行 `npm start`，打开 `http://127.0.0.1:3001`。生产入口从运行环境读取配置。容器交付包括本机回环入口、Caddy HTTPS / 共享口令入口、健康检查与镜像发布回滚，步骤见 [容器部署与发布恢复](容器部署.md)。

## 二、三分钟验收顺序

| 顺序                | 操作                                                          | 应观察的结果                                                             |
| ------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1 · 完整回答        | 点击首页“甲硝唑是什么？”，等待完成                            | 两段思考、一次工具调用、正文逐步出现，结束后退出生成状态                 |
| 2 · 资料对应        | 展开活动过程；打开正文含 +1 的引用并翻页                      | 思考和工具可读；来源标题、摘要、域名、原文链接与附件对应，页码前后有边界 |
| 3 · 停止与恢复      | 再次生成时先写下一条草稿，再点停止；之后主动发送              | 草稿保留、不自动提交；旧消息终止，新回答独立运行                         |
| 4 · 异常与空结果    | 切换“异常恢复”“空结果”；异常后切回正常场景再重新生成          | 已收到正文保留，有明确反馈，重试不重复插入用户问题                       |
| 5 · Markdown 与阅读 | 切换 Markdown 演示，查看代码/表格；生成中向上阅读，再回到最新 | 长内容局部滚动，复制保留原文；阅读历史时不被强制拉到底部                 |

演示过程中不需要打开模型配置。原始附件是固定回放，自定义提问不会改变附件答案；只有真实模型路径才根据输入生成新答案。

补充演示：生成中写草稿，切换其他会话再返回；尚未发送过消息的草稿也能从侧栏找回。远程错误可展开“问题详情”复制请求编号，关联服务端日志。详见 [请求诊断与草稿](请求诊断与草稿.md)。

一个有代表性的缺陷是“停止时已有草稿被误提交”：停止切换按钮状态后，浏览器仍可能执行该次点击的默认表单动作。当前先取消默认动作，再停止请求；浏览器回归同时检查草稿、请求数量和按钮状态。详见 [原题缺陷记录](任务书验收对照.md#停止时草稿误提交的修复)。

选择现有库时保留来源、许可证和本地修改记录；状态、附件适配及业务规则由项目表达。详见 [开源源码说明](../third_party/README.md)。

## 五、范围与后续接口约定

- 会话保存在当前浏览器 IndexedDB，支持刷新恢复；当前没有登录、服务端历史数据库或公网用户隔离。
- 来源与工具过程在附件路径中回放；普通真实模型聊天不伪造搜索和引用。
- 引用高亮按段落或列表项关联；原效果图未给出字符区间，当前没有推测更精细的范围。
- 各聊天独立生成，同一聊天只允许一个任务；切换聊天不取消其他任务，停止／归档／删除仅作用于目标聊天。刷新或关闭网页会中断连接，已收到内容可恢复；并发受服务端上限约束。
- 当前先稳定满足题目提供的数据规模。真实业务接入时再确认新协议、来源字段、历史保存和用户权限要求。

这些边界与实现一起交付，便于后续评审和接入。
