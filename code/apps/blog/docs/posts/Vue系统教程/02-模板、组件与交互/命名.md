# 命名

> 本节目标：理解“命名”的核心思路，并能把它用于实际开发或面试表达。
**命名规范：**

- ==直接在== `DOM` ==中使用一个组件时，强烈推荐遵循==

    ```
    W3C
    ```

    ==规范====中的自定义组件名：==
    - ==字母全小写且必须包含一个连字符。==
    - ==这会帮助你避免和当前以及未来的== `HTML` ==元素相冲突。==
- ==在字符串模板或====单文件组件==中可以使用`PascalCase`==大==驼峰写法
- ==可以在====风格指南====中查阅到关于组件名的其它建议。==

**方式**
==一、使用==

```
 kebab-case (
```

==短横线分隔命名==`)`==。==

```
Vue.component('my-component-name', { /* ... */ })
```
 ==引用时也必须使用== `kebab-case`==，例如== `\<my-component-name\>`==。==

==二、使用== `PascalCase`==。==

```
Vue.component('MyComponentName', { /* ... */ })
```
 ==引用时两种命名法都可以使用。==
==也就是说== `\<my-component-name\>` ==和== `\<MyComponentName\>` ==都是可接受的。==

**注意**==：尽管如此，直接在== `DOM (`==即非字符串的模板==`)` ==中使用时只有== `kebab-case` ==是有效的。==
