# 指令

> 本节目标：理解“指令”的核心思路，并能把它用于实际开发或面试表达。
指令带有前缀 `v-`，以表示它们是 `Vue` 提供的特殊 `attribute`。
它们会在渲染的 `DOM` 上应用特殊的响应式行为。

比如：

```
<span v-bind:title="message">
```

鼠标悬停几秒钟查看此处动态绑定的提示信息！

```
 </span>
```
 上例指令的意思是：“将这个元素节点的 `title` `attribute` 和 `Vue` 实例的 `message` `property` 保持一致”。
