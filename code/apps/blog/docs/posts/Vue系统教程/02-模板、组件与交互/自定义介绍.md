# 自定义介绍

> 本节目标：理解“自定义介绍”的核心思路，并能把它用于实际开发或面试表达。
自定义指令中包含了几个生命周期，vue2和vue3不同；
每个生命周期函数会传入一些参数值，有：

- el当前元素dom；
- binding自定义指令传递进来的信息，比如v-focus:foo.bar="1+1"，这里有就：
    - name：focus
    - value和oldValue：2
    - expression：1+1
    - arg：foo
    - modifiers: bar
- vnode: 被绑定元素的虚拟dom；
- oldVnode：上一个虚拟节点；

**参数传入**
动态参数：其中的参数arg支持动态的；还来更强大的功能，通过动态参数实现有区别的功能；

**多个值传入**
通过对象字面量传入多个参数；
