# 插槽默认值

> 本节目标：理解“插槽默认值”的核心思路，并能把它用于实际开发或面试表达。
==插槽的默认值只会在没有提供内容的时候被渲染，有内容则以传递的内容为准。==
==插槽的默认值写在==`\<slot\>`==的开始和结束标签之间；==
==例如：==

```
<button type="submit">  <slot>Submit</slot></button>
```
