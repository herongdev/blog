# 编译作用域

> 本节目标：理解“编译作用域”的核心思路，并能把它用于实际开发或面试表达。
==当我们在给某组件的插槽传递内容时，我们会把要传递的内容写在组件的开始和结束标签之间，====这些准备传递的内容可以访问组件使用时所在实例的作用域，而====不能====访问组件自身的作用域。如：==

```
<navigation-link url="/profile">  Logged in as {{ user.name }}</navigation-link>
<navigation-link url="/profile">  Clicking here will send you to: {{ url }}  <!--
```

==这里的== `` `url` `` ==会是== `undefined`==，因为这块内容是==

```

```

==传递给== `\<navigation-link\>` ==的，而不是==

```

```

==在== `\<navigation-link\>` ==组件内部定义的，所以无法访问组件内部变量。==

```
  --></navigation-link>
```
 ==注意：====父级模板里的所有内容都是在父级作用域中编译的；子模板里的所有内容都是在子作用域中编译的。==
