# 绑定内联样式

> 本节目标：理解“绑定内联样式”的核心思路，并能把它用于实际开发或面试表达。
**对象语法**
`v-bind:style` 的对象语法：

- 赋值为一个 `JavaScript` 对象（看着非常像 CSS）。
- `CSS property` 名可以用驼峰式 `(camelCase)` 或短横线分隔 `(kebab-case`，要用引号括起来`)` 来命名。
- 推荐用法：直接绑定到一个样式对象通常更好，这会让模板更清晰。（例2）
- 推荐用法：赋值为返回对象的计算属性。

如：

```
<div v-bind:style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>
data: {  activeColor: 'red',  fontSize: 30}
```
 例`2`：

```
<div v-bind:style="styleObject"></div>
data: {  styleObject: {    color: 'red',    fontSize: '13px'  }}
```

**数组语法**
`v-bind:style` 的数组语法：
每个数组成员都是一个样式对象。

```
<div v-bind:style="[baseStyles, overridingStyles]"></div>
```

**其它**
**自动添加前缀：**当 `v-bind:style` 使用需要添加[浏览器引擎前缀](https://developer.mozilla.org/zh-CN/docs/Glossary/Vendor_Prefix)的 `CSS property` 时，如 `transform`，`Vue.js` 会自动侦测并添加相应的前缀。

**多重值**
`2.3.0+`
从 `2.3.0` 起你可以为 `style` 绑定中的 `css property` 提供一个包含多个值的数组，常用于提供多个带前缀的值，例如：

```
<div :style="{ display: ['-webkit-box', '-ms-flexbox', 'flex'] }"></div>
```
 这样写只会渲染数组中最后一个被浏览器支持的值。在本例中，如果浏览器支持不带浏览器前缀的 `flexbox`，那么就只会渲染 `display: flex`。
