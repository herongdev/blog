# 用在自定义组件上

> 本节目标：理解“用在自定义组件上”的核心思路，并能把它用于实际开发或面试表达。
在自定义组件上使用 `class` `property`，包括使用v-bind:`class`绑定的样式时：

- 这些 `class` 将被添加到该组件的根元素上面。
- 且根元素上已经存在的 `class` 不会被覆盖。

```
<my-component v-bind:class="{ active: isActive }"></my-component>
```
 当 `isActive` 为 `truthy` 时，组件的根元素p将被渲染成为：

```
<p class="foo bar active">Hi</p>
```
