# 条件渲染

> 本节目标：理解“条件渲染”的核心思路，并能把它用于实际开发或面试表达。
```
==条件渲染用于控制一个元素是否，如：==
==<div id====="app-3"====>======  ==<p v-if====="seen"====>====现在你看到我了====</p>========</div>==
==var== ==app3 === ==new== ==Vue({======  ==el:== =='#app-3'====,======  ==data: {======    ==seen:== ==true======  ==}========})==
==当====v-if====后的表达式值为真时，====id====为====p====元素显示，否则不显示。==
```
