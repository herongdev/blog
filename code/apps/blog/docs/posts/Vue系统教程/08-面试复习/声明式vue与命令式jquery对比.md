# 声明式vue与命令式jquery对比

> 本节目标：理解“声明式vue与命令式jquery对比”的核心思路，并能把它用于实际开发或面试表达。
==总结就是：====命令式会有操作====dom====的逻辑，声明式基本上是操作数据，由数据去影响视图；==

==Vue====所有的界面事件，都是只去操作数据的，====用数据的变化来改变视图；====Jquery====操作====DOM==

```
==Vue====所有界面的变动，都是根据数据自动绑定出来的，====Jquery====操作====DOM==
```
