# SPA&MPA

> 本节目标：理解“SPA&MPA”的核心思路，并能把它用于实际开发或面试表达。
单页面可以通过tabs实现一个应用；
但实际实现中，对于有地址拦的浏览器，一般是切换tabs或菜单，改变地址栏，从尔显示不同的应用组件。

但对于没有地址栏的app，则会

- tabs切换或菜单
- 或者做成多页面
