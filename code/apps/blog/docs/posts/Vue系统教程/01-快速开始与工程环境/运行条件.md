# 运行条件

> 本节目标：理解“运行条件”的核心思路，并能把它用于实际开发或面试表达。
**一、运行环境要求**
Vue 使用了ECMAScript 5 特性。IE8 及以下版本不支持ES5所以无法运行vue;
其它所有兼容 ECMAScript 5 的浏览器均可运行vue。

```
**二、开发环境要求**
# 查看 node 版本
node -v
# npm 版本
npm -v
```
