# 依赖分析

> 本节目标：理解“依赖分析”的核心思路，并能把它用于实际开发或面试表达。
一、`vue-cli`相关

- 主框架：

    ```
    "@vue/cli": "~4.5.0",
    ```

- 起服务：`@vue/cli-service": "~4.5.0"`

二、`vue`相关，如果是`vue2`，会添加以下生产依赖

```
"vue": "^2.6.11",
"vue-class-component": "^7.2.3",
"vue-property-decorator": "^9.1.2",
```

三、`typescript`

- `"typescript": "~4.1.5",`
- `"@vue/cli-plugin-typescript": "~4.5.0",`

四、`webpack`打包相关
`babel`相关，转换高版本到低版本

- ```
    "core-js": "^3.6.5",
    ```

- `@vue/cli-plugin-babel": "~4.5.0",`

`eslint`相关

- `"eslint": "^6.7.2",`
- `"@vue/cli-plugin-eslint": "~4.5.0",`
- 插件：`"eslint-plugin-import": "^2.20.2",`
- `node`插件：`"eslint-plugin-node": "^11.1.0",`
- 期约插件：`"eslint-plugin-promise": "^4.2.1",`
- 规范插件：`"eslint-plugin-standard": "^4.0.0",`

如果是`vue`框架

- `vue`插件：`"eslint-plugin-vue": "^6.2.2",`
- 配置文件：`"@vue/eslint-config-standard": "^5.1.2",`
- `Vue-cli`插件：
    - `@vue/cli-plugin-eslint": "~4.5.0"`

`eslint`支持`TS`

- 解析器：`"@typescript-eslint/parser": "^4.18.0",`
- 插件：`"@typescript-eslint/eslint-plugin": "^4.18.0",`

如果是使用`ts`编写`vue`单文件

- 配置：`"@vue/eslint-config-typescript": "^7.0.0",`
