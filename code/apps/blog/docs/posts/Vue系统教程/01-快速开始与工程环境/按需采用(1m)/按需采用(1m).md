# 按需采用(1m)

> 本节目标：理解“按需采用(1m)”的核心思路，并能把它用于实际开发或面试表达。
`React` 是一个用于构建用户界面的 `JavaScript` 库。
把数据库中的数据通过网络请求获取到，并在界面中显示出来；
`React` 可被逐步采用的，可**按需引入或多或少的** `React` **特性**。可以：

- 仅体验下 `React`；
- 用它`HTML` 页面增加一点交互；
- 开发一个完全由 `React` 驱动的复杂应用。
