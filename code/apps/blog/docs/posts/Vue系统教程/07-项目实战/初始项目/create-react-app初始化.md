# create-react-app初始化

> 本节目标：理解“create-react-app初始化”的核心思路，并能把它用于实际开发或面试表达。
==首先通过 create-react-app 这个脚手架工具生成项目的初始化化结构。==
==注意: 请保证你的 create-react-app 是最新版本，不然目录结构不会生成。==
==在命令行中输入以下命令:==
==create-react-app cloud-music======
==完成后，根据提示：==
==cd cloud-music======
==启动项目:==
==npm start==
