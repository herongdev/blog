# 双向绑定v-model

> 本节目标：理解“双向绑定v-model”的核心思路，并能把它用于实际开发或面试表达。
方式一：
定义一个响应式的变量；
它的值控制组件的值；
同时它的值也会被组件改变，我们可以watch这个值，进而进行相应操作；

方式二：
定义一个计算属性；
get函数用来计算传递给组件的值；
当组件要改变它的值时，触发set函数，我们可以在set函数中修改get函数中的依赖项的值；这们再次触发get时，自然会是新的值；

方式三：
用父属性来控制这个子组件的v-model的值；
这时，重新定义一个计算属性变量，它从父组件传递的属性来计算出传递给组件的值；
同时，当组件改变了这个值时，会触发set函数，我们在set函数中直接修改父组件传递过来的属性的值；但是要注意的时，如果属性值是一个对象或数组，我们可以修改它的属性，从而影响源对象；但如果属性是一个基本值，我们是无法直拉赋新值的，因为这个属性是只读的，这时，我们可以使用emit把这个值传出去，父组件处理这个事件，改变传递给子组件的属性；
