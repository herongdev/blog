# 更新数据的两种方式

> 本节目标：理解“更新数据的两种方式”的核心思路，并能把它用于实际开发或面试表达。
一、直接替换原引用，watch不用深度watch，可能会引发不必要的渲染，可能的副作用，如果不停地换引用，点击事件获取的当时的数据，在之后不会一直更新；

二、不替换原引用，合并属性；

- watch如果不deep，可能没反应；
- 模板中读取的属性值都会响应式更新；
