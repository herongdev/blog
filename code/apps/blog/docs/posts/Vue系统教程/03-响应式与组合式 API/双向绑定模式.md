# 双向绑定模式

> 本节目标：理解“双向绑定模式”的核心思路，并能把它用于实际开发或面试表达。
一、子组件watch传入的属性，在变化时修改内部的值；
二、当内部自己修改值时，将新值emit等通知给父组件；
三、父组件的值又通过props传入到子组件，子组件又watch到；这时要做一个新旧值对比，如果值相同，中断后面的处理；要不然一直死循环下去了
