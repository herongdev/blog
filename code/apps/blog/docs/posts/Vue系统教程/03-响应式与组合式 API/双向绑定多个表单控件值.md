# 双向绑定多个表单控件值

> 本节目标：理解“双向绑定多个表单控件值”的核心思路，并能把它用于实际开发或面试表达。
双向绑定一般应用在：

- 值保存在父组件，而触发值变化的事件发生在子组件；
- `vue`中使用属性和父组件捕获子组件事件来实现，双向绑定是其中方便的一种；
- `react`使用属性值和值为回调函数的属性来实现，在子组件的事件中，调用父组件传递的回调函数，从而改变父组件中保存的值；

一、通过`v-model`来给组件添加双向绑定；
二、对于`v-model`，认为传入的属性值为`modelValue`，组件内部的会产生`update:modelValue`事件，这个事件会更新`modelValue`的值；
三、我们在组件的内部，将传入的`modelValue`进行响应式解析，并将值传入到具体的表单控件：

```
const props = defineProps<Props>();
const emits = defineEmits(["update:modelValue"]);
const { modelValue } = toRefs(props);
const number0 = toRef(modelValue.value, 0);
const number1 = toRef(modelValue.value, 1);
const number2 = toRef(modelValue.value, 2);
const number3 = toRef(modelValue.value, 3);
```

 此时，已经完成了单向绑定，现在，我们要在任何一个表单控件更新其`v-model`值时，也就是触发其`change`事件时，触发一个`update:modelValue`事件，将传入的`modelValue`值进行更新，从而完成双向绑定；
四、我们采用的方法是`watch`这四个控件的`v-model`值，当任意一个值发生变化时，触发`update:modelValue`方法，将新值传到父级，而父级又通过`modelValue`变量回显我们表单控件的值：

```
watch([number0, number1, number2, number3], (newValue) => {
```

```
 emits("update:modelValue", newValue);
});
```
 完成双向绑定；

此外，还可以在组件上使用多个`v-mode:xxx`来实现多个表单控件的双向绑定，只是要定义的变量较多，可以视实际需求选用；
