# 表单数据一直无法重置

> 本节目标：理解“表单数据一直无法重置”的核心思路，并能把它用于实际开发或面试表达。

你的分析是正确的！由于 Vue 的响应式系统，你从外部模块导入的 countryConstructionReportList 被引用后，当你在表单中修改其值时，这些修改会直接影响到导入的初始数据。之后，当你再次进入页面并在 created 钩子中将这个已经被修改的数据重新赋值给表单时，表单会显示上次修改后的数据，而不是初始的默认值。

解决方案
为了避免这个问题，你需要确保每次进入页面时，表单的数据都是从一个未被修改的初始状态开始。可以通过以下几种方法来解决这个问题：

1. 使用 lodash 的 cloneDeep 进行深拷贝
在将初始数据赋值给表单数据时，使用 lodash 的 cloneDeep 方法创建一个深拷贝，确保每次都得到一个新的对象实例，而不是对原始数据的引用。
import cloneDeep from 'lodash/cloneDeep';
created() \{
this.editPigStatusForm.constrInfoList = cloneDeep(countryConstructionReportList);
\},
这种方式可以确保 countryConstructionReportList 的初始值不会因为表单数据的修改而被改变，每次进入页面时，都会重新创建一个干净的、未被修改的初始数据对象。

2. 在外部模块中使用工厂函数返回初始数据
