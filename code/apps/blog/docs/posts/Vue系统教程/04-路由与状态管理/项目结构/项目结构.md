# 项目结构

> 本节目标：理解“项目结构”的核心思路，并能把它用于实际开发或面试表达。
`Vuex` 并不限制你的代码结构。但是，它规定了一些需要遵守的规则：

1. 单一store：应用层级的状态应该集中到单个 `store` 对象中。
2. 更改状态：只能mutation更改状态，并且这个过程是同步的。
3. 异步：异步逻辑都应该封装到 `action` 里面。

只要你遵守以上规则，如何组织代码随你便。如果你的 `store` 文件太大，只需将 `action`、`mutation` 和 `getter` 分割到单独的文件。
