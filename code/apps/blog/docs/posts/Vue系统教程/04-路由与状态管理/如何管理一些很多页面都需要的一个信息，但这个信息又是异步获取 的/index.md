# 如何管理一些很多页面都需要的一个信息，但这个信息又是异步获取 的

> 本节目标：理解“如何管理一些很多页面都需要的一个信息，但这个信息又是异步获取 的”的核心思路，并能把它用于实际开发或面试表达。
在我的项目中，当前选中账户非常重要，很多请求都依赖其中的信息，如果 没有这些信息，请求发送的参数就会缺失，然后获取到的数据 就不准确，最佳的做法是什么、
 \> 来自 \<[https://chat.deepseek.com/a/chat/s/d8561a95-b74a-4ed4-8bbd-6575d9c37470](https://chat.deepseek.com/a/chat/s/d8561a95-b74a-4ed4-8bbd-6575d9c37470)\>

思路：
一、在组件根上进行判断
二、将这个信息放在根组件，向下面传递provide,inject
三、有路由的钩子中处理，进入页面前先进行判断，如果没有，页面加载，有了进入页面；
