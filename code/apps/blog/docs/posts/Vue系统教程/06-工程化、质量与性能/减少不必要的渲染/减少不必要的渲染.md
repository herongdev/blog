# 减少不必要的渲染

> 本节目标：理解“减少不必要的渲染”的核心思路，并能把它用于实际开发或面试表达。
```
react渲染可能引起的问题：
```

父组件更新了，子组件接受的属性虽然没有更新，但也会调用Render方法，虽然由于diff算法的存在，不一定会引起dom渲染；

子组件接受的属性确定变化了，但这些变化的属性，子组件在根据没有用到；

子组件接受属性中，一些事件的回调方法不影响渲染，不应该引起组件render调用；

传给子组件的派生状态或方法是一个新引用，也就是内存地址发生了变化，在purComponent或React.Memo优化中，会认为属性值发生了变化，引起优化失效；

:::
