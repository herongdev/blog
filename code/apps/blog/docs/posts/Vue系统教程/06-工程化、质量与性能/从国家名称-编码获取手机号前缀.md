# 从国家名称-编码获取手机号前缀

> 本节目标：理解“从国家名称-编码获取手机号前缀”的核心思路，并能把它用于实际开发或面试表达。
==以下是关于 ​==**从国家名称/编码获取手机号前缀（国际电话区号）​** ==的解决方案，结合 npm 包和 API 推荐：==

**​****1. 使用 libphonenumber-js（推荐）​**
**功能**==：解析国家代码对应的国际电话区号（如== ==Afghanistan → +93====），支持反向查找。==
**安装**==：==

==bash==
==复制==
==npm== ==install== ==libphonenumber-js==
**​****代码示例**

==javascript==
==复制==
==import== ==\{ getCountryCallingCode \}== ==from== =='libphonenumber-js/mobile'====;======
_// 根据国家编码获取电话前缀_======const== ==phonePrefix== ===== ==getCountryCallingCode====(===='AF'====);== _// 返回 "93"（阿富汗）_======console====.====log====(====`+====${phonePrefix}====`====);== _// +93_====
_// 结合国家名称使用（需先通过国家名查编码）_======import== ==\{ countries \}== ==from== =='country-code-lookup'====;========const== ==countryName== ===== =="Afghanistan"====;========const== ==countryCode== ===== ==countries.====find====(c== ===\>== ==c.country== ======= ==countryName)====?.====iso2;========const== ==prefix== ===== ==countryCode== ==?== ==`+====${====getCountryCallingCode====(countryCode)}====`== ==:== ==null====;==

**​****2. 使用 google-libphonenumber（官方库的封装）​**
**功能**==：谷歌官方电话库的 Node.js 适配，功能更全面但体积较大。==
**安装**==：==

==bash==
==复制==
==npm== ==install== ==google-libphonenumber==
**​****代码示例**

==javascript==
==复制==
==const== ==libphonenumber== ===== ==require====(===='google-libphonenumber'====);========const== ==phoneUtil== ===== ==libphonenumber.PhoneNumberUtil.====getInstance====();======
_// 获取国家区号_======const== ==countryCode== ===== =='US'====;== _// 美国_======const== ==prefix== ===== ==phoneUtil.====getCountryCodeForRegion====(countryCode);== _// 返回 1_======console====.====log====(====`+====${prefix}====`====);==

**​****3. 使用 country-telephone-data（轻量级数据）​**
**功能**==：直接提供国家编码、电话前缀、格式等数据的 JSON 文件。==
**安装**==：==

==bash==
==复制==
==npm== ==install== ==country-telephone-data==
**​****代码示例**

==javascript==
==复制==
==import== ==\{ allCountries \}== ==from== =='country-telephone-data'====;======
==const== ==countryName== ===== =="Afghanistan"====;========const== ==countryData== ===== ==allCountries.====find====(c== ===\>== ==c.name== ======= ==countryName);========if== ==(countryData) \{====== ==console====.====log====(====`+====${countryData.dialCode}====`====);== _// +93_======\}==

_// 查找阿富汗_======const== ==afghanistan== ===== ==extendedCountries.====find====(c== ===\>== ==c.country== ======= =="Afghanistan"====);========console====.====log====(afghanistan====?.====phonePrefix);== _// +93_

**​****5. 免费 API 方案（实时数据）​**
