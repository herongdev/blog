# 错误边界应该放置在哪？

> 本节目标：理解“错误边界应该放置在哪？”的核心思路，并能把它用于实际开发或面试表达。
错误边界的粒度由你来决定：

- 可以将其包装在最顶层的路由组件并为用户展示一个 “`Something went wrong`” 的错误信息，就像服务端框架经常处理崩溃一样。
- 你也可以将单独的部件包装在错误边界以保护应用其他部分不崩溃。
