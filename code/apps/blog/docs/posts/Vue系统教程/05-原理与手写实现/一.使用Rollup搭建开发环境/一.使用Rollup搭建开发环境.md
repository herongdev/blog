# 一.使用Rollup搭建开发环境

> 本节目标：理解“一.使用Rollup搭建开发环境”的核心思路，并能把它用于实际开发或面试表达。
**什么是****Rollup?**
_Rollup_ 是一个 JavaScript 模块打包器,可以将小块代码编译成大块复杂的代码；
rollup.js更专注于Javascript类库打包 （开发应用时使用Webpack，开发库时使用Rollup）；
