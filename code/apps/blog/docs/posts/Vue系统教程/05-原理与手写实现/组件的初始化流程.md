# 组件的初始化流程

> 本节目标：理解“组件的初始化流程”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
全局组件和局部组件

全局组件：使用Vue.component创建的组件，可以在整个应用中使用；比如创建了很多个Vue实例，可以在它们中直接使用全局组件；

局部组件：在new Vue()实例时，在实例中使用components定义的组件，则只能在这个Vue实例中使用；

局部组件优先级高于全局组件，即优先使用局部组件，再选择使用全局组件；这是一个类似于作用域链的查找机制，局部组件并不会覆盖全局组件；

每次调用vue.component()时，实际际在内部调用vue.extend();

- Vue.extend方法内部的主要逻辑是创建一个子类，这个子类继承了vue；
- 然后把vue上的options合并到子类上；
- 最后，返回这个子类；

所以我们可以利用vue.extend返回的子类来创建实例，这个实例继承可以调用vue上的所有方法。
