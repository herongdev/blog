# 最后给一个最短记忆版

> 本节目标：理解“最后给一个最短记忆版”的核心思路，并能把它用于实际开发或面试表达。
你可以把浏览器缓存记成 6 句话：

1. **存不存**：看 no-store / private / public。(**MDN Web Docs**)
2. **多久 fresh**：看 max-age，没有再看 Expires，再没有才可能启发式缓存。(**RFC Editor**)
3. **过期后怎么确认**：看 ETag / Last-Modified。(**MDN Web Docs**)
4. **同 URL 能不能复用同一份**：看 Vary。(**MDN Web Docs**)
5. **这次请求有没有强行改规则**：看请求头 Cache-Control 和 fetch(..., \{ cache \})。(**MDN Web Docs**)
6. **别忘了还有 bfcache 和 Service Worker**：它们可能让你根本没走普通 HTTP cache。(**MDN Web Docs**)
