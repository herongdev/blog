# 数组

> 本节目标：理解“数组”的核心思路，并能把它用于实际开发或面试表达。
**寻址容易，插入和删除困难（数组）**

- **寻址容易**：数组可以通过索引快速访问任意元素。例如，要访问数组的第 5 个元素，可以通过 array[4] 直接访问，时间复杂度为 O(1)。
- **插入和删除困难**：在数组中插入或删除元素需要移动元素。例如，在数组中插入一个新元素到第 3 个位置，必须将第 3 个位置及之后的所有元素向后移动一位。
