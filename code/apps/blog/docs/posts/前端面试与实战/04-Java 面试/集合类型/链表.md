# 链表

> 本节目标：理解“链表”的核心思路，并能把它用于实际开发或面试表达。
**寻址困难，但插入和删除容易（链表）**

- **寻址困难**：链表需要从头遍历，查找元素时间复杂度为 O(n)。
- **插入和删除容易**：在链表中插入或删除元素只需调整指针，不需要移动其他元素。
