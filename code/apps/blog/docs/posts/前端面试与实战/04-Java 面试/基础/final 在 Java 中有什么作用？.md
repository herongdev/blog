# final 在 Java 中有什么作用？

> 本节目标：理解“final 在 Java 中有什么作用？”的核心思路，并能把它用于实际开发或面试表达。
- **修饰变量**：
    - 基本数据类型：值无法修改。
    - 引用数据类型：对象或数组本身可以修改，但指向该对象或数组的引用不能修改。类的成员变量必须当场赋值，否则编译报错。
- **修饰方法**：方法无法被子类重写，但可以被继承。
- **修饰类**：类无法被继承。例如，String 类就是一个最终类。
