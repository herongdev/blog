# HJ107 求解立方根

> 本节目标：理解“HJ107 求解立方根”的核心思路，并能把它用于实际开发或面试表达。
中等  通过率：26.70%  时间限制：1秒  空间限制：32M
知识点==基础数学====二分==
**描述**
计算一个浮点数的立方根，不使用库函数。
保留一位小数。

数据范围：∣���∣≤20 ∣_val_∣≤20
**输入描述：**
待求解参数，为double类型（一个实数）
**输出描述：**
输出参数的立方根。保留一位小数。
**示例1**
输入：
19.9
==复制==
输出：
2.7
==复制==
**示例2**
输入：
2.7
==复制==
输出：
1.4

牛顿迭代法
while True:
try:
a = float(input().strip()) # 获取输入的实数a
e = 0.0001 # 设定一个精度值
t = a # 初始化立方根t的值为输入的值a
while abs(t*t*t - a) \> e: # 差值没有达到精度，便一直更新立方根
# x(i+1) = x(i) - f(xi)/f'(xi)
# 更新后的x = 原x - (原x的立方-a)/f(原x)导数
t = t - (t*t*t - a) * 1.0 / (3 * t*t)
print("%.1f" % t) # 当精度达到要求时，此时的立方根t便为输入实数的立方根解
except:
break

二分法
while True:
try:
# 输入待求立方根的数
a = float(input().strip())
# 设置精度值，用于判断当前的解是否足够接近真实立方根
epsilon = 0.0001
# 设置查找的初始范围。如果a是负数，查找范围是[a, 0]；如果a是正数或0，查找范围是[0, a]或[1, a]（如果a大于1）
low = min(-1.0, a)
high = max(1.0, a)
# 计算中间值
ans = (low + high) / 2
# 当当前解的立方与目标值a的差的绝对值大于epsilon时，继续查找
while abs(ans**3 - a) \>= epsilon:
if ans**3 \< a: # 如果中间值的立方小于a，说明真实立方根在右侧，更新low为当前中间值
low = ans
else: # 否则，真实立方根在左侧，更新high为当前中间值
high = ans
# 重新计算中间值
ans = (low + high) / 2.0
# 输出结果，保留一位小数
print('%.1f' % ans)
except EOFError: # 捕获输入结束的信号
break # 结束循环

在求解立方根（或其他类似数学问题）时，精度值（epsilon）的确定往往依赖于具体的应用场景和对结果精度的需求。精度值epsilon表示我们能接受的最大误差范围，它影响着算法的终止条件和最终结果的准确度。选择合适的epsilon是在算法的效率和结果精度之间寻找平衡的过程。

以下是确定epsilon的一些考虑因素：

1. **应用需求：**首先需要考虑的是应用对精度的要求。不同的问题可能对结果的精度有不同的要求。例如，工程计算可能需要非常高的精度，而某些快速估计可能对精度的要求相对宽松。

2. **数值范围：**被求立方根的数的大小也会影响精度值的选择。对于非常大或非常小的数，可能需要调整epsilon的值以获得准确的结果。

3. **计算资源：**更小的epsilon值意味着更高的精度，但同时可能会导致算法需要更多的迭代次数，从而消耗更多的计算资源。在有限的计算资源下，需要在计算时间和精度之间做出权衡。

4. **数值稳定性：**在某些情况下，过小的epsilon可能会导致数值计算中的稳定性问题，从而影响结果的可靠性。

在实际应用中，epsilon的值通常是根据经验选择的。一个常用的起点是`0.0001`或`0.001`，然后根据计算结果的准确性和算法的执行时间进行调整。如果需要非常高的精度，可以进一步减小epsilon；如果计算资源有限，或者对精度的需求不是非常高，可以适当增大epsilon。

在实际编程实践中，选择epsilon时还需要考虑到浮点数计算的精度限制，避免因为浮点数表示的精度问题而导致的死循环或是无法达到预期的精度。
