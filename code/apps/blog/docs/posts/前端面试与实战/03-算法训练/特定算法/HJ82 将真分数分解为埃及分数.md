# HJ82 将真分数分解为埃及分数

> 本节目标：理解“HJ82 将真分数分解为埃及分数”的核心思路，并能把它用于实际开发或面试表达。
中等  通过率：38.02%  时间限制：1秒  空间限制：32M
知识点==基础数学====搜索==
**描述**
分子为1的分数称为埃及分数。现输入一个真分数(分子比分母小的分数，叫做真分数)，请将该分数分解为埃及分数。如：8/11 = 1/2+1/5+1/55+1/110。
注：真分数指分子小于分母的分数，分子和分母有可能gcd不为1！
如有多个解，请输出任意一个。
**输入描述：**
输入一个真分数，String型
**输出描述：**
输出分解后的string
**示例1**
输入：
8/112/4
==复制==
输出：
1/2+1/5+1/55+1/1101/3+1/6
==复制==
说明：
第二个样例直接输出1/2也是可以的

要解决这个问题，可以使用贪心算法来逐步找到合适的埃及分数分解。给定一个真分数a/b，我们寻找最小的c使得1/c小于或等于a/b，然后将a/b减去1/c，重复此过程直到a/b变为0。这样做可以确保每次都使用最大可能的埃及分数来分解，从而最小化分解中的项数。

请注意，这个算法可能不是最优解，因为埃及分数的分解不是唯一的，而且有时候可以通过选择稍大的分母来减少分解中的项数。但是，对于大多数情况，这个贪心策略是有效的。

下面是这个算法的Python实现：
def decompose(fraction):
a, b = map(int, fraction.split('/'))
result = []
while a != 0:
# 如果b不能整除a，则找到大于b/a的最小整数c
if b % a != 0:
c = b // a + 1
else:
# 如果b可以整除a，那么1/(b/a)就是最后一个埃及分数
c = b // a
result.append('1/\{\}'.format(c))
break
# 将找到的埃及分数1/c加入结果列表
result.append('1/\{\}'.format(c))
# 更新a和b的值
a = a * c - b
b = b * c
# 约简a和b
gcd_ab = gcd(a, b)
a //= gcd_ab
b //= gcd_ab
return '+'.join(result)
# 求最大公约数的函数

def gcd(x, y):
while y != 0:
x, y = y, x % y
return x

# 读取输入并处理
while True:
try:
fraction = input()
print(decompose(fraction))
except EOFError:
break

这个程序读取一个用户输入的真分数，然后输出其埃及分数分解。注意，这里还添加了一个gcd函数来约简每一步骤中的分子和分母，以保证每次减去的都是最简分数。

寻找合适的单位分数
你的理解基本正确，让我来帮你整理一下：

1. 当我们面对一个真分数`a/b`（其中`a\<b`），我们的目标是找到一系列的单位分数（即分子为1的分数），它们的和等于`a/b`。

2. 我们首先尝试找到一个**最大**的单位分数，使得它**小于或等于**`a/b`。这个单位分数的形式是`1/x`。

3. 为了找到这个`x`，我们考虑`a/b`的倒数，即`b/a`，因为如果`b/a`可以整除，那么`1/(b/a)`正好是我们需要的单位分数。但大多时候`b/a`是不能整除的，这时候我们需要找到一个稍微大一点的数，保证`1/x`小于`a/b`。这个数就是`ceil(b/a)`，它表示`b/a`向上取整。

4. 但这只是第一步，找到这个最大的单位分数`1/ceil(b/a)`后，我们需要从原分数`a/b`中减去这个单位分数，然后对剩下的部分重复这个过程，直到剩余部分为0。

5. 通过这种方式，我们能够把原来的真分数`a/b`表示为几个单位分数的和，而且这种表示方式符合埃及分数的定义。

所以，你提到的“把分母`(b/a)`再加1”的过程，实际上是一个简化理解。正确的做法是直接计算`ceil(b/a)`来找到第一个单位分数的分母。这样做是为了确保这个单位分数既是**小于**`a/b`的，同时又是**最接近**`a/b`的（即最大的单位分数）。这个单位分数被用来从原分数中减去，然后对剩余的部分重复相同的过程。

埃及分数
埃及分数的表示法基于古埃及数学中的一种表示分数的方法，即任何分数都可以表示为几个互不相同的单位分数之和。单位分数是分子为1的分数，例如1/2、1/3、1/4等。这种表示法的可能性基于数学原理，特别是贪心算法的应用。

对于任意给定的真分数（即分子小于分母的分数），我们总是可以找到一个单位分数，使得这个单位分数小于或等于给定的分数。这个过程可以通过以下步骤递归地进行：

1. 对于给定的分数a/b（其中a \< b），找到最小的单位分数1/c，使得1/c \<= a/b。可以通过取c = ceil(b/a)来找到这样的c，其中ceil是向上取整函数。
2. 减去找到的单位分数1/c，得到新的分数(a*c - b) / (b*c)。
3. 对新得到的分数重复步骤1和2，直到最终分数为0。

这个过程之所以总是可行的，是因为对于任何非单位分数，我们总能找到一个最大的单位分数使得它小于等于原分数。减去这个单位分数后，我们得到一个更小的分数，这个过程可以重复进行，直到分数被完全分解为单位分数之和。

这种方法之所以有效，是因为单位分数1/c的选择保证了每一步都在减少剩余的分数的大小，而且每次选择的单位分数都不会重复，因为随着算法的进行，分子在逐渐减小，而分母在逐渐增大，保证了单位分数的唯一性。

贪心算法的关键在于每一步都做出当前看来最优的选择（即找到最大可能的单位分数），这保证了算法的进展，并最终达到了分解的目的。这种方法虽然不一定能找到单位分数分解的最短序列，但它保证了任何分数都可以表示为埃及分数的形式。
