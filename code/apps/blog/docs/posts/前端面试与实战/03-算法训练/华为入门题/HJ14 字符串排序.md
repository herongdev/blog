# HJ14 字符串排序

> 本节目标：理解“HJ14 字符串排序”的核心思路，并能把它用于实际开发或面试表达。
**描述**
给定 n 个字符串，请对 n 个字符串按照字典序排列。
数据范围： 1≤�≤1000 1≤_n_≤1000  ，字符串长度满足 1≤���≤100 1≤_len_≤100
**输入描述：**
输入第一行为一个正整数n(1≤n≤1000),下面n行为n个字符串(字符串长度≤100),字符串中只含有大小写字母。
**输出描述：**
数据输出n行，输出结果为按照字典序排列的字符串。
**示例1**
输入：
9captocatcardtwotooupboatboot
==复制==
输出：
boatbootcapcardcattotootwoup
==复制==

def sort_strings(n):
# 初始化一个空列表用于存储输入的字符串
strings = []
# 循环读取n个字符串，并添加到列表中
for _ in range(n):
strings.append(input())
# 按字典序排序字符串
strings.sort()
# 输出排序后的字符串
for string in strings:
print(string)
# 读取输入的字符串数量
n = int(input())
# 调用函数，进行排序和输出
sort_strings(n)
