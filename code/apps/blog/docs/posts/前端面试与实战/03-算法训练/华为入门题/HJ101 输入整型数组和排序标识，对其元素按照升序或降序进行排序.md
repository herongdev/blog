# HJ101 输入整型数组和排序标识，对其元素按照升序或降序进行排序

> 本节目标：理解“HJ101 输入整型数组和排序标识，对其元素按照升序或降序进行排序”的核心思路，并能把它用于实际开发或面试表达。
**描述**
输入整型数组和排序标识，对其元素按照升序或降序进行排序

数据范围：元素大小满足 0≤���≤100000 0≤_val_≤100000
**输入描述：**
第一行输入数组元素个数
第二行输入待排序的数组，每个数用空格隔开
第三行输入一个整数0或1。0代表升序排序，1代表降序排序
**输出描述：**
输出排好序的数字
**示例1**
输入：
81 2 4 9 3 55 64 250
==复制==
输出：
1 2 3 4 9 25 55 64
==复制==
**示例2**
输入：
51 2 3 4 51
==复制==
输出：
5 4 3 2 1

def sort_array(nums, sort_flag):
"""
对数组进行排序
:param nums: 待排序的数组
:param sort_flag: 排序标识，0代表升序，1代表降序
:return: 排序后的数组
"""
return sorted(nums, reverse=bool(sort_flag))

# 读取输入
n = int(input()) # 数组元素个数
nums = list(map(int, input().split())) # 待排序的数组
sort_flag = int(input()) # 排序标识
# 进行排序
sorted_nums = sort_array(nums, sort_flag)
# 输出排序后的数组
print(' '.join(map(str, sorted_nums)))
