# HJ80 整型数组合并

> 本节目标：理解“HJ80 整型数组合并”的核心思路，并能把它用于实际开发或面试表达。
简单  通过率：35.15%  时间限制：1秒  空间限制：32M
知识点==排序====数组====哈希==
**描述**
题目标题：
将两个整型数组按照升序合并，并且过滤掉重复数组元素。
输出时相邻两数之间没有空格。
**输入描述：**
输入说明，按下列顺序输入：
1 输入第一个数组的个数
2 输入第一个数组的数值
3 输入第二个数组的个数
4 输入第二个数组的数值
**输出描述：**
输出合并之后的数组
**示例1**
输入：
31 2 54-1 0 3 2
==复制==
输出：
-101235

# 读入第一个数组的长度和元素
n1 = int(input())
array1 = list(map(int, input().split()))
# 读入第二个数组的长度和元素
n2 = int(input())
array2 = list(map(int, input().split()))
# 合并数组
merged_array = array1 + array2
# 去除重复元素
unique_array = list(set(merged_array))
# 排序
unique_array.sort()
# 将排序后的数组转换为字符串，相邻两数之间没有空格
result = ''.join(str(num) for num in unique_array)
# 输出
print(result)
