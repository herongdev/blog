# HJ11 数字颠倒

> 本节目标：理解“HJ11 数字颠倒”的核心思路，并能把它用于实际开发或面试表达。
**描述**
输入一个整数，将这个整数以字符串的形式逆序输出
程序不考虑负数的情况，若数字含有0，则逆序形式也含有0，如输入为100，则输出为001
数据范围： 0≤�≤230−1 0≤_n_≤230−1
**输入描述：**
输入一个int整数
**输出描述：**
将这个整数以字符串的形式逆序输出
**示例1**
输入：
1516000
==复制==
输出：
0006151
==复制==
**示例2**
输入：
0
==复制==
输出：
0
==复制==

切片操作是Python中一个非常强大的特性，用于提取序列类型（如列表、元组、字符串）的一部分。切片操作的基本语法是`[start:stop:step]`，其中`start`是切片开始的位置，`stop`是切片结束的位置（但不包括此位置的元素），`step`是步长（即每次跳过的元素数量）。如果省略`start`和`stop`，默认是从序列的开始到结束；如果省略`step`，默认步长为1，即不跳过任何元素。

`[::-1]`是切片操作的一种特殊用法，用于将序列逆序。下面是这三个参数在`[::-1]`中的作用：

- `start`：由于没有明确指定，所以默认从序列的末尾开始。
- `stop`：同样，由于没有明确指定，所以默认到序列的开头。
- `step`：步长为-1，意味着从序列的末尾向前遍历序列。

因此，`[::-1]`实际上告诉Python：从序列的最后一个元素开始，一直到序列的第一个元素结束，每次步进-1（即向前移动一个位置）。这样就实现了将原序列逆序的效果。

这里是一些使用`[::-1]`的示例：

```python
# 对字符串进行逆序
s = "Hello, World!"
print(s[::-1])
# 输出: "!dlroW ,olleH"

# 对列表进行逆序
lst = [1, 2, 3, 4, 5]
print(lst[::-1])
# 输出: [5, 4, 3, 2, 1]

# 对元组进行逆序
tup = (1, 2, 3, 4, 5)
print(tup[::-1])
# 输出: (5, 4, 3, 2, 1)
```

这个操作是非常方便的，因为它不仅简洁易读，而且适用于所有序列类型的对象，且不修改原始序列，而是返回一个新的逆序序列。

:::
