# HJ100 等差数列

> 本节目标：理解“HJ100 等差数列”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
**描述**
等差数列 2，5，8，11，14。。。。
（从 2 开始的 3 为公差的等差数列）
输出求等差数列前n项和
数据范围：

**输入描述：**
输入一个正整数n。
**输出描述：**
输出一个相加后的整数。
**示例1**
输入：
2
==复制==
输出：
7
==复制==
说明：
2+5=7
**示例2**
输入：
275
==复制==
输出：
113575
==复制==
说明：
2+5+...+821+824=113575

求等差数列前n项和的公式是：

# 输入
n = int(input())
# 计算前n项和
Sn = n * (3 * n + 1) // 2
# 输出
print(Sn)

# 输入
n = int(input())
# 初始化等差数列的首项
first_term = 2
# 初始化等差
difference = 3
# 初始化和为0
sum = 0
# 通过循环累加每一项
for i in range(n):
# 计算当前项
current_term = first_term + i * difference
# 累加到和中
sum += current_term
# 输出和
print(sum)
