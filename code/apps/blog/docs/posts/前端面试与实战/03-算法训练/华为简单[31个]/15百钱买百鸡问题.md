# 15百钱买百鸡问题

> 本节目标：理解“15百钱买百鸡问题”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
简单  通过率：53.19%  时间限制：1秒  空间限制：32M
**描述**
公元五世纪，我国古代数学家张丘建在《算经》一书中提出了“百鸡问题”：鸡翁一值钱五，鸡母一值钱三，鸡雏三值钱一。百钱买百鸡，问鸡翁、鸡母、鸡雏各几何？
现要求你打印出所有花一百元买一百只鸡的方式。
**输入描述：**
输入任何一个整数，即可运行程序。
**输出描述：**
 输出有数行，每行三个整数，分别代表鸡翁，母鸡，鸡雏的数量
**示例1**
输入：
1
==复制==
输出：
0 25 754 18 788 11 8112 4 84

这个问题是一个典型的枚举问题，我们可以通过遍历可能的鸡翁（公鸡）数量，然后在每个鸡翁数量下遍历可能的鸡母（母鸡）数量，最后计算出鸡雏（小鸡）的数量，检查这三种鸡的数量和价格是否满足条件。

条件是：
- 鸡翁价格5元一只，鸡母价格3元一只，鸡雏3只1元。
- 总共要买100只鸡。
- 总共要花100元钱。

鸡翁数量我们设为`x`，鸡母数量设为`y`，鸡雏数量为`z`，则有以下两个条件：
- `x + y + z = 100`（总共买100只鸡）
- `5x + 3y + z/3 = 100`（总共花费100元）

我们可以写一个简单的循环来遍历可能的`x`和`y`的值，然后根据上面的两个条件计算出`z`的值，并检查解是否合法。

下面是Python代码示例：
# 输入任何一个整数，即可运行程序
_ = input()
# 遍历鸡翁的可能数量
for x in range(0, 101):
# 遍历鸡母的可能数量
for y in range(0, 101 - x):
# 计算鸡雏的数量
z = 100 - x - y
# 检查是否满足花费100元的条件
if 5*x + 3*y + z/3 == 100:
print(x, y, z)

这段代码通过双层循环遍历鸡翁和鸡母的可能数量，并计算出鸡雏的数量。然后，它检查这种组合是否能够满足总数为100只鸡、总价为100元的条件。如果条件满足，就打印出这种组合的鸡翁、鸡母和鸡雏的数量。这种枚举方法虽然简单，但能有效地解决问题。

方法二
利用了两个等式：a + b + c = 100 和 5a + 3b + c/3 = 100。通过数学推导

我们发现
# 无需持续输入，直接执行一次
try:
for i in range(4): # 公鸡数量是4的倍数，且因为要保证b为正，a的取值范围为0到3，即最多12只公鸡
a = 4 * i # 公鸡数量
b = 25 - 7 * i # 母鸡数量
c = 100 - a - b # 小鸡数量
# 输出购买方案
print(a, b, c)
except:
pass
