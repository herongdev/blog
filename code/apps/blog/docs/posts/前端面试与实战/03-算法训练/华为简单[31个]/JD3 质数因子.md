# JD3 质数因子

> 本节目标：理解“JD3 质数因子”的核心思路，并能把它用于实际开发或面试表达。
**描述**
功能:输入一个正整数，按照从小到大的顺序输出它的所有质因子（重复的也要列举）（如180的质因子为2 2 3 3 5 ）
数据范围： 1≤�≤2×109+14 1≤_n_≤2×109+14
**输入描述：**
输入一个整数
**输出描述：**
按照从小到大的顺序输出它的所有质数的因子，以空格隔开。
**示例1**
输入：
180
==复制==
输出：
2 2 3 3 5

要找到一个数的所有质数因子并按从小到大的顺序输出，你不需要显式地检查每个因子是否为质数。相反，你可以从最小的可能质数（2）开始尝试，依次除以这个数，直到它不再是原数的因子为止，然后移动到下一个数。如果某个数是给定数的因子，那么这个数必须是质数，因为我们从最小的质数开始，并且已经除去了所有比它小的质数的因子。

以下是这个方法的Python实现：
def get_prime_factors(n):
# 初始化一个空列表用来存储所有的质数因子
factors = []
# 从2开始，尝试所有小于等于n的可能的质数因子
divisor = 2
while divisor * divisor \<= n:
# 当divisor是n的因子时，添加到factors列表中，并除以divisor直到它不再是因子为止
while n % divisor == 0:
factors.append(divisor)
n //= divisor
divisor += 1
# 如果n大于1，那么n是原数的一个质数因子
if n \> 1:
factors.append(n)
return factors

# 从用户输入中读取一个整数
n = int(input())
# 获取这个整数的所有质数因子
prime_factors = get_prime_factors(n)
# 按照要求的格式输出这些质数因子
print(" ".join(map(str, prime_factors)))

这个实现利用了数学上的一个事实：任何合数都可以分解为一系列质数的乘积，而且这个分解是唯一的（基本定理算术）。通过从最小的质数开始除，我们可以确保找到的每个因子都是质数，从而避免了显式的质数检查。
