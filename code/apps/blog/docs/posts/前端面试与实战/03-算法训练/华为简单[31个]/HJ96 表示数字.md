# HJ96 表示数字

> 本节目标：理解“HJ96 表示数字”的核心思路，并能把它用于实际开发或面试表达。
**描述**
将一个字符串中所有的整数前后加上符号“*”，其他字符保持不变。连续的数字视为一个整数。
数据范围：字符串长度满足  1≤_n_≤100
**输入描述：**
输入一个字符串
**输出描述：**
字符中所有出现的数字前后加上符号“*”，其他字符保持不变
**示例1**
输入：
Jkdi234klowe90a3
==复制==
输出：
Jkdi*234*klowe*90*a*3*

# 输入字符串
s = input()
# 初始化一个新的字符串用于存放结果
result = ""
# 标记当前是否处于数字中
in_number = False
for char in s:
# 检查当前字符是否为数字
if char.isdigit():
if not in_number:
# 数字开始，加'*'
result += '*'
in_number = True
# 添加当前的数字字符
result += char
else:
if in_number:
# 数字结束，加'*'
result += '*'
in_number = False
# 添加当前的非数字字符
result += char
# 如果字符串以数字结束，确保在最后也加上'*'
if in_number:
result += '*'
# 输出结果
print(result)
