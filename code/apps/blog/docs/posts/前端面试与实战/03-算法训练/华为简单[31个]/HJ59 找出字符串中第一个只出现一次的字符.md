# HJ59 找出字符串中第一个只出现一次的字符

**描述**
找出字符串中第一个只出现一次的字符

数据范围：输入的字符串长度满足 1≤�≤1000 1≤_n_≤1000

**输入描述：**
输入一个非空字符串
**输出描述：**
输出第一个只出现一次的字符，如果不存在输出-1
**示例1**
输入：
asdfasdfo

输出：
o

为了找出字符串中第一个只出现一次的字符，我们可以使用一个简单的算法，该算法具有两个步骤：

1. **计数**：遍历字符串，用一个字典或数组来计数每个字符出现的次数。
2. **查找**：再次遍历字符串，检查每个字符的出现次数，返回第一个出现次数为1的字符。

这个算法的时间复杂度是O(n)，因为我们需要两次遍历字符串，其中n是字符串的长度。空间复杂度依赖于存储字符计数的数据结构，通常是O(1)，因为字符集的大小是有限的。

下面是实现这个算法的Python代码示例：

def firstUniqChar(s):
# 计数
char_count = \{\}
for char in s:
if char in char_count:
char_count[char] += 1
else:
char_count[char] = 1   # 查找
for char in s:
if char_count[char] == 1:
return char
return -1
# 示例
s = "asdfasdfo"
print(firstUniqChar(s)) # 输出: o

这段代码首先通过遍历字符串` s `来填充` char_count` 字典，其中键是字符，值是该字符出现的次数。之后，它再次遍历字符串，查找并返回第一个出现次数为1的字符。如果没有这样的字符，它返回-1。
