# 是否闰年

> 本节目标：理解“是否闰年”的核心思路，并能把它用于实际开发或面试表达。
要判断一个年份是否是闰年，可以根据以下规则：

1. 如果年份能被4整除但不能被100整除，则是闰年。
2. 如果年份能被400整除，则也是闰年。

根据这些规则，闰年的判断条件可以总结为：年份能被4整除，并且（不能被100整除或能被400整除）。

以下是使用Python实现的示例代码：
def is_leap_year(year):
# 判断是否是闰年
return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

is_leap_year = lambda year: (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

这个函数首先检查年份是否满足闰年的条件，如果满足，则返回`True`表示是闰年；如果不满足，则返回`False`表示不是闰年。这样，你就可以用这个函数来判断任何一个年份是否是闰年。
