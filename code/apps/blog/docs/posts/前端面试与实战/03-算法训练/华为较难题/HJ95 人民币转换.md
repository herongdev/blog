# HJ95 人民币转换

> 本节目标：理解“HJ95 人民币转换”的核心思路，并能把它用于实际开发或面试表达。
较难  通过率：27.03%  时间限制：1秒  空间限制：32M
知识点==字符串==
**描述**
考试题目和要点：
1、中文大写金额数字前应标明“人民币”字样。中文大写金额数字应用壹、贰、叁、肆、伍、陆、柒、捌、玖、拾、佰、仟、万、亿、元、角、分、零、整等字样填写。
2、中文大写金额数字到“元”为止的，在“元”之后，应写“整字，如532.00应写成“人民币伍佰叁拾贰元整”。在”角“和”分“后面不写”整字。
3、阿拉伯数字中间有“0”时，中文大写要写“零”字，阿拉伯数字中间连续有几个“0”时，中文大写金额中间只写一个“零”字，如6007.14，应写成“人民币陆仟零柒元壹角肆分“。
4、10应写作“拾”，100应写作“壹佰”。例如，1010.00应写作“人民币壹仟零拾元整”，110.00应写作“人民币壹佰拾元整”
5、十万以上的数字接千不用加“零”，例如，30105000.00应写作“人民币叁仟零拾万伍仟元整”
**输入描述：**
输入一个double数
**输出描述：**
输出人民币格式
**示例1**
输入：
151121.15
==复制==
输出：
人民币拾伍万壹仟壹佰贰拾壹元壹角伍分
==复制==
**示例2**
输入：
1010.00
==复制==
输出：
人民币壹仟零拾元整
==复制==

当然！我们的目标是把数字转换成中文的钱的形式。比如，13.64元要变成“人民币拾叁元陆角肆分”。我们分几步来做这个转换：

1. 把整数和小数部分分开。
2. 把整数部分的每一位数字转成中文。
3. 把小数部分的每一位数字转成中文。
4. 在正确的位置加上“拾”、“佰”、“仟”等中文单位。
5. 如果十位上的数字是1，我们就直接说“拾”而不是“壹拾”。
6. 如果有连续的零，我们只说一次“零”。
7. 最后把所有的部分合起来，就得到了完整的中文钱的形式。

好，现在我们开始给代码加注释，就像在给五岁的孩子讲故事一样。

# 这是将数字转换成中文金额表示的函数
def convert_to_chinese_currency(num_str):
# 这些是中文数字，从"零"到"玖"
digits = "零壹贰叁肆伍陆柒捌玖"
# 这些是单位，从个位开始到千位
units = ["", "拾", "佰", "仟"]
# 这些是更大的单位，从万开始
big_units = ["", "万", "亿", "兆"]
# 这个函数是用来转换整数部分的
def convert_integer_part(integer_str):
result = "" # 这是我们将要建立的字符串
str_len = len(integer_str) # 计算数字的长度
# 将整数部分分成每四位一组
groups = [integer_str[max(0, i - 4): i]
for i in range(str_len, 0, -4)][::-1]
# 对每组数字进行处理
for idx, grp in enumerate(groups):
grp_str = "" # 这是每组的字符串
zero_flag = False # 这个标记用来记住我们是否需要加"零"
for i, digit in enumerate(grp[::-1]): # 从右向左查看每一位数字
digit = int(digit) # 将字符转换成数字
if digit == 0: # 如果数字是0
zero_flag = True
else:
if zero_flag: # 如果之前有0，我们需要加一个"零"
grp_str = "零" + grp_str
zero_flag = False
# 特别处理"拾"的情况
if i == 1 and digit == 1 and len(grp) \> 1:
grp_str = units[i] + grp_str
else: # 正常情况下，加上数字和单位
grp_str = digits[digit] + units[i] + grp_str
if int(grp) != 0: # 如果这组数字不全是0
grp_str += big_units[len(groups) - idx - 1] # 加上大单位，比如"万"、"亿"
if zero_flag and idx != len(groups) - 1: # 如果需要，前面加上"零"
grp_str = "零" + grp_str
result += grp_str # 将这组的字符串加到结果中
return result + "元" # 最后加上"元"
# 这个函数是用来转换小数部分的
def convert_decimal_part(decimal_str):
part = "" # 这是我们将要建立的字符串
if decimal_str[0] != "0": # 如果角位不是0
part += digits[int(decimal_str[0])] + "角" # 加上角的表示
if decimal_str[1] != "0": # 如果分位不是0
part += digits[int(decimal_str[1])] + "分" # 加上分的表示
return part if part else "整" # 如果没有小数，就加上"整"
# 确保输入的数字有两位小数
num_str = format(float(num_str), ".2f")
# 分割整数部分和小数部分
integer_part, decimal_part = num_str.split(".")
# 开始建立整个字符串
chinese_currency = "人民币" # 先加上"人民币"
if integer_part != "0": # 如果整数部分不是0
chinese_currency += convert_integer_part(integer_part) # 加上整数部分的中文表示
chinese_currency += convert_decimal_part(decimal_part) # 加上小数部分的中文表示
return chinese_currency # 返回最终的字符串

# 读取一个数字，然后把它转换成中文金额表示
print(convert_to_chinese_currency(input())) # 期望输出：人民币拾伍万壹仟壹佰贰拾壹元壹角伍分

这个故事告诉我们怎么把数字变成中文的钱的样子。我们按照中文的习惯，一个一个数字地说出来，然后加上合适的单位。如果有很多零，我们只说一次零。还有，如果十位是1，我们就直接说拾。我们小心地说这些数字和单位，直到我们讲出完整的故事。

**if** **not** **integer_str****:**
`if not integer_str:` 这行代码会在 `integer_str` 是一个空字符串时成立。在这个特定的转换函数中，空字符串会出现在我们去除了整数部分开头所有的 '0' 之后，如果原始的整数部分仅由 '0' 组成。

例如，如果我们开始有一个数字 `0.85`，那么在执行 `integer_part.lstrip('0')` 后，整数部分（`integer_part`）会从 `'0'` 变成一个空字符串 `''`，因为我们移除了前面的零。此时，`if not integer_str:` 这个条件就会成立，函数会返回 `'零元'`。这样做是为了确保在只有小数部分，没有整数部分时（即，整数部分为0时），我们能够正确地输出中文金额表示。

**字符串转数字时的****0****的处理**
1. **转换为整数 (`int`)：**
- 如果字符串不包含小数点，即被视为整数，那么将所有前置零去掉。转换结果仅反映非零数字部分。
- 例如：`'000123'` 转换后为整数 `123`。

2. **转换为浮点数 (`float`)：**
- 如果字符串包含小数点，即被视为浮点数：
- **小数部分：** 不做任何处理，保留原样，包括任何零。这是因为小数部分的零可能影响数值的精度和表示。
- 例如：`'0.0500'` 保留为浮点数 `0.0500`。
- **整数部分：**
- 如果整数部分的值等于0（即小数点前全是零或仅一个零），则保留一个零。这符合浮点数表示法，确保了数值小于1时的正确表示。
- 例如：`'0.123'` 转换后为浮点数 `0.123`。
- 如果整数部分的值不等于0，则去掉所有前置零，仅保留数值有效部分。
- 例如：`'000123.456'` 转换后为浮点数 `123.456`。

通过这样的规则，我们可以清楚地区分整数和浮点数的转换处理，同时准确地反映原始数据的意图，无论是在数值的大小还是在精度上。这套规则旨在确保数值转换的过程中，无论是整数还是浮点数，前置零的处理都是适当和准确的。

**groups** **= [****integer_str****[****max****(****0****,** **i** **-** **4****):** **i****]**
**for** **i** **in** **range****(****str_len****,** **0****, -****4****)][::-****1****]**
这行代码的目的是将一个整数字符串分割成每四位一组的小段，以便按照中文的计数习惯（个、十、百、千、万、亿）来处理。下面是这行代码的详细介绍：

1. `for i in range(str_len, 0, -4)`

- 这部分是一个 `for` 循环，使用 `range` 函数生成一个序列。
- `str_len` 是整数部分字符串的长度。
- `range` 函数的起始值是 `str_len`（整数部分的长度），结束值是 `0`，步长是 `-4`。
- 这意味着 `i` 会从字符串的末尾开始，每次向前移动4个字符的位置，直到到达字符串的开始。

2. `integer_str[max(0, i - 4) : i]`

- 对于每一个 `i`，这个表达式都会从整数字符串中截取一个子字符串。
- `i - 4` 计算的是子字符串的起始位置（从右向左数），`i` 是结束位置。
- 使用 `max(0, i - 4)` 确保起始位置不会小于0，这是因为当处理字符串的最左边几位时，`i - 4` 可能会是一个负数。
- 所以，这个表达式会从整数字符串中截取从第 `i - 4` 位到第 `i` 位（不包含第 `i` 位本身）的子字符串。

3. `[...]`

- 这个方括号表示列表推导式，用于创建一个新的列表，列表中的每个元素都是通过上面描述的过程计算得到的子字符串。

4. `[...][::-1]`

- 最后，`[::-1]` 是一个列表的切片操作，用于将列表反转。
- 这是因为我们从字符串的末尾开始分割，最先生成的子字符串实际上对应整数的最低位的四位数字。
- 为了使得子字符串列表的顺序与数字的自然顺序（即从左到右）一致，我们需要将列表反转。

综上所述，这行代码将整数字符串按照每四位数字一组的方式分割成多个子字符串，并且这些子字符串的顺序与原始整数中数字的顺序一致。这样的分割方式符合中文数字的读写习惯，便于后续按中文的方式将数字转换为文字描述。
