# 取模运算保证在特定区间

> 本节目标：理解“取模运算保证在特定区间”的核心思路，并能把它用于实际开发或面试表达。
这段代码是Python中对字符进行大小写转换和字母位移的一个例子。让我们逐步分解这个表达式的意义。

假设`char`是一个小写英文字母。这行代码将`char`向后移动一个字母位置，并且转换成大写。如果`char`是'z'，它会回到字母表的开头，并转换为'A'。

表达式解析如下：

1. `ord(char)`: 得到`char`字符的ASCII码值。
2. `ord('a')`: 得到小写字母`'a'`的ASCII码值。
3. `ord(char) - ord('a')`: 计算`char`与`'a'`的ASCII码值之差。这实际上给了我们`char`在字母表中的位置（例如，如果`char`是`'a'`，结果是`0`；如果是`'b'`，结果是`1`，以此类推）。
4. `(ord(char) - ord('a') + 1)`: 将`char`的位置向后移动一个位置。
5. `... % 26`: 由于英文字母表中有26个字母，这个模运算确保了如果我们已经在字母`'z'`上（它是第25个字母，因为我们从0开始计数），我们会回到字母表的开头。模运算是取余数操作，确保结果总是在`0`到`25`之间。
6. `... + ord('A')`: 由于上一步得到的是`0`到`25`之间的一个数，我们通过加上大写字母`'A'`的ASCII码值，将其转换回ASCII码。这一步是因为大写字母A的ASCII值是65，这样可以保证最终的ASCII值是一个大写字母。
7. `chr(...)`: 最后，`chr`函数将这个ASCII码值转换回一个字符，这个字符是原始`char`字符按字母表顺序向后移动一位的大写版本。

例如，如果`char`是`'a'`，则`ord('a')`是97，`ord('A')`是65。计算得到：

```
97 - 97 + 1 = 1
1 % 26 = 1
1 + 65 = 66
chr(66) = 'B'
```

所以，如果`char`是`'a'`，这行代码的结果就是`'B'`。如果`char`是`'z'`：

```
122 - 97 + 1 = 26
26 % 26 = 0
0 + 65 = 65
chr(65) = 'A'
```

在这个例子中，`char`是`'z'`，结果是`'A'`，实现了从`'z'`到`'A'`的转换。
