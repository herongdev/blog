# 组件 & Props(1m)

> 本节目标：理解“组件 & Props(1m)”的核心思路，并能把它用于实际开发或面试表达。
组件允许你将 UI 拆分为独立可复用的代码片段，并对每个片段进行独立构思。

组件，从概念上类似于 JavaScript 函数。
它接受任意的入参（即 “props”），并返回用于描述页面展示内容的 React 元素。
