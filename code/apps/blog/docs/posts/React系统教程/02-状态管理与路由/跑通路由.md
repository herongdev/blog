`npm i react-router-dom @types/react-router-dom path-to-regexp -S`

当你安装了`react-router-dom` 适用于浏览器端的库，会自动安装以下库：

- `react-router` 才是真正的路由库跨平台，可以应用浏览器 `canvas` `vr`；
- `history` 底层实现模拟历史对象的库 内部写了二套，一套是使用`hash,`一套是使用`window.history`；

```
src\index.tsx
import React from 'react';
import ReactDOM from 'react-dom';
import { HashRouter as Router, Route } from './react-router-dom';
import Home from './components/Home';
import User from './components/User';
import Profile from './components/Profile';
debugger
ReactDOM.render(
  <Router>
    <Route path="/" exact={true} component={Home} />
    <Route path="/user" component={User} />
    <Route path="/profile" component={Profile} />
  </Router>,
  document.getElementById('root')
);
src\components\Home.tsx
import React from "react";
export default class Home extends React.Component {
  render() {
    console.log(this.props);
    return <div>Home</div>
  }
}
User.tsx
import React from "react";
export default class User extends React.Component {
  render() {
    console.log(this.props);
    return <div>User</div>
  }
}
src\components\Profile.tsx
import React from "react";
export default class Profile extends React.Component {
  render() {
    return <div>Profile</div>
  }
}
