# 数据提交

> 本节目标：理解“数据提交”的核心思路，并能把它用于实际开发或面试表达。
```
import { debounce, isInteger } from "lodash";
const onSave = debounce(
    async () => {
    const { code, data } = await handlerSaveFormData();
    if (code === "error") {
        message.warning(data?.message);
    } else {
        message.info(data?.message);
    }
    },
    1000,
    { maxWait: 1500 }
);
```
