# 高阶组件

> 本节目标：理解“高阶组件”的核心思路，并能把它用于实际开发或面试表达。
高阶组件就是一个函数，传给它一个组件，它返回一个新的组件；
高阶组件的作用其实就是为了组件之间的代码复用；

```
const NewComponent = higherOrderComponent(OldComponent)
```
