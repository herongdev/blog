 当被代理`dom`上的某类型事件发生时，会调用些方法；

- 先找到事件类型和`target;`
- 将批量更新设置为`true;`
- 创建一个合成事件对象；
- 然后模拟向上冒泡；
- 从`target`开始，从中取出真实的事件处理函数；
- 然后在合成事件对象上加上`targe`和`currentTarget`；
- 再绑定`this`为被代理`dom`后，调用事件处理函数，并传入合成的事件对象；
