# 14. render props

> 本节目标：理解“14. render props”的核心思路，并能把它用于实际开发或面试表达。
- ```
    render-props
    ```

- `render prop` 是指一种在 `React` 组件之间使用一个值为函数的 `prop` 共享代码的简单技术
- 具有 `render prop` 的组件接受一个函数，该函数返回一个 `React` 元素并调用它而不是实现自己的渲染逻辑
- `render prop` 是一个用于告知组件需要渲染什么内容的函数 `prop`
- 这也是逻辑复用的一种方式
