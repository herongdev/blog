在碰到`jsx`语法后，按照`webpack`配置，调用`babel-loader`解析这个`jsx`语法；会查看`\<`后面的变量名：

- 如果是原生`dom`标签中的一种，就标识为字符串；按规范来说是小写，`type`将会是变量名，即`type:`变量名；然后再解析出`props`和`children`，这三个重要部分，然后再传入`React.createElement`方法，这个方法刚好需要这三个值：

如果是小写，就认为是原生`dom`类型，`type`将会是字符串，即`type:`字符串；然后再解析出`props`和`children`，这三个重要部分，然后再传入`React.createElement`方法，这个方法刚好需要这三个值：

```
function createElement(type, config, children)
```
 其中的第三个参数`children`可以是一个数组，也可以是一个普通值；
此外，这个方法会把第三个参数后面多传的参数都当成`children;`
所以，对于以下

```
jsx:
let element1 = (
  <div className="title" style={{ color: "red" }}>
    <span>hello</span>world
  </div>
);
```
 由于第一个字母是小写的，所以`type=div`；
另外会解析出属性`classname="title",style={color:"red"};`
此外标签之间的内容会被当成`children,`所以，`children=[{`标签之间的内容`}]`，最终经过`React.createElement`转换后的普通 对象如下所示：

- 如果是大写，就认为是自定义组件，就会查看这个大写开头的变量，它一般是模块内定义或者从其他文件引入的一个大写字母开头变量；
- 这时，这是会判断这个变量是函数还是对象
    - 如果是函数，还要进一步判断`isReactClassComponent`，即是函数组件还是类组件；
    - 如果是对象，我们`type`将直接指向这个对象，即`type:`大写的变量名（代表一个对象），然后这个对象上会有一个`$$typeof`属性，用来区分这个对象是必属于哪一种`React`的特殊类型；
