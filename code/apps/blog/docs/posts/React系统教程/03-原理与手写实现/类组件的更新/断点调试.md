 在`forceUpdate`方法中：

- 我们取出`oldRenderVdom`；
- 然后我们调用`findDOM`，目的是为了找到旧的真实`DOM;`
- 接下来，我们调用组件的`render`方法，取得最新的`renderVdom`；
- 最后，我们进行`vdom`对比；
- 然后，我们把最新的`renderVdom`保存到实例的`oldRenderVdom`上；

```
forceUpdate() {
```
