# 响应式框架

> 本节目标：理解“响应式框架”的核心思路，并能把它用于实际开发或面试表达。
- 页面的结构和样式，都是写死的。
- 或者是在不同情况下用相应的结构和样式，但总体而言，是事先写好的；
- 我们所要做的，是把不停变化的数据放到我们的页面中去，实时更新页面。
- 一般来说页面的更新有以下因素引起：
    - 纯粹的数据变化，如后端提供的数据变化了，我们页面要相应变化，更新显示新数据；
    - 另外是页面发生了交互操作，这些操作要求请求不一样的数据，并将他显示出来；

框架要做的事就是，当以上行为发生时，自动帮我们把新数据更新到页面中去。

在react 中，我们把数据放在顶级组件中，或者放在组件自己的状态中保存，页面被分成了一个个组件，相当于一个个函数，顶级组件的数据就如同实际上也是全局变量，顶级组件的数据，下面的组件也就是函数都可以访问到，从中取出值来更新自己的页面；

当然，组件也就是函数也有自己的局部变量，保存着自己的数据；
