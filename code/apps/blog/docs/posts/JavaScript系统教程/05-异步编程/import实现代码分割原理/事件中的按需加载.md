# 事件中的按需加载

> 本节目标：理解“事件中的按需加载”的核心思路，并能把它用于实际开发或面试表达。
是的，当浏览器遇到 `import()` 表达式时，它会立即开始处理模块加载的流程。这包括发送网络请求来获取指定的 JavaScript 模块文件。这一行为是异步的，不会阻塞浏览器的主线程，这意味着页面的其他操作如用户交互、渲染等不会被延迟或阻塞。

### 浏览器中 `import()` 的执行细节：

1. **网络请求**：浏览器解析 `import()` 提供的 URL 或路径，并向服务器发起请求，尝试获取相应的 JavaScript 文件。这一步类似于浏览器加载页面中的其他资源（如图片、CSS文件等）。

2. **异步操作**：`import()` 返回一个 `Promise` 对象，这允许调用者以非阻塞方式处理加载、编译和执行模块的结果。这意味着浏览器可以继续执行页面的其他脚本和渲染任务，而不必等待模块加载完成。

3. **缓存和优化**：如果模块之前已被加载过，浏览器可能会使用缓存的副本而不是重新从服务器加载。此外，现代浏览器和网络服务通常会实施各种缓存策略和优化，以减少网络请求的频率和提高加载速度。

4. **加载完成后的处理**：一旦模块文件被成功下载和解析，`import()` 所返回的 `Promise` 将被解决（resolve），调用链上的 `.then()` 方法会被触发。在 `.then()` 方法中，你可以访问和使用模块导出的功能。

### 示例情景

假设有如下代码片段：

```javascript
button.addEventListener('click', () => {
import('/path/to/some-module.js')
.then(module => {
module.doSomething();
})
.catch(error => {
console.error('Module loading failed: ', error);
});
});
```

在这个例子中，只有当用户点击了一个按钮时，`/path/to/some-module.js` 才会被请求。这表明 `import()` 可以用来实现按需加载（也称为懒加载），这是优化大型 Web 应用性能的一种常见策略。

### 总结

因此，当代码执行到 `import()` 时，浏览器确实会立即开始加载指定的模块。这种机制为开发者提供了一种强大的工具，可以根据应用的实际需要动态加载代码，从而优化应用的性能和用户体验。
