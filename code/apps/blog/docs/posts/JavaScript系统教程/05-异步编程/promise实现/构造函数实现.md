# 构造函数实现

> 本节目标：理解“构造函数实现”的核心思路，并能把它用于实际开发或面试表达。
- 构造函数接受一个函数`executor`作为参数；
- 构造函数内部定义了五个变量：
    - `status`：状态
    - `Value:`成功的值
    - `Reason`：失败的原因
    - `onFulfilledCallbacks`：成功时的回调函数
    - `onRejectedCallbacks`：失败时的回调函数
- 还定义了两个方法，这两个方法可以修改构造函数的以上的五个变量，并通过传递给构造函数的参数`executor`来将方法传递给外界，让外界可以修改构造函数内部的变量；
    - `resolve`方法作用有两个：
        - 用来改变构造函数内部状态成功时的值`value`；
        - 在状态成功时，调用成功回调函数；
    - `reject`方法作用也有两个：
        - 用来改变构造函数内部状态失败时的值`reason`；
        - 在状态操作性时，调用失败回调函数；
- 最后，我们执行传入的参数`execotor`，并给这个函数`executor`传入我们构造函数内部定义的两个方法给这个函数`execuotor(resolve,reject)`，这样，我们在`execotor`中调用`resolve`或`reject`就可以修改构造函数内部定义的五个变量`;`
- `Executor(resolve,reject)`执行时，可能会出错，我们对错误进行捕获，并将捕获的错误通过调用`reject`方法来修改`promise`内部的变量，包括状态值、成功的值和失败的原因；
