**什么是回调函数**
把要在异步执行函数执行完后才能执行的代码封装到一个函数中，然后作为参数传递到异步执行函数中去，等异步执行函数中的异步代码执行完后，再执行这个作为参数传递的函数，这个作为参数传递给异步执行函数的函数，叫做`callback`，即回调函数。
