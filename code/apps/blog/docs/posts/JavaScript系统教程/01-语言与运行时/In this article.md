**Link types: modulepreload**
The **modulepreload** keyword for the [rel](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/link#attr-rel) attribute of the [\<link\>](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/link) element provides a declarative way to preemptively fetch a [module script](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) and its dependencies, and store them in the document's module map for later evaluation.
