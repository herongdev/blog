# ECMAScript

> 本节目标：理解“ECMAScript”的核心思路，并能把它用于实际开发或面试表达。
```
Javascript由Netscape创造；
```

Netscape希望这门语言能成为国际标准，于1996年11月，将其提交给标准化组织ECMA（欧洲计算机工业协会）。次年ECMAScript 1.0 版发布。

它大致规定了下列部分：

- 语法
- 关键字/保留字
- 类型
- 操作符
- 语句
- 对象

**兼容**`ECMAScript`
只要做到以下两点，就兼容了

```
ECMAScript
```

：

- 支持`ECMA-262`描述的所有类型、值、对象、属性、函数以及程序句法和语义；
- 支持`Unicode`字符标准。

**拓展**`ECMAScript`
兼容`ECMAScript`的前提下，可以对**兼容**`ECMAScript`进行拓展。

- 添加`ECMA-262`没有描述的“更多类型、值、对象、属性和函数。`ECMA-262`所说的这些新增特性，主要是指该标准中没有规定的新对象和对象的新属性。
- 支持`ECMA-262`没有定义的`"`程序和正则表达式语法`"`，也就是说，可以修改和扩展内置的正则表达式语法。
