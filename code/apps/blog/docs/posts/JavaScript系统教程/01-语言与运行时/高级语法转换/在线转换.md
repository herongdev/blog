# 在线转换

> 本节目标：理解“在线转换”的核心思路，并能把它用于实际开发或面试表达。
Babel 提供一个[REPL](https://babeljs.io/repl/) 在线编译器，可以在线将 ES6 代码转为 ES5 代码。转换后的代码，可以直接作为 ES5 代码插入网页运行。
