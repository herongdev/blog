# 浏览器模型

> 本节目标：理解“浏览器模型”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
三个级别

- `screen-\>screen.height-\>screen.avaiHeight`：有任务条的存在
- `windows-\>outerHeight/innerHeight`：有标题栏，工具栏和状态栏的存在
- `body-\>body.offsetHeight-\>body.clientHeight`：有水平和垂直滚动条的存在
