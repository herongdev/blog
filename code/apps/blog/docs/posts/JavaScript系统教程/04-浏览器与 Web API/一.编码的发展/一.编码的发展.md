# 一.编码的发展

> 本节目标：理解“一.编码的发展”的核心思路，并能把它用于实际开发或面试表达。
一个字节由`8`个位组成，`gbk`中一个汉字`2`个字节，`utf8`中一个汉字`3`个字节

- `ASCII`编码
- `GB2312`
- `GBK`
- `GB18030`
- `Unicode`
- `UTF-8`

`Node`中不支持`GBK`编码，我们需要将`GBK`转为`UTF8`编码

```
var iconv = require('iconv-lite');
function readGBKText(pathname) {
    var bin = fs.readFileSync(pathname);
    return iconv.decode(bin, 'gbk');
}
```

在服务端，我们需要一个东西可以来标识内存 。但是不能是字符串，因为字符串无法标识图片；
node中用Buffer来标识内存的数据，他把内容转换成了16进制来显示 （16进制比较短）
