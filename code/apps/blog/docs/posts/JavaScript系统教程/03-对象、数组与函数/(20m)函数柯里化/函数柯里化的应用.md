# 函数柯里化的应用

> 本节目标：理解“函数柯里化的应用”的核心思路，并能把它用于实际开发或面试表达。
参数复用
通过柯里化，可以固定一些参数，生成新的函数，简化后续的调用。
function multiply(a, b, c) \{
return a * b * c;
\}
function curry(func) \{
return function curried(...args) \{
if (args.length \>= func.length) \{
return func.apply(this, args);
\} else \{
return function(...nextArgs) \{
return curried.apply(this, args.concat(nextArgs));
\};
\}
\};
\}
let curriedMultiply = curry(multiply);
// 创建一个新的函数，将第一个参数固定为 2
let multiplyByTwo = curriedMultiply(2);
console.log(multiplyByTwo(3, 4)); // 输出: 24
console.log(multiplyByTwo(5, 6)); // 输出: 60
在这个例子中，`multiplyByTwo` 函数将 `multiply` 函数的第一个参数固定为 `2`，从而简化了后续的调用。

延迟计算
通过柯里化，可以在不同的时间点传递参数，延迟函数的执行。
function add(a, b) \{
return a + b;
\}
let curriedAdd = curry(add);
// 延迟传递第二个参数
let addFiveLater = curriedAdd(5);
console.log(addFiveLater(10)); // 输出: 15
console.log(addFiveLater(20)); // 输出: 25
在这个例子中，`addFiveLater` 函数在初次调用时只传递了一个参数 `5`，第二个参数在后续调用时才传递，实现了延迟计算。

函数组合
柯里化可以与其他函数式编程技巧结合，构建更复杂的功能。例如，结合函数组合（compose）来创建一个数据处理管道。
function compose(...funcs) \{
return function (initialValue) \{
return funcs.reduceRight((acc, func) =\> func(acc), initialValue);
\};
\}
function add(a) \{
return function (b) \{
return a + b;
\};
\}
function multiply(a) \{
return function (b) \{
return a * b;
\};
\}
function subtract(a) \{
return function (b) \{
return b - a;
\};
\}
let addFive = add(5);
let multiplyByTwo = multiply(2);
let subtractThree = subtract(3);
let process = compose(subtractThree, multiplyByTwo, addFive);
console.log(process(4)); // 输出: 13
在这个例子中，我们创建了一个 `compose` 函数，用于组合多个函数。每个函数都使用柯里化，使得可以逐步传递参数并构建一个复杂的处理管道。最终，`process` 函数将按照 `addFive`、`multiplyByTwo` 和 `subtractThree` 的顺序处理输入值。

总结
柯里化不仅可以固定参数和延迟计算，还可以与其他函数式编程技巧结合使用，创建更加灵活和可组合的函数。通过具体的代码示例，可以更好地理解柯里化的应用场景和优势。
