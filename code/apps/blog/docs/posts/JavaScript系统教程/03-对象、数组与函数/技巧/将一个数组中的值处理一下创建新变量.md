# 将一个数组中的值处理一下创建新变量

> 本节目标：理解“将一个数组中的值处理一下创建新变量”的核心思路，并能把它用于实际开发或面试表达。
if (selectedDate[0]) \{
startTime = moment(selectedDate[0]).format(ymdhms);
\}
if (selectedDate[1]) \{
endTime = moment(selectedDate[1]).format(ymdhms);
\}

直接遍历数组，然后解构赋值：
const [startTime, endTime] = selectedDate.map((date) =\>
date ? moment(date).format(ymdhms) : ""
);
