# 中的元字符

> 本节目标：理解“中的元字符”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
var regexEscapeRE = /[-.*+?^$\{\}()|[\]\/\\]/g;
除了

- 右中括号]，因为会误认为是]结束符
- 反斜杠\，因为需要转义符，要不然怎么表示右中括号]呢
- 斜杠/，目前看起来不用转义也可，可能是考虑操作系统：

其它元字符在中括号[]中就表示字符本身

放在js正则表达式字符组[]中的｜，有什么特殊用处吗
在正则表达式中，| 符号表示逻辑"或"（OR），用于表示两个或多个模式之间的选择。然而，在字符组（[]）内，| 符号不具有特殊含义。在字符组内，| 只是表示字面值的竖线字符。
例如，考虑以下正则表达式：

- /a|b/：匹配字符 a 或字符 b。
- /[a|b]/：匹配字符 a、字符 b 或字符 |，在这里 | 仅作为一个普通字符。

所以，如果你在字符组中使用了 |，并期望它具有特殊功能，请检查你的正则表达式以确保使用正确。在字符组内部，您通常不需要 |，因为字符组本身表示匹配其中任何一个字符。
