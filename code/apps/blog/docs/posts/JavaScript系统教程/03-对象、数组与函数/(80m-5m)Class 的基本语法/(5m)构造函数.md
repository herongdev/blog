# 构造函数

> 本节目标：理解“构造函数”的核心思路，并能把它用于实际开发或面试表达。
```
constructor方法就是构造方法，等同于es5的构造函数。
```

```
**this**
constructor中的this同样也是代表实例对象。
```

```
**特点**
1、必须有：一个类必须有constructor方法；
2、没定义则为空：如果没有显式定义，一个空的constructor方法会被默认添加。
3、创建时自动调用：通过new命令生成对象实例时，自动调用constructor方法。
class Point {}
// 等同于class Point {  constructor() {}}
```

```
**返回**
1、constructor方法默认返回实例对象（即this）；
2、也完全可以指定返回另外一个对象。
class Foo {  constructor() {    return Object.create(null);  }}
new Foo() instanceof Foo// false
```
