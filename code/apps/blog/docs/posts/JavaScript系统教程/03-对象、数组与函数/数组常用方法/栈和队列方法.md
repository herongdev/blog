# 栈和队列方法

> 本节目标：理解“栈和队列方法”的核心思路，并能把它用于实际开发或面试表达。
push()：可以接受任意数量的参数，把它们逐个添加到数组末尾，并返回数组的长度length。

pop()：方法无参数，它从数组末尾移除最后一项，然后返回移除的项。

```
shift()方法：无参数，可以移除数组的第一项，并返回改项。
```

unshift()方法：接受任意多个参数值，它保持参数传递时的顺序把它们添加进数组前端，并返回添加参数值后的长度length。
