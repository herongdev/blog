# 位置方法

> 本节目标：理解“位置方法”的核心思路，并能把它用于实际开发或面试表达。
ECMAScript 5 新增
**indexOf()****和****lastIndexOf()**
该方法接收两个参数，要查找的项和（可选的）查开始项的索引。
其中indexOf()从数组的开头向后查找；lastIndexOf()则从数组末尾向前查找。
两个方法都返回要查找项在数组中第一次出现的索引，如果在数组中没有找到该项，则返回-1。

注意：在比较要查找的项和数组中的每一项时，使用的是精确相等（===）操作符。
