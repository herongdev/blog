# Global对象

> 本节目标：理解“Global对象”的核心思路，并能把它用于实际开发或面试表达。
```
Global对象可以说是ECMAScipt中最特别的一个对象了。
```

```
因为不管从什么角度上看，这个对象都是不存在的。
```

```
不属于任何其他对象的属性和方法，都是Global对象的属性。
```

```
诸如isNaN()、isFinite()、parseInt()以及parseFloat()，实际上都是Global对象的方法。
```
