# 属性的简洁表示法

> 本节目标：理解“属性的简洁表示法”的核心思路，并能把它用于实际开发或面试表达。
ES6 允许在大括号里面，直接写入变量和函数，作为对象的属性和方法。这样的书写更加简洁。这时，属性名就是变量名, 属性值就是变量值。

```
**属性简写**
const foo = 'bar';const baz = {foo};baz // {foo: "bar"}
// 等同于const baz = {foo: foo};
```

```
function f(x, y) {  return {x, y};}
// 等同于
function f(x, y) {  return {x: x, y: y};}
f(1, 2) // Object {x: 1, y: 2}
```

```
**方法简写**
const o = {  method() {    return "Hello!";  }};
// 等同于
const o = {  method: function() {    return "Hello!";  }};
```
