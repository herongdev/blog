# 函数表达式

> 本节目标：理解“函数表达式”的核心思路，并能把它用于实际开发或面试表达。
定义函数除了使用函数声明，还可以使用函数表达式。
函数表达式是JavaScript中的一个既强大又容易令人困惑的特性。

函数可以作为一个值，赋值给一个变量或作为函数的返回值或作为对象的属性值或函数参数；

函数声明function关键字后如果没有函数名，即name为空白字符串时，叫匿名函数。

```
当函数作为一个值使用时，可以为匿名函数。
```

函数如果定义了就立即执行，不需复用的话，也可以是匿名函数。

```
**函数表达式**
```

当把一个函数作为一个值赋值给一个变量时，就是一个函数表达式；

```
作为值的函数可以是匿名函数，也可以是命名函数。
```

```
分别叫做匿名函数表达式和命名函数表达式。
```

```
**不存在变量提升**
例如，执行以下代码的结果可能会让人意想不到，因为不同浏览器处理方式不一样：
// 不要这样做
if (condition) {
    function sayHi() {
        console.log('Hi')
    }
} else {
    function sayHi() {
        console.log('Yo!')
    }
}
不过，如果是使用函数表达式，那就没有什么问题了。
// 可以这样做
var sayHi;
if (condition) {
    sayHi = function () {
        alert("Hi!");
    };
} else {
    sayHi = function () {
        alert("Yo!");
    };
}
```

```
**函数表达式的函数名**
```

如果是匿名函数表达式，函数的name属性会被赋值为变量名；当这个函数再次被赋值给其它变量时，这个name值不会再改变；

如果是命名函数表达式，则函数的名称就是function关键字后面的函数名；

:::
