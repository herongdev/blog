# RegExp实例方法

> 本节目标：理解“RegExp实例方法”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
主要方法是exec():
该方法专门为捕获组而设计的。
它接收一个参数，即要应用模式的字符串，然后返回包含第一个匹配项信息的数组；或者在没有匹配项的情况下返回null。

返回的数组虽然是Array实例，但包含两个额外的属性：index和input。其中index表示匹配项在字符串中的位置，而input表示应用正则表达式的字符串。在数组中，第一项是整个模式匹配的字符串，其他项是与模式中的捕获组匹配的字符串（如果模式中没有捕获组，则该数组只包含一项），如下：

注意：对于exec()方法而言，在不设置全局模式的情况下，在同一个字符串上多次调用exec()将始终返回第一个匹配项的信息。如果设置了全局标志（g)，它每次也只会返回一个匹配项。但每次调用exec()则都会记录上次结束查询时的位置lastIndex，再次调用方法时会从lastIndex位置继续查询新匹配项，直到查找到字符串末尾为止。如下：
