# 属性类型

> 本节目标：理解“属性类型”的核心思路，并能把它用于实际开发或面试表达。
`ECMAScript`中有两种属性：数据属性和访问器属性。

特性`(attribute)`

- 用来描述属性`(property)`
- 是为了实现`JavaScript`引擎用的
    - 不能直接访问它们
    - 用两对儿方括号表示是内部值，如`[[Enumerable]]`。
