# 工厂模式：直接调用工厂函数返回对象

> 本节目标：理解“工厂模式：直接调用工厂函数返回对象”的核心思路，并能把它用于实际开发或面试表达。
实际上是对Object 构造函数创建对象的一种封装。

```
function createPerson(name, age, job) {
    var o = new Object();
    o.name = name;
    o.age = age;
    o.job = job;
    o.sayName = function () {
        alert(this.name);
    };
    return o;
}
var person1 = createPerson("Nicholas", 29, "Software Engineer");
var person2 = createPerson("Greg", 27, "Doctor");
```

工厂模式问题：

- 无法共享所有实例属性值相同的属性。
- 没有解决对象识别的问题，都是Object类型，无法再细分。
