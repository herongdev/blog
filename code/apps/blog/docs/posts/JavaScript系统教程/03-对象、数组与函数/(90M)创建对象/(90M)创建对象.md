# 创建对象

> 本节目标：理解“创建对象”的核心思路，并能把它用于实际开发或面试表达。
任何语言都要保存数据，会有各种数据类型，每种数据类型就是一个类，具体的值就是这个类的实例。

定义类来创建对象的过程中，要考虑一些问题：
一、如何分离共享属性和差异属性：

- 共享属性只存储一份，所有实例共享。
- 而差异属性则同名不同值。
    - 差异属性通过传参解决。
    - 共同属性通过原型对象共享。
- 如何区分对象类型。
- 实例修改自身属性不影响原型对象，从而不影响其它实例。
