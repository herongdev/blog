# 转换规则

> 本节目标：理解“转换规则”的核心思路，并能把它用于实际开发或面试表达。
```
BigInt转为布尔值：使用Boolean()或取反运算符（!）
```

```
Boolean(0n) // falseBoolean(1n) // true!0n // true!1n // false
```

```
转数值：使用Number()，后缀n会消失
```

```
Number(1n)  // 1
```

```
转字符串：使用String()，转为字符串时后缀n会消失。
```

```
String(1n)  // "1"
```
