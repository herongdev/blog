# While Loops

> 本节目标：理解“While Loops”的核心思路，并能把它用于实际开发或面试表达。
`Iterate with JavaScript While Loops`
另一种类型的 `JavaScript` 循环被称为`while`==循环==，因为它规定，当（`while`）条件为真，循环才会执行，反之不执行。

```
var ourArray = [];
var i = 0;
while(i < 5) {
ourArray.push(i);
i++;
}
```

 myArray
