# 特殊字符

> 本节目标：理解“特殊字符”的核心思路，并能把它用于实际开发或面试表达。
`U+202E` 是一个特殊的 `Unicode` 字符，可以这个字符后面的字符串从右到左显示。很多病毒软件就利用这个特性，诱骗用户点击，比如 `foofdp.exe` 这个文件名，只要在`foo`后面插入该字符，就会显示成 `fooexe.pdf`。
 \> 来自

```
 <https://www.ruanyifeng.com/blog/2022/06/weekly-issue-211.html>
```

`Javascript`中的特殊字符一共有`13`个，建议都进行转义处理，如下：

|   |   |   |   |
|---|---|---|---|
|`Unicode` **字符值**|**转义序列**|**含义**|**类别**|
|`\u0008`|`\b`|`Backspace`||
|`\u0009`|`\t`|`Tab`|空白|
|`\u000A`|`\n`|换行符（换行）|行结束符|
|`\u000B`|`\v`|垂直制表符|空白|
|`\u000C`|`\f`|换页|空白|
|`\u000D`|`\r`|回车|行结束符|
|`\u0022`|`"`|双引号 `(")`||
|`\u0027`|`'`|单引号 `(')`||
|`\u005C`|`\`|反斜杠 `()`||
|`\u00A0`||不间断空格|空白|
|`\u2028`||行分隔符|行结束符|
|`\u2029`||段落分隔符|行结束符|
|`\uFEFF`||字节顺序标记|空白|
