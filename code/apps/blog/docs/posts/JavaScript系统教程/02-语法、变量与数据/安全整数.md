# 安全整数

> 本节目标：理解“安全整数”的核心思路，并能把它用于实际开发或面试表达。
JavaScript 能够准确表示的整数范围在-2^53到2^53之间（不含两个端点），超过这个范围，无法精确表示这个值。
Math.pow(2, 53) // 9007199254740992
9007199254740992  // 90071992547409929007199254740993  // 9007199254740992
Math.pow(2, 53) === Math.pow(2, 53) + 1// true
上面代码中，超出 2 的 53 次方之后，一个数就不精确了。

```
Number.MAX_SAFE_INTEGER和Number.MIN_SAFE_INTEGER两个常量，用来表示安全整数个范围的上下限。
```

```
可以用Number.isSafeInteger()方法来判断一个值是否是安全整数。
```
