# 变量提升题

> 本节目标：理解“变量提升题”的核心思路，并能把它用于实际开发或面试表达。
```
var a = 1;
test();
function test() {
console.log(a);
var a = 2;
console.log(a);
}
```

```
var a = 1;
b = function a(x) {
x && a(--x);
};
console.log(a);
console.log(b);
```
