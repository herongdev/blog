# 去掉首尾空白字符

> 本节目标：理解“去掉首尾空白字符”的核心思路，并能把它用于实际开发或面试表达。
```
**trim()****，****trimStart()****，****trimEnd()**
trim()消除字符串头尾部的空格；
trimStart()消除字符串头部的空格；
trimEnd()消除尾部的空格。
参数：除了空格键，这两个方法对字符串头部（或尾部）的 tab 键、换行符等不可见的空白符号也有效。
返回：它们返回的都是新字符串，不会修改原始字符串。
const s = '  abc  ';
s.trim() // "abc"s.trimStart() // "abc  "s.trimEnd() // "  abc"
```

```
**注意：**
trimLeft()是trimStart()的别名，trimRight()是trimEnd()的别名。
```
