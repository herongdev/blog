# 检测数据类型

> 本节目标：理解“检测数据类型”的核心思路，并能把它用于实际开发或面试表达。
```

==返回值：====返回值是一个==**字符串**==，有时候在浏览器里会把引号省略掉，但是可以用====typeof====去检测这个返回值，比如==
```

`Instanceof`
用法：`instanceof`是一个操作符，返回值是一个布尔值；`instanceof`是检测引用数据类型，而不能检测基本数据类型；但是只要是在原型链上出现过构造函数都会返回`true`，所以这个检测结果不很准确。

**不足：**
不能检测基本数据类型
==var== ==arr = [];========arr== ==instanceof== ==Array====;====//true======
==arr== ==instanceof== ==Object====;====//true======
