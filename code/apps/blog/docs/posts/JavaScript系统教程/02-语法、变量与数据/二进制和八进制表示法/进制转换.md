# 进制转换

> 本节目标：理解“进制转换”的核心思路，并能把它用于实际开发或面试表达。
**转十进制**
如果要将0b和0o前缀的字符串数值转为十进制，要使用Number方法。
Number('0b111')  // 7Number('0o10')  // 8
