# 二进制和八进制表示法

> 本节目标：理解“二进制和八进制表示法”的核心思路，并能把它用于实际开发或面试表达。
```
ES6中：
二进制：用前缀0b（或0B）
八进制：用前缀0o（或0O）
0b111110111 === 503 // true0o767 === 503 // true
```

```
**注意：模式中的八进制**
在ES5的严格模式之中，八进制就不再允许使用前缀0表示，要使用前缀0o表示。
// 非严格模式(function(){  console.log(0o11 === 011);})() // true
// 严格模式(function(){  'use strict';  console.log(0o11 === 011);})() // Uncaught SyntaxError: Octal literals are not allowed in strict mode.
```
