# 写一个每次执行自增1的函数

> 本节目标：理解“写一个每次执行自增1的函数”的核心思路，并能把它用于实际开发或面试表达。
```
let fn = (function add() {
var i = 0;
return function () {
i++;
console.log(i);
}
})()
```

；

```
fn();
fn();
fn();
fn();
fn();
```

```
function add() {
var i = 0;
return add = function () {
i++;
console.log(i);
}
}
add();
add();
add();
add();
add();
```
