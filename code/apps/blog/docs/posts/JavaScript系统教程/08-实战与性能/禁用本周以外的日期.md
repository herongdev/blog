# 禁用本周以外的日期

> 本节目标：理解“禁用本周以外的日期”的核心思路，并能把它用于实际开发或面试表达。
pickerOptions() \{
const now = new Date();
let startDay = now.getDay();
let startOfWeek = new Date(now);
startOfWeek.setDate(now.getDate() - startDay + 1); // 获取周一
startOfWeek.setHours(0, 0, 0, 0); // 设置为当天的00:00:00
let endOfWeek = new Date(now);
endOfWeek.setDate(now.getDate() + (7 - startDay)); // 获取周日
endOfWeek.setHours(23, 59, 59, 999); // 设置为当天的23:59:59
const disabledDate = (time) =\> \{
return (
time.getTime() \< startOfWeek.getTime() ||
time.getTime() \> endOfWeek.getTime()
);
\};
return \{ firstDayOfWeek: 1, disabledDate \};
\},
