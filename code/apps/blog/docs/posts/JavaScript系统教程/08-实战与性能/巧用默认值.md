# 巧用默认值

> 本节目标：理解“巧用默认值”的核心思路，并能把它用于实际开发或面试表达。
有时候，我们要对某个值进行操作；
但是，这个值在第一次有可能不存在；
一般情况下，我们会写一个`if`判断，先看有没有，没有就给个默认值，进行一些操作，有的情况下，就直接进行操作；
但是，`if`判断代码较长，我们可用默认值；

- 如果有的话用已有值，否则取默认值；
- 然后对取到的值进行操作；

举例：以下的`currGas.statusMap`属性第一次是没有的，我们要给他加上一些属性值；

```
currGas.statusMap = currGas.statusMap || {}
currGas.statusMap[devId] = status === "
```

离线

```
" ? "
```

离线

```
" : currGas.warningLevel;
```
