# HR 小象 Logo 精修与项目替换

日期：2026-11-03。状态：代码、矢量资产和本地预览已完成；未执行线上发布。

## 最终设计与源文件

在已选的蓝紫浅立体方案上精修：保持平背与同色象鼻；毯子收窄并与 H 下方留白对齐；D 形耳面与鼻子共同提示 R；弱化阴影，只保留轻微渐变、毯边和细小眼线。小尺寸优先保证 HR 与象鼻轮廓。

仓库根目录（不是 code/）的 `logo.svg` 是唯一可编辑母版。它使用真正的 SVG 路径、渐变与分组，没有嵌入位图、脚本或外链。根目录同时提供 `logo-light.svg`、`logo-dark.svg` 和精简细节的 `logo-icon.svg`。

浅色背景使用较深的蓝紫主体；深色背景使用较亮的蓝紫主体，毯子和耳面降低明度，保持字母内部区域的对比。页面品牌随网站手动主题切换；独立 SVG 和浏览器 favicon 按系统主题调整。分享图为 512px PNG，Apple 图标为 180px PNG，使用中性浅色底。

## 维护方式

在 code/ 下执行：

```sh
pnpm run brand:generate
pnpm run check:brand
pnpm run check:chrome
```

`scripts/generate-brand-assets.mjs` 从母版生成主题、微型图标与 PNG，并同步到各应用；共享包生成自包含 data URL。42 项输出进行字节一致性校验。PNG 与母版哈希写入品牌清单。只包含 code/ 的打包环境使用共享包内母版副本。主站构建前加入品牌一致性校验，静态合并的共享文件仍必须字节完全一致。
