# 制作工作台入口合并

日期：2026-11-10（Asia/Shanghai）。用户指出「制作流程」与「选题与拍摄」重复，审核合并方案后要求调整一版查看，以使用方便为准。本轮制作本地可运行预览，不将上轮首版上线记录当作本轮版本已部署。

## 用户任务与布局依据

使用者需要安排本周做什么、打开一条内容继续当前阶段、核对原资料并查看实际文章和成片。重复维护两套目标和提纲会使状态及内容冲突。

实施前在已运行的 Microsoft Edge 原有窗口打开新标签，实际查看 [Linear Projects 官方页面](https://linear.app/docs/projects) 及其中项目概况截图：同一项目集中展示状态、属性和资源，以视图组织同一批内容。本轮沿用这一信息结构，保留写作台语义 tokens、明暗主题、Radix 与 Lucide，不复制参考产品颜色或样例数据。Frame.io 官方审阅页面仅做文本核对，不记为其界面截图验收。

## 合并规则

- 顶层收敛为制作、内容库和发布中心；制作提供本周排期与全部进度视图，保留目录、搜索、历史、分页和拖动。排期决定顺序，制作档案决定阶段，已拍不等于成片通过或作品已公开。
- 内容内只保留一个制作入口，旧 filming 页签值兼容跳转到制作。文章、视频、制作素材、发布和更新记录继续负责对应任务，切换时保留制作稿及正文。
- 旧 `.filming.json` 的四个文本字段和完整调研来源保留。制作内按需阅读原文，显式引用只进入空白阶段的本地草稿，已有稿件和未保存输入不覆盖，不自动保存、检查或确认。目标与提纲不按字段名机械拆为已核实结论。
- 建立制作档案前不重复填写学习目标；在对应阶段编辑。配套文章阶段关联实际文章版本并保存核对记录，正文继续在文章编辑器维护。成片和素材使用现有文件管理入口。
- 有制作档案后，旧拍摄准备 PATCH 返回 409 并提示先复制输入再刷新；读取和未建档的旧写入接口保持兼容。研究导入工具直接使用原 store，未改变其行为。原鉴权、Origin 和 CSRF 检查保持在业务路由之前。
- 不迁移真实课程、不覆盖旧稿或规则快照、不把旧资料存在视为验收通过，不触发网站发布或平台投稿。
