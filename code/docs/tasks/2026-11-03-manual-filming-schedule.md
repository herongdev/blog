## 实现

- 后端 schema v2：v1 升级保留条目、已拍与历史，本周按已拍/待拍稳定分组（各组原相对顺序不变），其它与历史顺序不变；新建排期本周为空。新周归档实际排过的旧周，未拍回其它最前，新本周为空，不自动补题。
- 沿用作者 `/api/schedule` 与 `/api/schedule/actions`，增加原子 `transfer`（目标组 `current` / `queue`、1-based 完整列表位置、revision）；原 `move` / `pull` / `defer` 兼容。废弃 `cadence` 返回 410；公开响应不再包含配额或下周模型。
- 前端共享拖动上下文、两组落点、空组接收、按钮替代操作；分页与筛选后按完整队列定位。拖动提交以开始时的版本及快照为准，避免后台刷新与旧手势混用。
- 保留新建素材、添加已有文章、标题搜索、分页、已拍/撤销、历史、稿件缺失与冲突处理。已拍条目先撤销再退回，避免移组丢失完成记录。
- 已拍行禁止排序，标记已拍追加到已拍区末尾，撤销后回到待拍区开头；拖动、按钮、指定位置与旧 API 均不能把待拍条目插在已拍前。后端将合法的越界待拍位置归到待拍区首，已拍排序请求返回 400，避免误报版本冲突。
- 同步作者 README 与 UI 约定。既有发布中心等无关未提交变更不纳入本任务。
