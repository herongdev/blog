# 写作台共享 UI 控件

日期：2026-11-10（Asia/Shanghai）。用户确认将 token 进一步落实到统一组件，先覆盖制作、内容库与发布中心；随后要求补完浅色、窄屏和其它页面验收，确认无问题后部署。已上线 `20261110T110945Z`，部署与数据保护证据见 [上线记录](2026-11-10-author-ui-release.md)；本文保留本地实现与验收矩阵。

## 范围与依据

沿用已有语义配色、主题、Lucide、Radix 和用户已验收的制作工具栏排列，统一普通单行控件的 36px 桌面 / 44px 窄屏或粗指针规格。参考既有 GitHub Actions 紧凑工具栏布局及 [Radix Playground](https://www.radix-ui.com/themes/playground#text-field) 的输入、选择、按钮与禁用状态组织；本轮 Edge 打开官方页面并读到实际控件树，但截图采集为灰色，不将其记录为取得参考画面或新版视觉验收通过。

## 实现

- `AuthorUI` 提供 Input、Textarea、Field、SearchField、Toolbar，并导出 `AuthorButton` / `AuthorButtonLink`。已有 `IconButton` 和 Radix `AuthorSelect` 接入同一控件基础。
- `author-ui.css` 独占尺寸、字号、行高、内边距、边框、焦点和禁用状态。单行控件使用含边框固定高度；多行表单自然增高，标题、摘要、Markdown 和制作正文保留专用编辑方式。
- 普通动作默认 button，表单提交保留显式 submit，下载和跳转仍为链接。保留原生 props、事件、ref 及 Radix asChild，字段关联可见标签与持久错误，帮助继续使用 tooltip。
- 迁移三个工作区与相关创建、更新、目录、排期、登录表单的常用控件，删除相应重复 CSS。文件/复选框、整行目录与版本选择、内容导航继续保持业务语义与布局。
- 共享制作搜索及工具栏移入通用组件，原导出名兼容；不重置排期与进度视图状态，不改变 API、任务身份、上传或发布逻辑，不写入真实内容。
- `check-author-controls.mjs` 使用现有 TypeScript 解析器检查 JSX，阻止普通原生输入、原生 select、旧按钮类及页面对共享控件直接改高度、上下内边距和字体。正反例自测与扫描接入作者 build；不扫描其它应用，不添加依赖。动态类映射、函数选择器和最终渲染尺寸不在此静态检查范围。

### 验收中修正并复核

- **搜索清空焦点：**共享搜索使用内部 input ref 并保留外部 ref，清空后焦点返回原输入框，可继续输入；只读和禁用输入的清空按钮不执行修改。已做清空后的焦点回归核对。
- **帮助层级：**`--author-layer-help` 由 90 调整为 130，高于 workspace 弹窗的 100/101 及选择层 120，低于 toast 140。实际检查弹窗中的“检查依据”说明已在遮罩与弹窗上方显示，未再被盖住，见上述 tooltip 截图。
- **320px 弹窗动作栏：**新建选题和创建更新的底部按钮曾在窄屏挤占宽度，公共对话框动作栏及排期弹窗采用可换行布局，更新弹窗不再强行等分撑宽。实际复验见 [新建选题](evidence/2026-11-10-author-ui-review/mobile-light-create-topic.jpg) 与 [创建更新](evidence/2026-11-10-author-ui-review/mobile-light-create-update.jpg)，对应尺寸记录未出现页面横向滚动。
- **长文本：**发布确认、发布详情与登录描述补充 `overflow-wrap: anywhere`，保护允许输入的长英文标题、账号别名；没有修改文案、账号或业务状态。该项经过代码和静态约束检查，真实平台账号登录描述未单独触发。
- 记录中的普通桌面控件为 36px，窄屏为 44px；桌面拖动等显式 `touch` 行操作仍为 44px，textarea 为自然高度，这些差异符合尺寸语义。

### 测量记录的例外与边界

`measurements.json` 保留 40 条原始观测。第 9 项 `320-light-content-production-empty` 在异步页签切换尚未完成时捕获了文章 DOM，标签不能作为制作页验收；其中唯一的 1000px textarea 是 CodeMirror 的输入辅助层，文档 `scrollWidth` 仍为 320。该项既不计制作页通过，也不删除原始记录。后续显式绑定标签、排除 CodeMirror 辅助层的 `320-light-production-empty` 为实际制作空态复验；其余 39 条记录的 `scrollWidth` 与视口宽度一致、`overflow` 数组为空。实际文章桌面及窄屏页面也另有截图和 DOM 记录，不据辅助层误判页面存在横向滚动。

实际渲染和交互验收补齐后，本地 `/admin/` 构建、类型检查、共享 UI 扫描与自测、配色及对比度检查通过，完整作者测试仍为 **304/304**。本地发布执行服务未配置，平台发布仅检查页面空态、禁用状态及错误校验；没有以此宣称真实平台扫码、身份验证、投稿或作品公开通过。未进行 iOS / Android 真机验收，浏览器窄屏模拟不代替真实手机。随后完成服务器测试、备份、激活及公网检查，见 [上线回执](2026-11-10-author-ui-release.md)。
