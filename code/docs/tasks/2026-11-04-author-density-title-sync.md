# 写作台空间利用与标题同步

日期：2026-11-04，Asia/Shanghai。

## 需求与参考

用户要求压缩 `/admin/` 的重复留白，避免少量内容独占一行，将解释性文字放入 tooltip；排期进入编辑器后修改标题，保存后必须同步到内容库和当前排期。

实现前实际查看 [WordPress 官方编辑器总览截图](https://wordpress.org/documentation/files/2019/03/block-editor-overview-6.7-1024x579.jpg) 和 [Strapi 官方草稿编辑截图](https://docs.strapi.io/img/assets/content-manager/editing_draft_version3.png)。采用 WordPress 的集中工具栏与正文紧接布局，结合 Strapi 的工作稿、线上版及版本历史结构。保留当前语义 token、明暗主题与 Lucide，没有复制参考产品的颜色或业务数据。

## 实现

- 返回、文章/视频/制作素材/发布页签、内容状态和刷新共用顶部一组；文章版本、目录位置、保存状态与保存按钮共用第二组。
- 标题、摘要按实际内容增高，减少固定留白；工具、目录和添加截图同行。内容库、视频、制作素材、发布中心使用相同的紧凑控件及较小间距。
- 桌面控件基准 36px，窄屏及粗指针恢复 44px；保留正常正文、长标题换行和错误/未保存/上传进度。
- 解释性文字改为帮助气泡，支持悬停、键盘焦点、点击、Escape、外点关闭以及视口边界定位；不使用只有原生 title 的提示。
- 保存成功后立即更新当前列表及排期缓存；返回排期时读取权威状态。刷新中的旧响应失效，取得新 revision 前不提交排期调整。重登录列表也经过同一请求序号保护。未保存标题不进入列表，历史排期标题继续冻结。
