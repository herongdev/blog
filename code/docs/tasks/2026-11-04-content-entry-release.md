## 用户可见变化

“内容库 → 我的内容 → 添加”提供添加文章、添加视频、添加资源。创建仅必填标题，自动生成地址，可选自定义。创建后进入相应页签，视频/资源无需先写正文。已有条目及排期更多菜单直接进入同一内容的写文章、添加视频、添加资源、发布与记录，不另建重复条目。

本次一起上线 11 月 3 日实现但此前未上线的文章、视频、制作素材、发布工作区，保留成片版本、私有分片上传、工程说明、原字节下载及 ZIP 包。保存、上传、发布仍是独立动作。三种入口共用现有稳定内容身份；没有新建第二套后台或公开资源库。

编码前实际查看 Strapi 官方 Media Library 与 Content Manager 草稿截图，采用固定添加菜单、条目更多菜单及统一内容身份，保留项目布局、语义 token、Radix、Lucide 和明暗主题。参考图片：`/tmp/author-entry-strapi-media.png`、`/tmp/author-entry-strapi-draft.png`；官方出处沿用 [内容工作区设计](2026-11-03-content-workspace-design.md)。
