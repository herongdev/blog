# AI 配套文章与完整 Markdown 导入

日期：2026-11-05（Asia/Shanghai）。作者后台与新模板已上线，云端 Skill 已保存并重新下载核对。未启用 GPT 直送插件。

## 用户目标与交互依据

让「开发者知识微课制作」Skill 随视频生成包含文章信息头的完整 Markdown。作者审稿、让 AI 修正后，将整篇文章复制或导入后台，不再逐项重填版本、平台、来源、搜索线索和实测记录。没有真实证据时省略实测记录，不能用模板值或推测凑齐。

沿用 [内容工作区设计](2026-11-03-content-workspace-design.md) 已核验的 Strapi 工作稿/线上版分工，复用项目现有 Radix 对话框、配色、主题和 Lucide 图标。导入、保存工作稿和发布保持独立操作。

## 已实现

- 编辑区增加「导入 Markdown」，支持选择 `.md` / `.markdown` 文件或粘贴全文。正文编辑器粘贴以 YAML 信息头开头的完整文档时，转入同一个导入预览；普通正文片段保持原粘贴行为。
- 预览展示标题、摘要、工具、内容类型、来源、日期、实测记录及缺项。确认后只应用到当前工作稿，仍需手动保存；取消保留原稿。导入期间不通过快捷键保存旧稿。
- 完整信息头替换原有元数据，避免继承旧模板的 TODO。缺少 `tool` 时仅沿用当前工具，缺少 `status` 时默认为 `draft`；只导入正文时原元数据保持不变。
- 兼容旧字段 `description → summary`、`updated/date → updatedAt`、`tags → keywords`，canonical 字段优先。YAML 锚点引用展开为实际值，兼容字段删除后引用仍有效；错误 YAML、重复键、非法字段类型、日期、工具、主题及循环引用会在应用前报错。
- 当前内容的 `kind`、`slug`、revision 和关联身份不被原稿覆盖。导入预览后若当前工作稿已变化，拒绝覆盖；导入的 `slug` 不改变文章地址。
- 正文保留资源相对路径，不自动上传或改写本地图片、SVG、视频及附件；发现本地引用时提醒另行上传。单篇输入及引用展开后的文档上限均为 2 MiB。
- 「发布信息」默认收起；高级字段继续可编辑。新工作稿模板改为干净的最小草稿，不再预填 TODO、示例来源、占位日期或亲测结论；没有批量重写旧稿。
- 实际渲染时发现工具标签被下拉控件挤成两行，补上标签不可压缩/不折行，操作按钮在空间不足时自然换行，保持紧凑工具栏。

主要代码位于 `code/apps/dev-guides/author/src/markdown-import.ts`、`App.tsx`、`RichEditor.tsx`，模板为 `code/apps/dev-guides/templates/tutorial.md`。沿用现有鉴权、保存接口和发布校验，本次未新增机器写入接口。
