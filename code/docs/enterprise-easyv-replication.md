# 政企领域 18 个 EasyV 参考 demo：逐项复刻记录

日期：2026-09-23。本记录用于逐项开发与验收，不表示 EasyV 的原演示已可访问，也不表示任何项目已复刻完成。

## 范围与入口

- 待处理清单以 `code/apps/enterprise-showcase/stage.json` 中 18 个带 `reference.url` 的项目为准：六个分类，每类三个。自有的汽车采样站另算，不在这 18 项里。
- 用户给出的 `https://easyv.cloud/market?sid=158852` 是素材广场入口，不是 18 个演示之一的直达地址。每项应以卡片所指向的 `https://easyv.cloud/m/market/<id>.html` 为公开详情来源，再核对其真正的预览/演示入口。
- 领域页保持 `https://herong.info/projects/enterprise/`。完成的一项 demo 放到 `/projects/enterprise/<项目标识>/`，卡片只在 demo 实际可用且验收后改为本站入口；原作链接与来源标识继续保留。
- 第一阶段先处理可观察、可操作的非 3D 项目；3D 模型、相机、拾取和动画统一放到后续逐项处理。不能把静态封面或录像称为交互 demo。
- `sources.json` 记录来源与素材哈希，未收录再分发许可或授权证明；原作可访问、已登录或已有下载文件均不等于获得复制发布授权。当前 18 项继续标为“参考案例”并链接原作，不虚构何荣的项目职责或已完成的本站 demo。本轮源码校正不代表授权已补齐或重新发布。

## 每项执行顺序

1. 在有权访问的源站会话中记录 demo URL、视口、初态截图、资源、数据来源，以及每个可见控件的操作前后结果。登录弹窗、无权限或仅有静态预览图时，记录为缺证据，不推测业务行为。
2. 用 `web-replica` 的 `project-discover` 保存初始来源证据；再建立独立基线、语义区域和可重复的交互断言。原始抓取、夹具干预、排除项和缺失资源显式保存。
3. 在 blog 项目中建立独立 demo 候选；公共工具缺口在 `web-replica` 中修正，并用受控负例及真实站点复查。界面、交互、数据更新分别验收；像素差异率不称为还原度。
4. 本地验收完成后部署到对应二级项目路径；检查入口、刷新、桌面/手机、功能和回滚，再将领域页卡片指向本站 demo。未完成项继续指向原作详情，并明确“参考案例”。

## 第一个试点：物流配送调度可视化平台（EasyV 1250）

- 原作详情：`https://easyv.cloud/m/market/1250.html`；属于已选 18 项的“物流仓储”分类，详情标注高级版、2560×1080。
- 2026-09-23 的匿名访问只显示大屏预览图。点击“全屏预览”弹出 EasyV 登录页；素材广场的卡片点击也弹出登录页。此时尚无实际 demo 的控件、数据变化和交互证据，因此未开始把封面做成假 demo，也未改本站卡片链接。
- 继续条件：用户提供有权限的 EasyV 登录会话，或可公开访问、可操作的演示 URL。取得后重新采集，并以实际渲染确认它是否为非 3D 项目。
- 工具发现问题：素材广场的第三方脚本使 `load` 等待超时，整页截图也可能卡住。发现阶段已改为在 `DOMContentLoaded` 后采集视口；严格的正式视觉基线仍单独配置。真实站点复采结果及未完成项以独立档案记录，不用已见的静态封面代替可操作演示。
