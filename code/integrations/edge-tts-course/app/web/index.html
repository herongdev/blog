新文稿将替换当前可编辑内容，现有文稿会自动备份。按空行拆成场景，再按句子拆分；不会改写你的文字。

使用说明

  1. 改台词：左侧选场景，直接修改中间的文字，点击“保存修改”。
  2. 改停顿：修改该句的“句后最少停顿”，单位为秒。原声自带的停顿会保留。
  3. 生成：改过台词后选“生成视频”；只改停顿或画面可选“仅更新画面”。
  4. 看结果：完成后自动打开 MP4，也可点“打开成片”或“打开输出文件夹”。

修改台词时，仅重新配音受影响的完整场景；未改场景复用原声。只改停顿不会重新请求配音。文字未对应已有原声时，“仅更新画面”会停止并提示。

“当前画面”用于检查排版；字幕高亮和最终时长在生成后依据真实声音安排。导入新文本默认使用文字画面，可逐句选择已有画面。
