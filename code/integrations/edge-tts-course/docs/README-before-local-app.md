# 原声配置已核实的整片恢复工程

这不是已经生成的新有声视频。当前执行环境无法连接微软语音服务，所以本包仍需在能联网的 Mac 或其他 Python 环境执行。

## 本次已经纠正

原音色来自第一期真实制作包，而不是猜测：`zh-CN-YunxiNeural`；开场语速 `-3%`，正文 `-5%`，音高 `+0Hz`，音量 `+0%`。`evidence/` 保留第一期的原始生成脚本、配音清单和短音频参考，可复查。

整个视频只用同一个原音色，不使用 HeyGen、机械临时声、付费 API 或不明来源的 TTS 网站。不生成候选试听，不要求再次选音色。

保留新版完整台词、暖白陶土橙、HR 小象 Logo。按完整语义段生成声音，不按单个字幕短句碎片化合成；理解停顿只增加在实际词间空隙，语音不进行变速。字幕与画面根据实际语音词事件安排，不按字数伪造同步。配音不完整、声音配置不一致或脚本版本不符时，停止，不导出静音“成片”。

## 在 Mac 上执行

需要 Python 3.10 或以上版本和能访问微软 Edge 语音服务的网络。解压本文件夹，打开终端，输入 `bash `（末尾有空格），把 `start.command` 拖入终端并回车。脚本会在独立虚拟环境安装依赖；FFmpeg 没有安装时使用 imageio-ffmpeg 提供的二进制，不需要购买或配置语音 API Key。

也可在已进入该文件夹的终端执行：

```bash
bash start.command
```

成功后自动打开：`output/full-course-original-voice.mp4`。

`output/subtitles.srt` 是完整字幕，`output/actual-timing.json` 是实际时间轴。`narration/` 保留原始 MP3、真实词边界、教学停顿和原声元数据，便于后续增量修改。

失败时会保留成功生成的语义段；重新运行可复用对应缓存，不自动改声音，不会输出伪完成版。
