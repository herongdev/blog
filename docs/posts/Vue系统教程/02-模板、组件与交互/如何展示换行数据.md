# 如何展示换行数据

> 本节目标：理解“如何展示换行数据”的核心思路，并能把它用于实际开发或面试表达。
在HTML中，普通的换行符 (\n) 不会被解释为换行。在HTML中，文本换行是通过\<br\>标签或其他块级元素（如\<div\>, \<p\>等）来实现的。因此，当你在Vue（或任何其他前端框架）中直接渲染包含\n的字符串时，你不会看到预期的换行效果。

为了在Vue中渲染这些字符串并保持换行效果，你可以使用以下几种方法：

使用CSS样式：你可以使用CSS的white-space属性设置为pre-line，这样\n字符会被解释为换行。

vue
Copy code
\<template\>
\<div class="pre-line-style"\>
\{\{ yourString \}\}
\</div\>
\</template\>

\<style\>
.pre-line-style \{
white-space: pre-line;
\}
\</style\>
替换\n为\<br\>标签：将字符串中的所有\n字符替换为HTML的\<br\>标签，并使用Vue的v-html指令渲染字符串。

vue
Copy code
\<template\>
\<div v-html="formattedString"\>\</div\>
\</template\>

\<script\>
export default \{
computed: \{
formattedString() \{
return this.yourString.replace(/\n/g, '\<br\>');
\}
\},
data() \{
return \{
yourString: 'Your string with\nnew lines'
\};
\}
\}
\</script\>
使用自定义过滤器：你也可以定义一个Vue过滤器来转换\n为\<br\>，然后在模板中使用这个过滤器。

vue
Copy code
\<template\>
\<div v-html="yourString | newlineToBr"\>\</div\>
\</template\>

\<script\>
export default \{
filters: \{
newlineToBr(value) \{
return value.replace(/\n/g, '\<br\>');
\}
\},
data() \{
return \{
yourString: 'Your string with\nnew lines'
\};
\}
\}
\</script\>
选择哪种方法取决于你的实际需求和使用场景。
