# 配置

> 本节目标：理解“配置”的核心思路，并能把它用于实际开发或面试表达。
在Vue.js中，Vue.config.productionTip是一个配置选项，它用于控制在生产环境中是否显示生产提示。

设置Vue.config.productionTip = false将禁用Vue在启动时生成的生产提示，例如“你正在使用开发版Vue.js”或“你正在使用Vue.js的生产版本”。在开发环境中，这些提示对于开发人员非常有用，因为它们可以帮助开发人员意识到他们正在使用哪个版本的Vue.js，以及是否开启了Vue.js的调试模式。但是，在生产环境中，这些提示可能会暴露关于您的应用程序的敏感信息，因此最好将其禁用。

因此，将Vue.config.productionTip设置为false可以帮助保护您的应用程序在生产环境中的安全性和隐私性。
