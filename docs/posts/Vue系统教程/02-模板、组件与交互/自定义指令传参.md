# 自定义指令传参

> 本节目标：理解“自定义指令传参”的核心思路，并能把它用于实际开发或面试表达。
要在自定义Vue插件中传递`options`并在指令中使用它们，您需要稍微修改插件的安装方法和指令定义。以下是具体的代码示例：

1. **插件安装方法**：

在`install`方法中，您可以接收`options`参数，并将其传递给指令。

```javascript
import previewDirective from "./lib/index.js";

export default {
install(Vue, options) {
Vue.directive("preview", previewDirective(options));
},
};
```

2. **自定义指令**：

在`previewDirective`的实现中，您可以接收这些`options`并根据需要使用它们。例如：

```javascript
// lib/index.js
export default function previewDirective(options) {
return {
// 指令的定义
inserted: function(el, binding, vnode) {
// 您可以在这里使用options
console.log(options);
// 其他指令逻辑...
}
};
}
```

3. **在Vue项目中使用插件**：

当您在Vue项目中注册这个插件时，可以传入`options`：

```javascript
import Vue from 'vue';
import PreviewDirective from 'path-to-your-plugin';

Vue.use(PreviewDirective, { yourOption: 'value' });
```

这样，您就可以在插件中接收并使用这些传入的选项。
