# Class和style属性

> 本节目标：理解“Class和style属性”的核心思路，并能把它用于实际开发或面试表达。
它们也是`attribute`，自然可以使用`v-bind`来绑定表达式。

此外，vue对`v-bind`用于`class`和`style`时，做了专门增强：
表达式的结果可以是

- 字符串
- 对象
- 数组

:::
