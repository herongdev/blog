# class与style使用对象的区别

> 本节目标：理解“class与style使用对象的区别”的核心思路，并能把它用于实际开发或面试表达。
`V-bind:class`中的对象，它的键往往代表的是`class`类名；
`V-bind:style`中的对象，它的键往往代表的是`css`属性名，如`color,width,fontsize`等
