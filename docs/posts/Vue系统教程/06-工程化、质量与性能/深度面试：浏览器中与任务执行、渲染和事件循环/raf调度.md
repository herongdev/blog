# raf调度

> 本节目标：理解“raf调度”的核心思路，并能把它用于实际开发或面试表达。
一、当高频报价来临时，要更新的数据全部放入到数组队列中；
二、然后调用flushSchedule
三、这个函数中，会先判断是否有之前存在的rafId，有的话退出
四、如果没有，将回调函数放到raf的回调中；
五、浏览器在下一帧渲染前，会调用回调函数，当然可以在调用前清除回调；
六、在回调执行中，我们只取出队列中最新值，也就是最后一个元素，然后执行数据更新
七、数据更新完毕，将rafId重置，这样可以继续添加raf回调
