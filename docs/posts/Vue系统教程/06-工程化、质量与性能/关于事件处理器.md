# 关于事件处理器

> 本节目标：理解“关于事件处理器”的核心思路，并能把它用于实际开发或面试表达。
错误边界**无法**捕获事件处理器内部的错误。
`React` 不需要错误边界来捕获事件处理器中的错误。
与 `render` 方法和生命周期方法不同，事件处理器不会在渲染期间触发。
因此，如果它们抛出异常，`React` 仍然能够知道需要在屏幕上显示什么。
