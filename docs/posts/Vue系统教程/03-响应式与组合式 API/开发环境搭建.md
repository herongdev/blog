# 开发环境搭建

> 本节目标：理解“开发环境搭建”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
```
==搭建====Monorepo====环境==
==Vue3====中使用====pnpm== ==workspace====来实现====monorepo== ==(====pnpm====是快速、节省磁盘空间的包管理器。主要采用符号链接的方式管理模块====)==
```

```
==#====全局安装====pnpm==
npm install pnpm -g # 全局安装pnpm
pnpm init -y # 初始化配置文件
```

==#====创建====.npmrc====文件==
shamefully-hoist=true
==这里您可以尝试一下安装====Vue3====,== ==pnpm install vue@next====此时，由于我们是在====workspace-root====运行此命令，默认情况下====vue3====所====依赖的其它模块不会被提升到====node_modules====下，而是放在了====node_modules/.pnpm====下，如图：==

==这样，如果其它包也依赖这些模块，就可以共享了；此时，如果我们删除掉====vue====，====.pnpm====下====vue3====依赖的包并不会被删除，称之为幽灵依赖；====这样会有多余的用不到的包产生；==
==添加羞耻的提升可以将====Vue3====，所依赖的模块提升到====node_modules====中；==

==#====配置====workspace==
==新建== ==pnpm-workspace.yaml==
packages:
 - 'packages/*'
==将====packages====下所有的目录都作为包进行管理。这样我们的====Monorepo====就搭建好了。确实比====lerna + yarn workspace====更快捷==

==reactivity/package.json==
{
  "name": "@vue/reactivity",
  "version": "1.0.0",
  "main": "index.js",
  "module": "dist/reactivity.esm-bundler.js",
  "unpkg": "dist/reactivity.global.js",
  =="buildOptions"====:== =={== ==//== ==自定义的配置==
    =="name"====:== =="VueReactivity"====,====global====格式需要指定的全局变量名==
    =="formats"====:== ==[==
      =="esm-bundler"====,==
      =="cjs"====,==
      =="global"==
    ==]==
  ==}==
}
==shared/package.json==
{
  "name": "@vue/shared",
  "version": "1.0.0",
  "main": "index.js",
  "module": "dist/shared.esm-bundler.js",
  "buildOptions": {
    =="formats"====:== ==[== ==//== ==只在开发工具中使用，所以不需要====gobal====格式==
      =="esm-bundler"====,==

    ==]==

}

    "sourceMap": true, // 采用sourcemap
    "target": "es2016", // 目标语法
    "module": "esnext", // 模块格式
    "moduleResolution": "node", // 模块解析方式
    "strict": false, // 严格模式
    "resolveJsonModule": true, // 解析json模块
    "esModuleInterop": true, // 允许通过es6语法引入commonjs模块

      "dom"
    ], // 支持的类库 esnext及dom

    "paths": { // 路径映射，相对于baseUrl

        "packages/*/src"
      ]
    }
  }
}
