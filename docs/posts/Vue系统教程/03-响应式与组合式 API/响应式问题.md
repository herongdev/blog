# 响应式问题

> 本节目标：理解“响应式问题”的核心思路，并能把它用于实际开发或面试表达。
计算属性：

- 返回一个ref，即一个有value属性的对象；
- 对于计算属性中的依赖项，如果是一个普通对象或数组，不管是重新赋值，即依赖项指向别的值还是别的内存地址，还是修改其属性（对于数组），还是变更数组元素（比如调用其6个方法），均不会引起计算属性重新计算新ref的值；也就是会利用缓存的值，页面也不会重新渲染；
- 但如果依赖的变量是一个响应式的变量，比如ref或reactive变量，则这些依赖变量的重新赋值或更改，均会重新计算计算属性，页面也会重新渲染；
- 也就是说，在vue中，只有明确声明的响应式对象，其重新赋值或修改才会认为是依赖变化了，需要更新；
