# 数据流

> 本节目标：理解“数据流”的核心思路，并能把它用于实际开发或面试表达。
vue3 中的mitt起什么作用
ChatGPT
在Vue 3中，mitt是一个轻量级的、简单易用的事件总线（Event Bus）库，用于在组件间进行通信。在一些场景下，组件间的通信可能会变得复杂，尤其是在父子组件之间的嵌套层次较深时。使用mitt库可以帮助你更容易地实现组件间的解耦通信。

mitt允许你在组件之间发送和监听自定义事件。通过mitt，你可以在组件A发送一个事件，然后在组件B中监听该事件并作出响应。这使得组件之间的通信更加直接和简便。

以下是使用mitt的简单示例：

首先，通过npm或yarn安装mitt库：
Copy code
npm install mitt
或

csharp
Copy code
yarn add mitt
创建一个mitt实例并将其导出，以便在整个应用中使用：
javascript
Copy code
// eventBus.js
import mitt from 'mitt';

const eventBus = mitt();

export default eventBus;
在组件A中，发送一个自定义事件：
javascript
Copy code
// ComponentA.vue
\<template\>
\<button @click="emitEvent"\>Emit event\</button\>
\</template\>

\<script\>
import eventBus from './eventBus';

export default \{
methods: \{
emitEvent() \{
eventBus.emit('my-event', \{ message: 'Hello from Component A!' \});
\},
\},
\};
\</script\>
在组件B中，监听并响应组件A发送的自定义事件：
javascript
Copy code
// ComponentB.vue
\<template\>
\<div\>\{\{ message \}\}\</div\>
\</template\>

\<script\>
import eventBus from './eventBus';

export default \{
data() \{
return \{
message: '',
\};
\},
mounted() \{
eventBus.on('my-event', (payload) =\> \{
this.message = payload.message;
\});
\},
beforeUnmount() \{
eventBus.off('my-event');
\},
\};
\</script\>
在这个示例中，当用户点击组件A中的按钮时，将触发一个名为my-event的自定义事件。组件B会监听并响应这个事件，将传入的消息显示在其内部。
