# 变量命名

> 本节目标：理解“变量命名”的核心思路，并能把它用于实际开发或面试表达。
1. ref以ref结尾；
2. 计算属性以computed结尾
3. 属性自然是props.开头；
4. 组件状态以state命名；
5. 函数名能准确表达它的作用最好；
6. 能不简写就不要简写，除非这个简写全世界程序员都懂；
