# 双向绑定

> 本节目标：理解“双向绑定”的核心思路，并能把它用于实际开发或面试表达。
双向绑定其实说到底就是：

- 在组件中，使用传入的属性；
- 在组件中，当事件发生时，产生了新值，我们将新值传出去，将传给组件的属性赋予新值；
- 新的属性值的变化被检测到，从而我们又使用新的属性值；

使用v-model

- 属性名为modelValue或指定的属性名；
- 将属性值赋值给表单控件，在表单的改变值的事件中
