# 半双向绑定

> 本节目标：理解“半双向绑定”的核心思路，并能把它用于实际开发或面试表达。
一、子组件内部维护一个本地状态，接受props.modelValue为初始值；
二、当我们在子组件中输入等操作时，会改变本地状态，然后我们观察这个状态的变化，并触发update:modelValue事件，更新父组件的值；
三、父组件的值回流到子组件，但由于子组件只是以props.modelValue作为初始值，这个新的props.modelValue不影响子组件的状态，但这次更新是由子组件引发的，所以父子状态值能同步；
四、当外部状态让父组件的值发生变化时，子组件不会同步变化

- 适用版本：Vue 3 + \<script setup\>
- 典型场景：表单类组件（输入框、选择器等）既要 **内部可编辑**，又允许 **父组件控制初始值**；外部值变化 _是否_ 同步，由你决定。

**1 什么是「半双向绑定」？**

- **双向绑定**：子组件把 modelValue → 本地状态，再把 本地状态 → update:modelValue，并且 _任何_ 时刻父子保持一致。
- **半双向绑定**：
    1. **初始值**　父传 modelValue → 子组件用于初始化。
    2. **内部修改** 子组件只修改自己的本地状态，并向父发 update:modelValue。
    3. **内部引发的回流**　父更新 modelValue → 子收到 _同一个值_，无需再写入本地。
    4. **外部修改**　父若被其他逻辑改写 modelValue，子组件**默认不会同步**——这是「半」的本质。

这种设计的好处：

- 子组件内部操作无延迟、无闪烁（完全受本地状态控制）。
- 父组件想“锁死”子组件时，只需不额外把值写回即可。

**2 实现步骤**

```
<script setup lang="ts">
import { ref, watch, computed } from 'vue'
// 1.
```

声明属性与事件

```
const props = defineProps<{ modelValue: string }>()
const emit = defineEmits<{ (e: 'update:modelValue', v: string): void }>()
// 2.
```

本地状态，用于内部完全控制

```
const local = ref(props.modelValue)
// 3.
```

内部输入 `→` 发出

```
 update:modelValue
function onInput(e: Event) {
  const v = (e.target as HTMLInputElement).value
  local.value = v
  emit('update:modelValue', v) //
```

触发父组件更新

```
}
// 4. [
```

可选`]` 如果 `*`确实`*` 需要响应外部强行修改，则同步

```
 props → local
watch(
  () => props.modelValue,
  (v) => {
    //
```

只有当父给的新值与本地不同，再写入

```
    if (v !== local.value) local.value = v
  }
)
</script>
<template>
  <input :value="local" @input="onInput" />
</template>
```

**✏️** **只关心内部修改**
若你**确认**外部永远不会给子组件强行改值，可以 **删除 step 4**；这样能省一次 watch，彻底独立。

**✏️** **同步外部强改**
若业务场景里父组件偶尔会手动改值（如表单重置、回显），务必保留 watch 或改用 computed 双向 getter/setter：
const value = computed(\{ get: () =\> props.modelValue, set: v =\> emit('update:modelValue', v)\})

**3 父组件用法**
复制编辑
\<!-- 父组件 --\>\<MyInput v-model="username" /\>

- username 在第一次渲染时注入到子组件本地。
- 子组件输入后，父组件立即拿到新值。
- 若父组件在别处执行 username = ''，
    - **有 watch**：子组件也被清空。
    - **无 watch**：子组件界面保持原值，形成“只出不进”的半双向。

**4 最佳实践 & 注意点**

|   |   |
|---|---|
|**需求**|**建议实现**|
|不允许外部改动|不写 watch，让子组件彻底独立。|
|需要外部重置/回显|用 watch 或 computed 同步 props → local。|
|大型表单|建议全部使用 **受控组件**（真双向），便于统一重置与校验。|
|列表中的输入项|为每一项创建唯一 :key，否则切换时可能复用 DOM 带来脏值。|

**5 快速排错清单**

1. **父组件改值无效？** 确认子组件是否监听 props.modelValue。
2. **输入闪烁？** 说明你既在输入回调里改 local，又立即把 props.modelValue 写回导致两次赋值，检查 watch。
3. **没有触发 update:modelValue？** 检查事件名是否 exactly 'update:modelValue'；大小写错一个字母也收不到。

通过“初始注入 + 自主维护 + 可选同步”这一套，你就实现了 Vue 里的 **半双向绑定/半受控组件**。按需开启 watch 即可在“全受控”与“完全本地”之间自由切换。祝编码顺利！
