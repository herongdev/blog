# 模块间引用问题

> 本节目标：理解“模块间引用问题”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
如果使用相对路径引入其它模块，那么其他模块也会被打包到dist

monorepo能组织两个模块之间的关系，可以相互依赖；

如果直接引用其它模块，会出现找不到，因为其它的第三方模块不在node_module，
这里，我们需要配置模块查找方式，要修改tsconfig.json

修改pacakage.json，增加workspaces字段：

还要增加private:true

这样，当我们执行yarn install时，会创建软链接，
即把src/packages的所有模块在node_modules下创建软链；

同时,packages下的模块中的依赖也会被安装到相应模块的node_modules下

ts文件本身不需要声明文件；
