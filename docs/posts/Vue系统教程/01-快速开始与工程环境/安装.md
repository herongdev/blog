# 安装

> 本节目标：理解“安装”的核心思路，并能把它用于实际开发或面试表达。
**一、使用****\<script\>****引入**
用 ==\<script\>== 标签引入，==Vue== 会被注册为一个全局变量。
引入的资源可以是：

```
本地资源；
```

- ```
    互联网资源，如==CDN==：
    ```

    ```
    **开发环境：**==<script src====="https://cdn.jsdelivr.net/npm/vue/dist/vue.js"====></script>==
    ```

    **生产环境：**==推荐链接到一个明确的版本号和构建文件，以避免新版本造成的不可预期的破坏：====\<script src====="https://cdn.jsdelivr.net/npm/vue@2.6.11"====\>\</script==

```
**原生****ESModules****引入：**
```

```
==<script type====="module"====>======  ==import== ==Vue== ==from== =='====https://cdn.jsdelivr.net/npm/vue2.6.11/dist/vue.esm.browser.js===='========</script>==
```

**二、使用包管理器**
安装到本地计算机：构建大型应用时推荐使用NPM安装，原因：

配合使用模块打包器：NPM能很好地和诸如webpack或Browserify等打包器配合使用。

```
Vue也提供了许多配套工具来辅助开发单文件组件。
```

```
安装方式：如安装最新稳定版
$ npm install vue
```
