# “前端路由”有哪些优点和缺点？

> 本节目标：理解““前端路由”有哪些优点和缺点？”的核心思路，并能把它用于实际开发或面试表达。
==前端路由概念======
==前端路由就是把不同路由对应不同的内容或页面的任务交给前端来做，之前是通过服务端根据== ==url== ==的不同返回不同的页面实现的。======
==什么时候使用前端路由？======
==在单页面应用，大部分页面结构不变，只改变部分内容的使用======
**优点和缺点**======优点========用户体验好，不需要每次都从服务器全部获取，快速展现给用户======
==缺点========单页面无法记住之前滚动的位置，无法在前进，后退的时候记住滚动的位置====== ====**实现方法**
==前端路由一共有两种实现方式，一种是通过== ==hash== ==的方式，一种是通过使用== ==pushState== ==的方式。==
