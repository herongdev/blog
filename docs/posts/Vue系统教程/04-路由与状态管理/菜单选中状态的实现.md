# 菜单选中状态的实现

> 本节目标：理解“菜单选中状态的实现”的核心思路，并能把它用于实际开发或面试表达。
一、当接口从后端获取到当前用户的菜单数据时，我们将菜单整理成路由配置，并添加上meta属性，给他加上index属性，值为一个唯一标识码，要确保符合elementUi菜单组件规范；
二、watch路由变化，取出当前路由，从中取出meta.index将它赋值给menu组件；此时element的菜单会自己选择相应的菜单项；
