# 调用子组件方法

> 本节目标：理解“调用子组件方法”的核心思路，并能把它用于实际开发或面试表达。
在 Vue 3 中，如果你不想使用 ref 来调用子组件的方法或访问子组件的属性，可以通过以下几种方式实现，主要利用 **事件机制**、**provide/inject** 或 **插槽作用域** 等方法。以下是具体方法和示例：

**1.** **通过事件机制（子组件暴露方法，父组件触发）**
子组件可以通过自定义事件或 $emit 将方法或属性暴露给父组件，父组件通过触发事件间接调用子组件的方法或获取属性。

- 父组件通过监听事件（如 @call-method）接收并调用子组件的方法或获取属性。
- 这种方式避免了直接访问子组件实例，符合 Vue 的单向数据流原则。

**2.** **使用** **`provide/inject`** **共享方法或属性**
通过 provide/inject，父组件可以向子组件注入一个控制对象，子组件通过注入的对象暴露方法或属性，父组件间接调用。

- 父组件通过 childApi.value 访问子组件的方法或属性。
- 这种方式适合需要深层组件通信的场景，且不需要 ref。

**推荐方案**

- **事件机制**：适合简单的父子通信，代码直观，符合 Vue 的响应式设计。
- **provide/inject**：适合需要跨多层组件共享方法或属性的复杂场景。
- **作用域插槽**：适合通过模板直接协作的场景，语义清晰。

**注意事项**

- 避免直接操作子组件的内部状态，优先使用事件或插槽等声明式方式，保持单向数据流。
- 如果子组件需要动态更新属性，建议使用响应式数据（如 ref 或 reactive）并通过上述方式传递。
- 如果有多个子组件，provide/inject 或事件机制需要设计唯一标识以区分不同的子组件。
