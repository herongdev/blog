最重要的是defineProperty方法，对data的属性使用Object.defineProperty进行劫持处理；即定义了每一个属性的get和Set方法；

```
import { isObject } from "../utils";
class Observer {
    constructor(value) {
        // 核心是循环对象
        this.walk(value);
    }
    walk(data) {
        // 使用defineProperty重新定义
        Object.keys(data).forEach(key => {
            defineReactive(data, key, data[key])
        })
    }
}
function defineReactive(obj, key, value) {
    Object.defineProperty(obj, key, {
        get() {
            // 闭包，此vaule会向上层的value进行查找
            return value;
        },
        set(newValue) {
            value = newValue;
        }
    })
}
```

```
vue应用了defineProperty需要一加载的时候就进行递归操作，所以耗性能；
```

```
此外： 如果data层次过深也会浪费性能；
```

```
性能优化的原则：
 1) 不需要响应式的数据不要放在data中，因为所有的数据都会增加get和set；
 2) 不要写数据的时候层次过深， 尽量扁平化数据；
 3) 不要频繁获取数据和修改数据；
 4) 如果数据不需要响应式 可以使用Object.freeze 冻结属性；
```
