::: v-pre

如果表名与

`mapper`

不一致，
可以添加注解`@TableName("mp_user")`到实体类上，用来指定实体类所对应的表名；



如果表中的列名`id`与实体`id`属性不一致，比如一个是下划线连接，一个是驼峰，可使用

@TableId
注解



如果表中的列名与实体属性完全不一样，可以在实体属性上添加

@TableField()
注解来表明属性对应的表列名



:::
