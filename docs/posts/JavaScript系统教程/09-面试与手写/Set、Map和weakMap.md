**字典**
是一些元素的集合。每个元素有一个称作key 的域，不同元素的key 各不相同;

区别
共同点：集合、字典都可以存储不重复的值；
不同点：集合是以[值，值]的形式存储元素，字典是以[键，值]的形式存储；
