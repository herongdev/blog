# import实现代码分割原理

> 本节目标：理解“import实现代码分割原理”的核心思路，并能把它用于实际开发或面试表达。
`import()` 语句实现了一种称为**代码分割**（Code Splitting）的功能，这是一种优化技术，用于按需加载 JavaScript 模块。与传统的 JavaScript 打包方式不同，其中所有脚本通常在初始加载时一次性加载，代码分割允许应用将代码分散到多个包中，并仅在需要时从服务器动态加载这些包。这种方法可以显著改善应用的启动时间和性能，尤其是在大型应用中。

### 代码分割与 Tree Shaking 的区别

1. **代码分割 (Code Splitting)**
- **目的**：延迟加载部分代码，直到真正需要时才下载和执行。
- **实现方式**：通过 `import()` 来动态加载 JavaScript 模块。当这些模块被请求时，它们被加载进来，通常这会在用户交互或其他条件触发时发生。
- **结果**：减少初始负载量，分散网络负载，改进用户体验。

2. **Tree Shaking**
- **目的**：移除未被使用的代码。
- **实现方式**：在构建过程中，通过工具（如Webpack、Rollup等）静态分析应用中的导入和导出，识别哪些代码未被其他部分引用。
- **结果**：减少最终打包文件的大小，提高加载速度和性能。

### 动态 `import()` 的工作原理

- 当 `import()` 被调用时，它返回一个 `Promise` 对象，这意味着它是异步的。这允许JavaScript运行时动态地从服务器加载模块。
- 模块一旦加载完成，它会被缓存，因此重复的导入调用不会造成网络活动。
- 使用代码分割可以将应用分解成多个较小的块，这些块可以独立加载和缓存，提供更灵活的加载策略，如按页面、按功能或按用户请求加载。

### 使用场景

- **按需加载**：在某些条件满足时加载特定功能，例如响应用户操作（点击按钮等）。
- **条件加载**：根据环境条件（如设备类型、网络速度）加载不同的代码。
- **性能优化**：减少应用的初始加载时间，按需加载重量级功能，如图像编辑器、复杂图表等。

动态 `import()` 是现代JavaScript应用中一个非常有用的功能，特别是对于那些需要快速响应和高效资源管理的大型应用或SPA（单页应用）。它和Tree Shaking一起，形成了前端性能优化的强大工具。
