# 05-异步编程

> 章节目标：围绕“05-异步编程”建立知识主干，能说清关键机制，并能用最小代码或真实案例验证结论。

## 学习要求

- 阅读时把“概念、适用场景、常见错误、验证方法”分别记下来。
- 带代码的内容至少运行一次，再主动修改一个条件观察结果。
- 学完后选择三个主题，不看原文向别人讲清楚。
