# 现况

> 本节目标：理解“现况”的核心思路，并能把它用于实际开发或面试表达。
尽管目前的Web和JavaScript已经有了长足的发展，但Web表单的变化并不明显。

由于Web表单没有为许多常见任务提供现成的解决手段，很多开发人员不仅会在验证表单时使用JavaScirpt,而且还增强了一些标准表单控件的默认行为。
