# 计算树的分支数

> 本节目标：理解“计算树的分支数”的核心思路，并能把它用于实际开发或面试表达。
```
function getNum(arr) {
   return arr.reduce((acc, curr) => {
       return acc + (curr.children ? getNum(curr.children)+1 : 1);
        }, 0)
}
```
