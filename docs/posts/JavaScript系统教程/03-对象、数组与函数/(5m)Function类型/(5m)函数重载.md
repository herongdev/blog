# 函数重载

> 本节目标：理解“函数重载”的核心思路，并能把它用于实际开发或面试表达。
**重载概念：**
可以为一个函数编写两个定义，只要这两个定义的签名(接受的参数的类型和数量)不同即可。

**没有重载**
ECMAScirpt函数没有签名，因为其参数是由包含零或多个值的数组来表示的。而没有函数签名，其正的重载是不可能做到的。

```
**实际效果**
如果在ECMAScript中定义了两个名字相同的函数，则该名字只属于后定义的函数。请看下面的例子：
function addSomeNumber(num) {
  return num + 100;
}
function addSomeNumber(num) {
  return num + 200;
}
var result = addSomeNumber(100); //300
```

**模仿重载**
通过检査传入函数中参数的类型和数量并作出不同的反应，可以模仿方法的重载。

:::
