# 禁止引用

> 本节目标：理解“禁止引用”的核心思路，并能把它用于实际开发或面试表达。
反向引用会占用一定的系统资源，在较长的正则表达式中，反向引用会降低匹配速度。如果分组仅仅是为了方便操作，可以禁止反向引用。
实现方法：在左括号的后面加上一个问号和冒号。

```
**var** s1 = "abc";
```

```
**var** r = /(?:\w*?)|(?:\d*?)/;
```

```
**var** a = r.test(si);
```

非引用型分组必须使用子表达式，但是又不希望存储无用的匹配信息，或者希望提高匹配速度来说，是非常重用的方法
