# 判断某个对象是否包含指定的属性或方法

> 本节目标：理解“判断某个对象是否包含指定的属性或方法”的核心思路，并能把它用于实际开发或面试表达。
|   |   |   |   |   |   |
|---|---|---|---|---|---|
|**方法**|**获取自身属性**|**获取原型链上的属性**|**获取可枚举属性**|**获取不可枚举属性**|**获取 Symbol 属性**|
|in 运算符|是|是|是|否|是|
|hasOwnProperty 方法|是|否|是|否|否|
|Object.prototype.hasOwnProperty.call|是|否|是|否|否|
|Object.keys|是|否|是|否|否|
|Object.getOwnPropertyNames|是|否|否|是|否|
|Object.getOwnPropertySymbols|是|否|否|是|是|
|for...in 循环|是|是|是|否|否|
|Reflect.has 方法|是|是|是|否|是|
|Object.getOwnPropertyDescriptors|是|否|否|是|是|
|Object.entries|是|否|是|否|否|
|for...of 循环|是（可迭代对象）|否|是|否|是（可迭代对象）|
