# 归并方法

> 本节目标：理解“归并方法”的核心思路，并能把它用于实际开发或面试表达。
**reduce()**
**reduceRight()**
这两个方法都会迭代数组的所有项，然后构建一个最终返回的值。其中reduce()方法从数组第一项开始，逐个遍历到最后。而reduceRight()则从数组的最后一项开始，向前遍历到第一项。

两个方法都接收两个参数：一个在每一项上调用的函数和（可选的）作为归并基础的初始值。

第一个参数表示的函数接收4个参数：分别表示数组的前一个值，当前项，当前项的索引和数组本身。这个函数返回的任何值都会作为第一个参数自动传给下一项。
如果这个方法的表示初始值的参数没有传的话，将会把数组的第一项作为函数的前一个值，并从数组的第二项开始迭代；
如果有传递初始值的话，将会把初始值作为函数的当前值，并从数组的第一个项开始迭代。

reduceRight()方法和reduce方法完全一样，除了迭代顺序是从最后一项开始往前面。
