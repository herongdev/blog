# 正则表达式(&)什么意思？

> 本节目标：理解“正则表达式(&)什么意思？”的核心思路，并能把它用于实际开发或面试表达。
以`xxx`开头，或者`&xxx`。应该是用于匹配`url`参数的，比如`'a=1&b=2&c=3'`，查找某个`key`，可能在开头，也可能在某个`&`后。
