# 读取属性的特性

> 本节目标：理解“读取属性的特性”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
获取对象单个属性特性：

```
Object.getOwnPropertyDescriptor(obj,propname)
```
 获取对象所有属性特性：`Objcet.getOwnPropertyDescriptors(obj)`

这两个方法可以针对任何对象——包括`DOM`和`BOM`对象使用方法
