> 本节目标：理解“变量对象的两个阶段”的核心思路，并能把它用于实际开发或面试表达。
==我们知道一段可执行代码分为解析和执行两个阶段，变量对象的创建和赋值分别对应了这两个阶段。==
**代码解析阶段**
==在代码解析阶段，会根据执行上下文中的变量声明和函数声明来创建变量对象。注意此时除了函数上下文可以根据传入的参数对====arguments====属性赋值以外，其他声明的属性的值都为== ==undefined== ==，即未定义。==
**代码执行阶段**
==在代码执行阶段，会顺序执行代码，根据代码，修改变量对象的值。==
