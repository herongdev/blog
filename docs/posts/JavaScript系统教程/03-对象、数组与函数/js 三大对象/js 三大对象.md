# js 三大对象

> 本节目标：理解“js 三大对象”的核心思路，并能把它用于实际开发或面试表达。
```
JavaScript有3大对象，分别是本地对象、内置对象和宿主对象。
```

```
很多时候会直接把本地对象和内置对象统称为“内置对象”。
```

```
==ECMA-262====对于他们的定义：==
**本地对象**
```

```
==独立于宿主环境==
```

```
==由====ECMA-262== ==定义的类（引用类型）通过====new====来创建的对象==
```

```
==包含：====Object====、====Array====、====Function====、====RegExp====、====Date====、====Boolean====、====Number====、====String====等。==
```

```
**内置对象**
```

```
==独立于宿主环境====，由====ECMAScript====实现提供的对象。==
```

```
==本身就是====已====实例化====的====内置对象。==
```

```
==内置对象是本地对象的子集。==
```

```
==包含：====Global====和====Math====还有====E====S====5====中====新====增====的====JSON====。==
```

```
**宿主对象**
```

```
==由宿主环境提供的对象====。==
```

```
==包含两大类，一个是宿主提供，一个是自定义类对象。==
```

```
==所有非本地对象都属于宿主对象。==
```

==对于嵌入到网页中的====JS====来说，其宿主对象就是浏览器提供的对象，浏览器对象有很多，如====Window====和====Document====等。==

```
==所有的====DOM====和====BOM====对象都属于宿主对象。==
```
