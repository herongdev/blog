# 语句与代码块

> 本节目标：理解“语句与代码块”的核心思路，并能把它用于实际开发或面试表达。
**语句**
ECMAScript中的语句以一个分号结尾；如果省略分号，则由解析器确定语句的结尾；
虽然语句结尾的分号不是必需的，但我们建议任何时候都不要省略它。理由如下：

```
因为加上这个分号可以避免很多错误；
```

```
方便删除多余的空格来压缩ECMAScript代码；
```

```
减少解析器推测分号插入位置的消耗。
```

```
**代码块**
可以把多条语句组合到一个代码块中，即代码块以左花括号{开头，以右花
瞧}结尾。
```
