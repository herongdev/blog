# 字符长度限制

> 本节目标：理解“字符长度限制”的核心思路，并能把它用于实际开发或面试表达。
一、使用escape方法
在JavaScript中，你可以通过创建一个函数来实现这个功能，该函数计算字符串的字节长度，包括Unicode字符（比如中文）。这是一个例子：

```javascript
function getByteLength(string) {
var length = 0;
for (var i = 0; i < string.length; i++) {
if (escape(string[i]).length > 4) {
// 一个中文字符长度为2
length += 2;
} else {
// 一个英文或数字字符长度为1
length += 1;
}
}
return length;
}
```

在这个函数中，我们使用了JavaScript的`escape`函数，这个函数会将非ASCII字符转化为Unicode形式，然后我们通过检查转换结果的长度来判断原始字符是中文还是英文/数字。

然后你可以在需要验证的地方使用这个函数，例如：

```javascript
var inputString = document.getElementById("myInput").value;
if (getByteLength(inputString) > yourByteLimit) {
alert("输入的字节超出限制!");
}
```

请注意，你需要将`yourByteLimit`替换为你实际的字节限制。

另外，虽然你可以在前端进行这种验证，但出于安全性的考虑，你还应该在后端进行同样的验证，因为用户可以绕过前端的验证。

二、使用码点
确实有一种方法是使用JavaScript的`charCodeAt`函数或者`codePointAt`函数，它们可以用来获取字符串中字符的Unicode编码。这种方法在处理包含四字节Unicode字符（比如一些特殊表情符号）的字符串时更为准确。下面是使用`charCodeAt`的示例：

```javascript
function getByteLength(string) {
var length = 0;
for (var i = 0; i < string.length; i++) {
var code = string.charCodeAt(i);
if (code <= 0x7f) {
length += 1;
} else if (code <= 0x7ff) {
length += 2;
} else if (code <= 0xffff) {
length += 3;
} else {
length += 4;
}
}
return length;
}
```

而`codePointAt`能更准确地处理那些需要两个代码单元表示的字符（即那些Unicode超过0xFFFF的字符），使用这个函数的示例如下：

```javascript
function getByteLength(string) {
var length = 0;
for (var i = 0; i < string.length; i++) {
var code = string.codePointAt(i);
if (code <= 0x7f) {
length += 1;
} else if (code <= 0x7ff) {
length += 2;
} else if (code <= 0xffff) {
length += 3;
} else {
length += 4;
}
if (code > 0xffff) {
i++;
}
}
return length;
}
```

注意到在这个函数中，如果我们碰到了一个四字节的字符，我们需要额外的`i++`，因为这个字符会占用两个代码单元。同样，你可以在需要验证的地方使用这个函数。

三、使用流相关
在JavaScript中，一个常用的办法是利用`Buffer`对象的`byteLength`方法来直接计算字符串所占的字节数，这是Node.js环境下的方法：

```javascript
const Buffer = require('buffer').Buffer;

function getByteLength(string) {
return Buffer.byteLength(string, 'utf8');
}
```

如果你在浏览器环境下，可以使用`Blob`对象来计算字节数：

```javascript
function getByteLength(string) {
return new Blob([string], {type : 'text/html'}).size;
}
```

这两种方法都能正确处理各种类型的字符，包括单字节字符、双字节字符以及四字节字符。如果你需要在前端代码中计算字符串的字节数，那么第二种方法可能更适合你。
