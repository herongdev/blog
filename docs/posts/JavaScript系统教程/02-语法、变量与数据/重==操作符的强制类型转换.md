# 重==操作符的强制类型转换

> 本节目标：理解“重==操作符的强制类型转换”的核心思路，并能把它用于实际开发或面试表达。
```
null与undefined相等==。
```

其它类型和数字之间的相等比较，都是转换为数字之后再进行比较。

其他类型和布尔类型之间的相等比较，先将布尔值转换为数字后，再应用其他规则进行比较。

```
NaN不与任何值包括自身相等==。
```

对象和非对象之间的相等比较，对象先调用valueOf()，如果没有返回值，则调用toString()方法，再进行比较。

如果两个操作值都是对象，则比较它们是不是指向同一个对像，指向同一个对象，则相等否则不相等。
