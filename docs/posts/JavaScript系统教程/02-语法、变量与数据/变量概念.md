# 变量概念

> 本节目标：理解“变量概念”的核心思路，并能把它用于实际开发或面试表达。
```
变量是用存储数据的容器。
```

编写程序时，用变量来表示实际数据会方便些，尤其是当需要多次使用某个值时；如使用变量PI显然比直接写数字值3.141592653589793方便。

```
**松散类型**
ECMAScript的变量是松散类型的，也就是说：变量存储的值可以从一种类型变成另一种类型，如：
let a = 1;
a = 'a';
变量a原本存储的是数字类型的值，后面改为存储字符串类型的值；这在ECMASscript中是允许的。
```

:::
