# 概述

> 本节目标：理解“概述”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
- `String`类型用于表示由零或多个`Unicode`字符组成的字符序列，即字符串。
- 字符串可以由双引号（`"`）或单引号（`'`）表示。两种方式表示的字符串完全相同。

**转义序列**
`String` 数据类型包含一些特殊的字符字面量，也叫转义序列，用于表示非打印字符，或者具有其他用途的字符。这些字符字面量如下表所示：
字面量 含 义
`\t` 制表
`\b` 退格
`\r` 回车
`\`n 换行
`\f` 进纸
`\\` 斜杠

```
\'
```

单引号（`'`），在用单引号表示的字符申中使用。例如

```
:'He said,\'hey.\''
\"
```

双引号（`"`），在用双引号表示的字符串中使用。例如：

```
"He said,\"hei.\""
\xnn
```

以十六进制代码`nn`表示的一个字符（其中`n`为`0 ~ F` ）。例如，

```
\x41

```
"A"

```

```

表示希腊字符

**字符串的特点**

- 字符串是不可变的，一旦创建值就不能改变。
- 要改变某个变量保存的字符串，首先要销毁原来的字符串，然后再用另一个包含新值的字符串填充该变量，

例如：

```
var lang = "Java";
lang = lang + "Script";
```
 实现这个操作的过程如下：首先创建一个能容纳`10`个字符的新字符串，然后在这个字符串中填充

```
'Java'
```

和

```
'scipt'
```

，最后一步是销毁原来的字符申`'Java'`和

```
'Script'
```

，因为这两个字符串已经没用了。这个过程是在后台发生的。
