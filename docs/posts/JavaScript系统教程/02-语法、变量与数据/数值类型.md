# 数值类型

> 本节目标：理解“数值类型”的核心思路，并能把它用于实际开发或面试表达。
==toPrecision== ==和== ==toFixed== ==和== ==Math.round== ==的区别？==
==toPrecision== ==用于处理精度，精度是从左至右第一个不为== ==0== ==的数开始数。==
==toPrecision()== ==方法以指定的精度返回该数值对象的字符串表示。==

==toFixed== ==是对小数点后指定位数取整，从小数点开始数起。========Math.round== ==是将一个数字四舍五入到一个整数。==
