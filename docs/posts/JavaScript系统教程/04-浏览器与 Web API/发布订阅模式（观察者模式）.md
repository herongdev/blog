# 发布订阅模式（观察者模式）

> 本节目标：理解“发布订阅模式（观察者模式）”的核心思路，并能把它用于实际开发或面试表达。
`//`发布者

```
var event = {};
//
```

发布者的缓存列表

```
event.clientList = [];
//
```

增加订阅者函数

```
event.listener = function (fn) {
this.clientList.push(fn);
}
//
```

发布信息

```
event.trigger = function () {
for (var i = 0; i < this.clientList.length; i++) {
var fn = this.clientList[i];
fn.apply(this, arguments);
}
}
```
