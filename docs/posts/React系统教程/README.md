# React系统教程

> 完成后，你能理解 React 的组件与更新模型，组织状态和路由，并阅读常见实现原理。

## 推荐学习方法

1. 按章节顺序阅读，先建立主干知识，再查补充主题。
2. 运行或改写笔记中的代码，不只记结论。
3. 每完成一章，用自己的话讲清核心机制，并为易错点补一个最小示例。
4. 遇到版本较老的写法，先理解其解决的问题，再结合当前项目决定是否采用。
