# 数组当子元素

> 本节目标：理解“数组当子元素”的核心思路，并能把它用于实际开发或面试表达。
```
React 组件也能够返回存储在数组中的一组元素：
render() {  // 不需要用额外的元素包裹列表元素！  return [    // 不要忘记设置 key :)    <li key="A">First item</li>,    <li key="B">Second item</li>,    <li key="C">Third item</li>,  ];}
```
