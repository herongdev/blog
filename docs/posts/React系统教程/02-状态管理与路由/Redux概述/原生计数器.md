- `store`对象`dispatch`一个代表一种操作和相应操作值的对象之后；
- 就会执行`reducer`，并传入`store`之前的值和操作对象；
- 然后`reducer`会根据传入的操作对象和`store`旧值，算出新的值；
- 然后用这个新的值替换老的`store`；
- 在整个过程中，老的`store`值并未被修改，只是`store`转存了一个新值，也就是说，`reducer`是一个纯函数，并不会修改传入函数的参数；
