# 如何将字符串反转？

> 本节目标：理解“如何将字符串反转？”的核心思路，并能把它用于实际开发或面试表达。
可以使用 StringBuilder 类的 reverse() 方法来反转字符串。例如：
StringBuilder sb = new StringBuilder("example");
sb.reverse();
String reversedString = sb.toString();
