# HJ76 尼科彻斯定理

> 本节目标：理解“HJ76 尼科彻斯定理”的核心思路，并能把它用于实际开发或面试表达。

> 说明：原 OneNote 中有图片引用，但图片未包含在导出目录中；本页保留了可用的文字与代码内容。
简单  通过率：46.98%  时间限制：1秒  空间限制：32M
知识点==基础数学==
**描述**
验证尼科彻斯定理，即：任何一个整数m的立方都可以写成m个连续奇数之和。
例如：
1^3=1
2^3=3+5
3^3=7+9+11
4^3=13+15+17+19
输入一个正整数m（m≤100），将m的立方写成m个连续奇数之和的形式输出。
数据范围： 1≤_m_≤100
进阶：时间复杂度：�(�) _O_(_m_) ，空间复杂度：_O_(1)
**输入描述：**
输入一个int整数
**输出描述：**
输出分解后的string
**示例1**
输入：
6
==复制==
输出：
31+33+35+37+39+41

inputInt = int(input())
center = inputInt * inputInt
distance = inputInt // 2
result = ""
if inputInt % 2 == 1:
result = "+".join(
map(
str, [i for i in range(center - distance * 2,
center + distance * 2 + 1, 2)]
)
)
else:
result = "+".join(
map(
str,
[j for j in range(center - distance * 2 + 1,
center + distance * 2, 2)],
)
)
print(result)

尼科彻斯定理表明任何正整数`m`的立方都可以表示为`m`个连续奇数之和。实际上，这些连续奇数的起始数可以通过一个简单的公式计算得出：`(m * (m - 1) + 1)`。然后，你只需要从这个起始数开始，连续地取`m`个奇数相加即可。

def nicomachus_theorem(m):
# 计算起始奇数
start_odd = m * (m - 1) + 1
# 生成m个连续奇数，并将它们转换为字符串形式
odd_numbers = [str(start_odd + 2 * i) for i in range(m)]
# 将这些奇数使用加号连接起来，形成最终的字符串
return '+'.join(odd_numbers)

# 输入
m = int(input())
# 输出
print(nicomachus_theorem(m))

这段代码首先计算了起始的奇数，然后通过列表解析生成了一个包含`m`个连续奇数的列表。列表中的每个奇数首先被转换为字符串，然后使用`'+'.join()`方法将这些字符串以加号`+`连接起来，形成最终需要的格式。

例如，当`m = 6`时，该函数将输出`"31+33+35+37+39+41"`，正好符合尼科彻斯定理的要求。
