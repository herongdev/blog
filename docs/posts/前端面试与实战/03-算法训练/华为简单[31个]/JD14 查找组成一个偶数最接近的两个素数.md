# JD14 查找组成一个偶数最接近的两个素数

> 本节目标：理解“JD14 查找组成一个偶数最接近的两个素数”的核心思路，并能把它用于实际开发或面试表达。
简单  通过率：41.90%  时间限制：1秒  空间限制：32M
知识点==查找====基础数学====穷举==
**描述**
任意一个偶数（大于2）都可以由2个素数组成，组成偶数的2个素数有很多种情况，本题目要求输出组成指定偶数的两个素数差值最小的素数对。
数据范围：输入的数据满足 4≤�≤1000 4≤_n_≤1000
**输入描述：**
输入一个大于2的偶数
**输出描述：**
从小到大输出两个素数
**示例1**
输入：
20
==复制==
输出：
713
==复制==
**示例2**
输入：
4
==复制==
输出：
22

为了找到组成指定偶数的两个素数差值最小的素数对，我们可以采取以下步骤：

1. **素数检测函数**：实现一个函数，用于检测一个数是否为素数。
2. **寻找素数对**：从该偶数的一半开始，向两边扩展寻找素数对，这样可以保证找到的第一对素数差值最小。
3.注意，偶数的一半可能是素数，比如4，它就是分成2+2，从中间数开始，包含中间数，另外判断的是当前数和一个比它小1的数，比如20，因为如果中间是10，再减1就是9，另一个值就是20-9，判断这两个数就行。
4.注意遍历时的最小值取值，如果取1，n-1就是0，取2，则是判断2和1是否是素数，比较合理

下面是实现这个逻辑的Python代码：
def is_prime(n):
if n \<= 1: # 素数定义为大于1的自然数
return False
for i in range(2, int(n ** 0.5) + 1): # 只需检查到sqrt(n)即可
if n % i == 0: # 如果n能被任何数整除，则不是素数
return False
return True # 如果以上都不满足，则n是素数

def get_prime_pairs(n):
for i in range(n//2, **1**, -1): # 从n/2开始向下检查，确保差值最小
if is_prime(i) and is_prime(n-i):
return i, n-i # 返回第一对找到的素数对

# 输入
input_num = int(input())
# 获取并打印素数对
left, right = get_prime_pairs(input_num)
print(left)
print(right)

这段代码首先定义了`is_prime`函数，用于判断给定的数是否为素数。接着，`find_prime_pair`函数从偶数的一半开始向下遍历，对于每个数`i`，检查`i`和`n-i`是否都是素数。如果都是素数，说明找到了一对符合条件的素数对，然后返回这两个素数。由于是从中间向两边找的，所以找到的第一对素数差值最小。

请注意，对于大于2的偶数，根据哥德巴赫猜想（尚未完全证明，但已被广泛验证），每个大于2的偶数都可以表示为两个素数之和，因此这个算法是可行的。
