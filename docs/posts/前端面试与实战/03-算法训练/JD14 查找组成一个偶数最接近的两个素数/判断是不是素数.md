# 判断是不是素数

> 本节目标：理解“判断是不是素数”的核心思路，并能把它用于实际开发或面试表达。
def is_prime(n):
if n \<= 1: # 素数定义为大于1的自然数
return False
for i in range(2, int(n**0.5) + 1): # 只需检查到sqrt(n)即可
if n % i == 0: # 如果n能被任何数整除，则不是素数
return False
return True # 如果以上都不满足，则n是素数
