# HJ34 图片整理

> 本节目标：理解“HJ34 图片整理”的核心思路，并能把它用于实际开发或面试表达。
简单  通过率：52.18%  时间限制：1秒  空间限制：32M
知识点==字符串====排序==
**描述**

Lily上课时使用字母数字图片教小朋友们学习英语单词，每次都需要把这些图片按照大小（ASCII码值从小到大）排列收好。请大家给Lily帮忙，通过代码解决。
Lily使用的图片使用字符"A"到"Z"、"a"到"z"、"0"到"9"表示。

数据范围：每组输入的字符串长度满足 1≤�≤1000 1≤_n_≤1000
**输入描述：**
一行，一个字符串，字符串中的每个字符表示一张Lily使用的图片。
**输出描述：**
Lily的所有图片按照从小到大的顺序输出
**示例1**
输入：
Ihave1nose2hands10fingers
==复制==
输出：
0112Iaadeeefghhinnnorsssv

是的，`sorted()`函数可以对字符串进行排序。在Python中，`sorted()`函数会将字符串视为字符序列，并根据字符的ASCII码值（或Unicode码点）对这些字符进行排序。排序后，`sorted()`函数返回字符的列表，而不是一个字符串。如果你想得到一个排序后的字符串，需要将排序后的字符列表重新组合成字符串。

针对"HJ34 图片整理"问题，我们可以直接使用`sorted()`函数对输入的字符串进行排序，然后使用`join()`方法将排序后的字符列表组合成一个新的字符串。以下是解决这个问题的Python代码示例：
def sort_string(s):
# 对字符串中的字符进行排序
sorted_chars = sorted(s)
# 将排序后的字符列表组合成新的字符串
sorted_string = ''.join(sorted_chars)
return sorted_string

# 示例输入
input_string = input()
# 执行函数并打印结果
print(sort_string(input_string))

这段代码首先调用`sorted()`函数对输入字符串`input_string`中的所有字符按ASCII码值进行排序，得到一个字符列表`sorted_chars`。然后，使用`''.join(sorted_chars)`将这些排序后的字符合并成一个新的字符串`sorted_string`，最后打印出这个排序后的字符串。

这种方法适用于任何包含“`A`到`Z`”、“`a`到`z`”、“`0`到`9`”字符的字符串，它将按照字符的ASCII码值从小到大的顺序进行排序，正好符合题目的要求。
