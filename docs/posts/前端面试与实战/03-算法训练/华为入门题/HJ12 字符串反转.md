# HJ12 字符串反转

> 本节目标：理解“HJ12 字符串反转”的核心思路，并能把它用于实际开发或面试表达。
**描述**
接受一个只包含小写字母的字符串，然后输出该字符串反转后的字符串。（字符串长度不超过1000）
**输入描述：**
输入一行，为一个只包含小写字母的字符串。
**输出描述：**
输出该字符串反转后的字符串。
**示例1**
输入：
abcd
==复制==
输出：
dcba
==复制==

# 读取输入的字符串
input_str = input()
# 使用切片操作反转字符串
reversed_str = input_str[::-1]
# 输出反转后的字符串
print(reversed_str)
